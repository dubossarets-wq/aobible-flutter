## 0. Из чего состоит «Карты и места»

| Часть | Что это |
|---|---|
| Строка «Название · Карта» в выборе слова | нажали слово — названное место предлагается открыть на карте (§3) |
| Карта места | отдельная **панель во второй половине главного экрана**: спутник/обычная карта, точка места, карточка места (§4) |
| Окно «Карты» (из «Ещё») | поиск мест по названию и библейские карты-картинки (25 штук) с увеличением (§5) |
| Модули | «Места» (`bible-places`, 1321 место) и «Карты» (`bible-maps`, 25 картинок) — оба `type: maps` (§1) |

Прежний отдельный экран (`MapScreen`: карта на весь экран с кнопкой «закрыть» и `Navigator.pop`) в коде есть, но **нигде не вызывается** — рабочий путь только «карта во второй половине экрана» (`openPlaceMap` → `mapPaneProvider`).

## 1. Данные

### 1.1. Модуль «Места» (`bible-places`)

JSON-модуль: `places` — список из 1321 места; поля места:
- `id` (`hebron`), `name` («Хеврон»), `lat`, `lng` — координаты в градусах;
- `type` — тип места, свободный текст: «населённый пункт», «область», «река», «горный хребет», «стоянка», «народ», «водоём», «дорога», «холм», «гора», «долина», «поле», «дерево»… (бывают составные: «гора, населённый пункт», «область, особое место», английские «mountain pass», «structure»). Влияет на масштаб (§4.4) и показывается в карточке и списке;
- `confidence` — **достоверность** отождествления, целое 0…100 (в данных у всех мест есть; показывается «Достоверность: N%» с полоской);
- `modern` — **современное отождествление** («Телль-Румейда, Хеврон, Палестина (Западный берег)», «река Барада, Сирия»); показывается как «Сейчас: …»;
- `description` — описание (несколько предложений с цитатами);
- `stems` — **основы названия** строчными без «ё» (`["хевр"]`, `["ава"]`), по которым узнаётся нажатое слово;
- `refs` — стихи, где место упомянуто, OSIS: `Gen.13.18`, `Josh.10.3`. В данных места — **только одиночные стихи** (диапазонов «Deut.8.7-9» у мест нет; у картинок они бывают);
- `nameEn` — английское название (приложением не используется).
Служебные поля модуля: `license` (показывается в карточке), `name`, `title`, `version`, `author`, `source`.

**Хранение на устройстве.** При установке (`convertPlaces`, в отдельном потоке) JSON раскладывается в таблицы SQLite этого модуля:
- `places(id PRIMARY KEY, ord, name, name_norm, lat, lng, type, confidence, modern, descr, stems, refs)` — `ord` порядок в файле, `name_norm` = название строчными с «ё»→«е», `stems` и `refs` — JSON-строки со списками; индекс по `name_norm`;
- `place_refs(ref, place_id)` — по строке на каждый стих из `refs`; индекс по `ref`. Строка `ref` — **ровно как в данных** (`Josh.14.15`).
У модуля «Места» **нет** таблицы `payload` (она есть только у «Карт»). Модуль считается «местами», если в базе есть таблица `places`.

### 1.2. Как находится место (`PlaceStore`)

- `inVerse(ref)` — места, у которых в `place_refs` есть **ровно** строка `Книга.глава.стих` этого стиха (по всем установленным модулям мест). Диапазонные ссылки не раскрываются.
- `forWord(слово, ref)` — из `inVerse(ref)` берутся те, у которых **любая основа** `stems` является **началом** нажатого слова; слово приводится к виду: строчные, «ё»→«е». Повторы по `id` убираются. Пример: «Хеврону» → «хевр…» → Хеврон; «Хеврон» нажато в стихе, где Хеврон не упомянут, — не предлагается.
  **Условия вместе:** место есть в списке упоминаний **этого стиха** И слово начинается с основы названия. «Карта наугад» не предлагается.
- `search(запрос, limit 50)` — запрос приводится как выше; короче 2 знаков — пусто; иначе подстрока в `name_norm` (с экранированием `%` `_` `\`), порядок `ord`, до 50 мест, модули подряд, пока не набралось 50.
- `count` — общее число мест во всех модулях (для заголовка «Места · N»).

### 1.3. Модуль «Карты» (`bible-maps`)

JSON-модуль с `maps` — список из 25 карт-картинок (Wikimedia Commons). Поля: `id`, `title` («Святая Земля: рельеф»), `description` (несколько абзацев: что на карте, язык подписей, **источник и лицензия**), `image` — путь относительно сайта (`modules/maps/bible-maps/relief.jpg`), `refs` — OSIS-ссылки, в том числе **диапазонами** (`Deut.8.7-9`, `Gen.12.1-9`).
Хранится в таблице `payload` (одна строка `json`). Картинка скачивается **по запросу** (`download(путь)`: сначала `https://aobible.app/`, при сбое — зеркало на GitHub Pages), кэшируется в памяти на время работы приложения (ошибка в кэш не попадает — можно повторить).

| Подложка | Источник | Примечания |

| Спутник (по умолчанию) | растровые тайлы **Sentinel-2 cloudless 2016** от EOX: `https://tiles.maps.eox.at/wmts/1.0.0/s2cloudless_3857/default/g/{z}/{y}/{x}.jpg` | свои снимки до приближения 13, дальше растягиваются; лицензия CC BY 4.0 |

| Точка места | один слой-кружок поверх всего: радиус 9, цвет `#B4451F` (светлая тема) / `#D9A35C` (тёмная), белая обводка 3 | |

Подписи источников (всегда видны, §4.6): спутник — «Sentinel-2 cloudless — https://s2maps.eu by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2016)» + « · » + «OpenFreeMap © OpenMapTiles Data from OpenStreetMap»; обычная — только «OpenFreeMap © OpenMapTiles Data from OpenStreetMap».
На **компьютере** (Windows/macOS/Linux) у MapLibre нет окна карты, вместо него `TileMap` — своя карта из тех же спутниковых тайлов (перетаскивание, колесо, «+ −», масштаб 2…17, снимки до 13); там нет обычной карты (кнопка «Спутник/Обычная» скрыта) и подпись только спутниковая. К iOS не относится.

### 1.5. Масштаб по типу места (`zoomFor`)

Тип места (строка) проверяется регулярными выражениями **по подстроке**:
- содержит «область», «район» или «народ» → масштаб **6,5** (область видна целиком);
- иначе содержит «хребет», «долина», «река», «водоём» или «пустын» → **8,5**;
- иначе → **11** (город с окрестностями).
(«область, особое место» → 6,5; «гора, река, населённый пункт…» → 8,5, потому что «река».)

## 3. Вход из чтения: слово → «Название · Карта»

При нажатии на слово собирается выбор слова (`SWIFT_SPEC` §2, `02-study.md`). Модуль «Карт» добавляет в него пункты `Hub.wordMenuItems`: для каждого найденного места (`PlaceStore.forWord(слово, ref)`) строка
**значок «метка» (акцент) · «{Название}» (жирно) · «·» · «Карта» · стрелка ›**. Порядок `order: 10` — эти строки стоят **выше** строк словарей (Стронг и др. идут после, порядок 100). Если места нет или модулей мест нет — пунктов нет.
Нажатие на строку → `openPlaceMap(place)`: выбор слова закрывается, карта открывается во второй половине экрана (§4.1).

Если слово — название нескольких мест (одно слово подходит к основам нескольких мест, упомянутых в этом стихе) — строк несколько, по одной на место (без повторов).

## 4. Карта места (`MapPaneView`)

### 4.1. Как и где открывается

`mapPaneProvider.open(place)`: главный экран (`HomeScreen`) показывает карту **в одном из слотов разделителя**:
- панель чтения одна → слоты: `[панель, карта]`;
- панелей несколько → **последняя панель чтения заменяется картой** (сама панель не закрывается, её место и перевод сохраняются; после закрытия карты она возвращается);
- слоты делят экран **поровну**; раскладка по общему правилу (настройка «панели»: рядом / друг над другом / авто: рядом, если ширина экрана ≥ 720 и ширина > 0,9 высоты; иначе друг над другом) — **карта всегда второй слот**: на iPhone внизу, на широком экране справа.
Состояние **не сохраняется**: после перезапуска приложение снова открывается чтением без карты.
Выбор другого места, пока карта открыта, **заменяет** карту: панель создаётся заново (`key = ValueKey(place)`, у `Place` нет сравнения по значению → новый объект = новая панель), поэтому подложка и режимы возвращаются к начальным (спутник; «только карта» выключено; карточка в начальном состоянии) [вывод из кода; уточнить на телефоне].

### 4.2. Шапка карты (на всю ширину панели)

Высота и цвет — как у шапки панели чтения (настройка `barHeight`, цвет верхней панели). Слева — значок «метка» и **название места** (жирно, одна строка). Справа три круглые кнопки 40×40:

| Кнопка | Значок | Подсказка | Что делает |
|---|---|---|---|
| Только карта | «слои» | «Только карта и точка» (включено: «Показать все наложения») | см. §4.5; включённая подсвечена |
| Спутник/Обычная | «карта» (когда спутник включён) / «спутник» (когда выключен) | «Обычная карта» (когда сейчас спутник) / «Спутник» (когда обычная) | переключает подложку; включённый спутник подсвечен. **На компьютере кнопки нет** |
| Закрыть | ✕ | «Закрыть карту» | `mapPaneProvider.close()` — карта закрывается, возвращается вторая панель чтения |

Кнопки «Только карта» и «Спутник/Обычная» недоступны (бледные), пока карта не загрузилась (`_ready == false`).

### 4.3. Карта

- Движок: MapLibre (на iPhone — нативный). Стиль: OpenFreeMap «liberty». Начальная позиция: центр = координаты места, масштаб `zoomFor(type)` (§1.5). Компас, наклон и логотип отключены; масштабная линейка включена; остальные жесты — по умолчанию MapLibre (сдвиг, щипок, поворот двумя пальцами).
- Пока стиль грузится — сверху плашка с крутилкой «**Загружаю карту…**».
- Когда стиль загрузился (`_onStyle`): добавляется растровый слой **спутника** (источник EOX, `maxzoom 13`, размер тайла 256) сразу **над самым нижним слоем** стиля (под остальными, так как остальные слои — над ним), и слой **точки** (источник — одна точка места) поверх всего. После этого применяются режимы (§4.5).
- Кнопки масштаба **«+»** («Увеличить») и **«−»** («Уменьшить»): белая группа справа вверху (отступ 10); уровень ±1 с анимацией. В режиме «только карта» скрыты.
- Фон за картой — светло-серый (пока тайлы не пришли).

### 4.4. Смена места при открытой карте

Если у панели меняется место (тот же виджет, другой `id`, пока карта готова), точка переносится и камера **плавно (900 мс)** летит к новому месту с масштабом по типу; в обычном потоке (§4.1) панель создаётся заново, и камера просто ставится на место.

### 4.5. Режимы подложки и «Только карта»

Состояние: `_sat` (по умолчанию **true**), `_clean` (по умолчанию **false**).
Слои стиля «liberty» делятся на **заливки** — слои, чьё имя начинается с `background`, `park`, `water`, `landcover` или `landuse` (после чего идёт `_` или конец имени) и в имени которых нет `name`, `label`, `shadow`, `building`, `aeroway`, `boundary` — и остальные (дороги, границы, подписи, здания…).

| `_sat` | `_clean` | Спутник | Заливки | Остальные слои |
|---|---|---|---|---|
| вкл | выкл | видим | **скрыты** (иначе закрыли бы снимки) | видимы (подписи, дороги, границы поверх снимков) |
| выкл | выкл | скрыт | видимы | видимы |
| вкл | вкл | видим | скрыты | **скрыты** → «чистый» снимок и точка |
| выкл | вкл | скрыт | видимы | скрыты → «суша и вода» без подписей и линий и точка |

Включение «Только карта» ещё и **сворачивает карточку места** (и скрывает её полностью, §4.7). Все вызовы видимости слоёв отправляются одним пакетом.

### 4.6. Подпись источников

Всегда видна **сверху слева** карты (отступы 6 / 6, справа оставлено 64 под кнопки масштаба), мелким шрифтом на светлой плашке, не нажимается. Состав — §1.4. Внизу её закрывали бы карточка и меню, поэтому она сверху. Условие лицензий CC BY / ODbL.

### 4.7. Карточка места

Плавающая карточка поверх карты, **слева внизу** (отступ 10 от краёв и от нижней границы области + нижний отступ экрана): на узкой области (< 640 pt) — на всю ширину минус отступы; на области ≥ 640 pt — **шириной 380** слева.
Максимальная высота — 55 % высоты области карты; содержимое прокручивается.

- **Заголовок карточки** (всегда виден, нажатие сворачивает/разворачивает): «**{Название}**» жирно + « · {тип}» серым (одна строка) и стрелка (вниз у раскрытой, вверх у свёрнутой, поворот 200 мс).
- **Начальное состояние:** раскрыта, если **высота экрана > 700 и ширина ≥ 720** (iPad), иначе свёрнута (на iPhone видна карта + строка заголовка). Дальше — как переключил человек (кроме §4.5).
- **Тело** (раскрывается и сворачивается плавно), сверху вниз; пустые поля не показываются:
  1. «**Сейчас:** {современное отождествление}» (подпись серым).
  2. «**Достоверность: {N}%**» (мелко, серым) и под ним полоска 5 pt шириной `N %` (N ограничено 0…100).
  3. Описание.
  4. Плашки стихов — `{Книга. гл:ст}` (обычная короткая `formatRef`), **до 40**; если больше — серым «**и ещё {n}**». Нажатие на плашку → **первая панель чтения** (`navigate(0, ref)`) идёт к стиху; **карта остаётся открытой** (окон нет, закрывать нечего). Порядок — как в данных. Диапазонные ссылки (если встретятся) идут с первого стиха; нераспознанные пропускаются.
  5. Линия и примечание: ссылка «**Спутник Google** ↗» — открывает во внешнем браузере/приложении `https://www.google.com/maps/@{lat},{lng},2000m/data=!3m1!1e3` (спутниковый вид на высоте 2000 м), затем « · {лицензия модуля}» (`license` модуля; если пусто — «**OpenBible.info, CC BY 4.0**»).
- **Видимость:** карточка показывается, если не включён режим «Только карта» **или** карточка раскрыта; на практике при «Только карта» она скрыта полностью (включение сворачивает её); при выключении «Только карта» появляется **свёрнутой** (только заголовок).

### 4.8. Чтобы точка не пряталась под карточкой

После каждого изменения (карта готова, карточка раскрыта/свёрнута, режим, ширина области) камера центрируется на точке, а затем смещается на свободную часть:
- область ≥ 640 pt (карточка слева): на `(ширина карточки + 20) / 2` по горизонтали — точка уходит вправо от карточки;
- иначе (карточка снизу): на `(высота карточки + 20) / 2` по вертикали — точка поднимается над карточкой.
Смещение — плавно за 300 мс. Начальное положение камеры (без анимации) — просто центр на точке.

### 4.9. Что происходит при действиях (сводка)

| Действие | Результат |
|---|---|
| Нажали слово → «Название · Карта» | карта открывается во второй половине экрана, камера на месте |
| Шапка: «Только карта и точка» | подложка очищается, карточка и «+ −» скрыты; повторное нажатие возвращает |
| Шапка: «Обычная карта» / «Спутник» | подложка переключается (заливки скрываются/показываются) |
| Шапка: ✕ | карта закрыта, вторая панель чтения на месте |
| «+» / «−» | масштаб ±1 |
| Заголовок карточки | свернуть/развернуть (камера сдвигается) |
| Плашка стиха | первая панель читает этот стих; карта остаётся |
| «Спутник Google» | внешняя ссылка |
| Жесты по карте | сдвиг / щипок / поворот |
| Открыли другое место (из слова или из окна «Карты») | карта заменяется новым местом |

## 5. Окно «Карты» («Ещё → Карты»)

**Когда пункт виден:** флаг `menu.maps` (Настройки → «Меню «Ещё»», по умолчанию включён) **и** установлен хотя бы один модуль типа `maps` (любой: «Места» или «Карты»). Значок «карта», порядок 60. Открывается обычным окном (лист), вкладка «Ещё» подсвечена.
Заголовок окна «**Карты**». Две части в одном прокручиваемом списке (показывается только то, что установлено):

### 5.1. Места (если есть модуль «Места»)

1. Заголовок группы «**Места · {N}**» (N — общее число мест, 1321).
2. Поле поиска, подсказка «**Найти место: Хеврон, Вифлеем…**». Поиск `PlaceStore.search` на каждый знак (≥ 2 знаков), результат кэшируется по строке.
3. Найденные места строками от края до края: значок «метка» (акцент) и **название** (средней жирности); под ним серым (до 2 строк) «{тип} · {современное отождествление}» (пустые части пропускаются).
4. Нажатие на строку → окно закрывается, `openPlaceMap(место)` — карта во второй половине экрана (§4.1).
5. Запрос ≥ 2 знаков, ничего не найдено — «**Ничего не найдено.**» (мелко, серым).

### 5.2. Библейские карты (если есть модуль «Карты»)

- **Плитки** сеткой: число колонок = `floor((ширина + 10) / 230)`, от 1 до 6, промежуток 10. Плитка: картинка-миниатюра (отношение 4:3, обрезка по заполнению; пока не загрузилась — серый фон), под ней **название** (жирно, одна строка) и **описание** (одна строка, серым; у карты описание начинается с абзаца о содержимом — виден его первый абзац, обрезанный по ширине) либо, если описания нет, **название модуля**.
  Миниатюры скачиваются по мере показа (§1.3); ошибка загрузки миниатюры — просто серый фон.
- **Нажатие на плитку** → просмотр карты внутри окна: заголовок окна = название карты, подзаголовок = название модуля, появляется стрелка «назад» (возвращает к списку и сбрасывает масштаб).

### 5.3. Просмотр одной карты

Сверху вниз:
1. Рамка высотой 50 % высоты экрана с картинкой (вписана целиком, по центру). Пока грузится — значок крутилки. Ошибка — по центру «**Карта не загрузилась. Проверьте интернет.**». На загруженной картинке внизу справа значок «развернуть». **Нажатие на картинку** → полноэкранный просмотр (§5.4). В окне картинка сама не увеличивается (чтобы жесты листали окно).
2. **Описание карты** (весь текст, с источником и лицензией).
3. **Плашки стихов** (`refs`): каждая — `{Книга. гл:ст}` (по первому стиху; диапазон «Deut.8.7-9» показывается как «Втор. 8:7»); нераспознанные пропускаются. Нажатие → окно закрывается (`closeToReader`), **панель, из которой открыли «Карты»** (`pane`), идёт к стиху.

### 5.4. Полноэкранный просмотр (`openMapFull`)

Чёрный полупрозрачный фон (92 %), картинка вписана по центру; **щипок/колесо/перетаскивание** (`InteractiveViewer`, 1×…6×). Нижние вкладки на время просмотра скрыты. Закрывается **только кнопкой ✕** (нажатие на фон не закрывает).
Справа сверху три круглые кнопки на тёмном круге: «**Уменьшить**» (÷1,5), «**Увеличить**» (×1,5) — масштаб относительно **середины видимой части картинки** (не экрана и не угла); при возврате к 1× — снова вся картинка по центру; «**Закрыть**» (✕).

### 5.5. Пусто

Нет ни мест, ни карт (например, модуль карт установлен, но пуст): по центру значок «карта», жирно «**Карты не установлены**», «**Установите карты из каталога.**» и подчёркнутая ссылка «**Открыть библиотеку**» (если есть библиотека модулей; закрывает окно и открывает библиотеку).

## 7. Как окна и состояния связаны (карта)

```
выбор слова ─ «Название · Карта» ─► openPlaceMap(place) ─► mapPaneProvider = place ─► главный экран: слот [последняя панель → карта]
«Ещё → Карты» ─ поиск ─ строка места ─► закрыть окно ─► openPlaceMap
карта: ✕ ─► mapPaneProvider = null ─► вернуть панель чтения
       плашка стиха ─► panes.navigate(0, ref) (карта остаётся)
       «Только карта» ─► слои + карточка свёрнута и скрыта
       «Спутник/Обычная» ─► слои
«Ещё → Карты» ─ плитка ─► просмотр картинки ─► на весь экран (1–6×, −/+/✕)
                          └ плашка стиха ─► closeToReader + panes.navigate(pane, ref)
```

## Расхождения со Swift (что нет / что иначе)

Сравнено с `swift/AOBible/Views/MapsView.swift` (далее **MV**), `swift/AOBible/Core/Places.swift` (**PL**), `Views/WordViews.swift` (**WV**), `Views/MoreView.swift` (**MR**), `Core/Lexicon.swift` (**LX**).

### А. Данные
1. PL `placesIn`/`placesFor`/`searchPlaces` повторяют `PlaceStore`: запрос к `place_refs` по точной строке `Книга.глава.стих`, основы `stems` как **начало** слова, поиск по `name_norm LIKE`, `ORDER BY ord`, лимит 50 — **совпадает**. Нормализация (строчные, «ё»→«е») — `Lexicon.normalizeWord` (LX) — совпадает.
2. Отличия: `confidence` — PL считает `0` отсутствием (`r.int(5) > 0`); Flutter — отсутствует только `NULL` (в реальных данных нулей нет, различие не проявляется). Поиск: PL убирает `%` и `_` из запроса, Flutter экранирует их (`ESCAPE '\'`).
3. `MapImage` (PL) читает `refs`, но **MV их нигде не показывает** (§5.3). Путь картинки: PL берёт `Net.bases[0]` + путь — **без запасного зеркала** (Flutter: `download` пробует `aobible.app`, затем GitHub Pages).

### Б. Вход и размещение карты
4. **Нет панели-карты во второй половине экрана.** MV/WV открывают `PlaceDetail` как **экран внутри листа** (`NavigationLink`; из выбора слова WV ставит `detent = .medium`) или внутри окна «Карты». Нет `mapPaneProvider`, нет замены последней панели чтения, нет ✕ «Закрыть карту», нет «карта остаётся открытой, а плашка стиха ведёт первую панель».
5. Плашка стиха в `PlaceDetail`: `dismiss()` + `openVerse(...)` — окно закрывается и переходит чтение; во Flutter окон нет, карта остаётся (§4.7 п. 4).
6. Строка «Название · Карта» в WV есть и стоит над словарями — **совпадает** (значок, жирное имя, «·», «Карта»).
7. Пункт «Карты» в «Ещё» (MR) показывается **всегда** (во Flutter — по флагу `menu.maps` и когда установлен модуль `maps`); открывается `NavigationLink`, без подсветки вкладки «Ещё» [как у остальных пунктов, см. `01` §6].

### В. Карта и карточка (MV `PlaceDetail`)
8. Движок — **MapKit** (`Map` + `Marker`), фиксированная область 1,2° × 1,2° вокруг места, высота 280 pt вверху `List`. Нет: масштаба по типу места (§1.5), переключателя «Спутник / Обычная карта», режима «Только карта и точка», кнопок «+ −», подписи источников сверху (§4.6), загрузки «Загружаю карту…», точки с белой обводкой.
   Если MapKit остаётся, нужно хотя бы: масштаб по типу места (три уровня из §1.5: область — крупно, хребет/долина/река/водоём/пустыня — средне, остальное — город с окрестностями; соответствие уровням MapKit подобрать), переключатель вида карты (стандарт ↔ спутник), режим «Только карта и точка»; **строку лицензии места** сохранить (CC BY 4.0, OpenBible.info — п. 11). Подпись EOX/OpenFreeMap нужна только если подключить эти тайлы.
9. Карточка в Flutter — **плавающая и сворачиваемая** (раскрыта на iPad, свёрнута на iPhone), с заголовком «{Название} · {тип}»; в MV всё лежит в `List` ниже карты, секциями: «Что это» (тип), «Сейчас», «Уверенность отождествления N%» (Flutter: «Достоверность: N%» + полоска 5 pt), описание, «Где упомянуто», «{модуль} · {лицензия}».
10. «Где упомянуто» в MV — **все** стихи списком (Flutter: плашки, не более 40, «и ещё {n}»); подпись плашки `Сокр. гл:ст` с точкой от `Books.info.short` (Flutter — `formatRef`, тоже с точкой); нажатие — `dismiss + openVerse`.
11. Нет ссылки «**Спутник Google**» (`https://www.google.com/maps/@{lat},{lng},2000m/data=!3m1!1e3`) и строки лицензии по умолчанию «OpenBible.info, CC BY 4.0» (MV показывает `place.license`, пустой не подменяется).
12. Нет сдвига камеры, чтобы точка не пряталась под карточкой (§4.8) — карточки поверх карты нет.

### Г. Окно «Карты» (MV `MapsView`)
13. Структура другая: сегментный переключатель «**Места / Карты**» (`Picker`) + `searchable` с подсказкой «Название места». Во Flutter — **один список**: группа «Места · N» с полем «Найти место: Хеврон, Вифлеем…» и результатами, ниже — **плитки** карт с миниатюрами.
14. Строка найденного места в MV: имя + `modern` (мелко); Flutter: значок «метка», имя, второй строкой «{тип} · {современное}» (до 2 строк).
15. Плитки: в MV только **названия** (`NavigationLink` с `Text(m.title)`), нет миниатюр, описаний, сетки по ширине.
16. Просмотр карты (MV `MapImageView`): `ScrollView` + `MagnifyGesture` 1…6×, описание внизу (`lineLimit(5)`), **нет**: рамки в окне с переходом на весь экран, кнопок «Увеличить/Уменьшить/Закрыть» (÷1,5 / ×1,5 к центру видимой части), чёрного фона 92 %, скрытия нижних вкладок, текста ошибки «Карта не загрузилась. Проверьте интернет.» (используется `AsyncImage` с `ProgressView`, ошибки нет), **плашек стихов** из `refs` (§5.3), заголовка с подзаголовком-модулем.
17. Тексты пустых состояний другие: MV — «Установите модуль «Места»: «Ещё» → «Библиотека модулей».» / «Введите название места, например «Иерусалим» или «Вифлеем».» / «Установите модуль «Карты»: «Ещё» → «Библиотека модулей».»; нужно — «Карты не установлены» / «Установите карты из каталога.» + ссылка «Открыть библиотеку»; для пустого поиска — «Ничего не найдено.» (в MV нет).
18. Нет «Места · {N}» (число мест).

### Д. Что совпадает
Источник и формат данных мест (`places`, `place_refs`, `stems`, `refs`, `confidence`, `modern`, `description`), правило предложения «Карта» (место в списке упоминаний стиха + слово начинается с основы), поиск мест по названию с лимитом 50, чтение карт-картинок из `payload` модуля `maps`, масштаб картинки 1…6×.
