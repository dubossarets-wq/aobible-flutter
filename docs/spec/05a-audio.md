# 05a. Аудио (чтение вслух) — как работает Flutter-версия

Составлено по полному чтению: `lib/features/audio/{audio,audio_bar,audio_data,audio_download,audio_engine,audio_fab,audio_listen,audio_logic,audio_offline,audio_player,audio_settings}.dart`.
Чтобы связать окна, дополнительно читались места вызова: `lib/ui/home_screen.dart` (где стоит мини-проигрыватель), `lib/ui/reader_pane.dart` (кнопка «Слушать», стрелки глав),
`lib/core/panes.dart` (`navigate`, `livePositions`), `lib/features/shell/{more_sheet,prefs_sheet}.dart` (пункты «Ещё» и «Настройки → Аудио»), `lib/features/plans/ui_kit.dart` (уведомления),
`ios/Runner/Info.plist` (фоновый режим) и сами аудиомодули (`/public/modules/audio-*.json`, `catalog.json` веб-репозитория).
Дизайн (цвета, радиусы, тени) не нужен: только функциональность, расположение, значения, тексты.
**[уточнить]** — не видно из прочитанных файлов; смотреть другие файлы Flutter или телефон. **[Swift]** — коротко о расхождении; полный список — в последнем разделе.

Все видимые строки во Flutter проходят через `t('русский текст')`; ключ перевода — сама русская строка, подстановки — `{имя}`. Ниже все тексты даны по-русски.
Названия книг: `Books.formatRef` = «Ин. 3:16» (сокращённое имя из справочника языка интерфейса, глава, стих) — как в `03-bookmarks.md` §2; полное имя — `meta(book).name` («От Иоанна»).

## 0. Из чего состоит «Аудио»

| Часть | Где живёт | Что это |
|---|---|---|
| Кнопка «Слушать» (наушники) | внизу по центру каждой панели чтения | запуск с текущего места панели (§4) |
| Мини-проигрыватель | над нижними вкладками, во всю ширину экрана (до 640 pt, по центру) | ⏮ ▶/⏸ ⏭, место, скачивание книги, настройки, ✕ (§6–7) |

| Движок | синглтон `AudioEngine.I` | состояние, запись по главе, звучащий стих, таймер сна, фон и экран блокировки |

Входы «Слушать» (все ведут в один и тот же запуск, §5.1): кнопка-наушники на панели; «Ещё → Слушать с этого места»; панель выделения и строка под стихом («Слушать отсюда» / «Слушать»);
плашка «▶ Слушать отсюда» в мини-проигрывателе, когда человек ушёл от звучащего места (§6.3).
«Аудио» **нет в «Ещё»** (в коде пункт есть, но исключён: `notInMenu = {'mydata','audio'}`), оно только в **Настройки → «Аудио»** (строка с подписью «Книги без интернета»).
Пункт «Слушать с этого места» в «Ещё» показывается по флагу `menu.listen` (Настройки → «Меню «Ещё»», по умолчанию включён).

## 1. Данные

### 1.1. Аудиомодуль (тип `audio`)

Модуль — обычный `aob-module`, ставится из каталога (как остальные). Поля JSON:

- `id` (`audio-kjv-librivox`), `name` («Аудио KJV»), `title` («King James Version — LibriVox (чтец Michael Armenta)»), `description`, `language` (`en`; по умолчанию `ru`), `version`, `author`, `source`, `license`, `versification`;
- **`translation`** — id перевода Библии, к которому записи подходят (`kjv`, `rst`, `oshb`, `byz-rp2018`…). Может отсутствовать или быть пустым — тогда запись подходит к любому переводу;
- **`chapters`** — объект `"Книга.глава"` → запись главы. Ключ: OSIS-id книги, точка, номер главы (`Gen.1`, `John.3`, `1Chr.1`). Запись главы:
  - `url` — **полный** адрес файла (`https://archive.org/download/…/40Matthew01.mp3`), обязательное поле (запись без `url` отбрасывается);
  - `verses` — список пар `[номер стиха, секунда начала]`, по возрастанию секунд: `[[1,40.36],[2,47.0],[3,55.26]]` (секунды — дробные, от начала **файла**); пары с нечисловыми значениями пропускаются;
  - `start`, `end` — только когда **несколько глав лежат в одном файле** (KJV, BSB, Luther 1912): глава — кусок файла от `start` до `end` (секунды от начала файла). Если `end` есть, глава считается «общей» (`shared`);
  - `duration` — длина всего файла (в файле есть, **приложением не используется**; длину берёт из плеера).

В каталоге (по `catalog.json` на 08.11.2026) пять записей: `audio-kjv-librivox` (kjv, en, весь KJV одним чтецом, общие файлы), `audio-rst-nt-wwjd` и `audio-rst-ot-wwjd` (rst, ru, живые чтецы, по файлу на главу),
`audio-hbo-shmuelof` (oshb, he, иврит, Шмуэлоф), `audio-grc-phemister` (byz-rp2018, grc, НЗ по-гречески). Запись каталога с `unavailable` для автоустановки пропускается (§15).

На устройстве модуль лежит в SQLite-базе модуля: таблица `payload`, одна строка, колонка `json` — **весь JSON модуля**. Разбор — в отдельном потоке (у «Шмуэлоф» ≈ 3 МБ), результат кэшируется в памяти по id модуля; после переустановки кэш сбрасывается (`forgetPack`).

### 1.2. Какая запись подходит к переводу (`fitsTranslation`)

Запись (`translation`) подходит к переводу панели `bibleId`, если:
1. `translation` отсутствует или пусто, **или**
2. `translation == bibleId`, **или**
3. обе величины входят в набор `{rst, rst-plus, rst-dc}` (Синодальный с разметкой и без — один текст).

Других связей нет: **язык не сравнивается**, подбор по «похожему переводу» не делается.

`audioSourcesFor(moduleId, ref)` обходит все установленные аудиомодули (порядок — как в списке установленных модулей `ModuleStore.installed`) и для каждого, у кого есть запись `Книга.глава` этой главы, кладёт его
в `recorded` (подходит к переводу) или в `other` (глава есть, но для другого перевода). **`other` нигде не используется** — запуск и смена перевода работают только с `recorded`.

### 1.3. Выбор записи при запуске

`listenFrom(pane, moduleId, ref)`:
1. `recorded` = подходящие записи с этой главой.
2. Сохранённый выбор `audioSource` (prefs, JSON-строка с id модуля) — если он среди `recorded`, берётся он; иначе — **первый** из `recorded`.
   Нигде в интерфейсе Flutter `audioSource` не записывается (метод `setSource` есть в движке, но кнопки «выбрать чтеца» нет) — поэтому на практике выбирается первый подходящий модуль. Значение может прийти только из файла веб-версии. **[Swift]** есть своё меню «Чтец» (см. последний раздел, п. 2).
3. Нашёлся → запуск (§5.2). Не нашёлся → **сообщение «Для этой главы нет аудиозаписи.»** (§5.3).

### 1.4. Время стихов и «какой стих звучит»

- `startFor(verse)`: если `verse == 1` и у главы есть `start` → `start` (начало главы, чтобы прозвучало объявление «Глава …»); иначе — секунда начала этого стиха из `verses`;
  стиха нет в `verses` → `start ?? 0` (то есть запись прыгнет на начало главы/файла). Для главы в **отдельном файле** (без `start`) первый стих начинается с **своей** секунды из `verses` (объявление «Глава …» пропускается), если стих 1 есть в разметке.
- `verseAt(sec)`: берётся `t = sec + 0,05`; звучит **последний** стих, чья секунда начала ≤ `t`; если секунда раньше первого стиха — `null` (ссылка стиха не меняется).
- Длина главы и положение в ней (`span`): общая глава — начало `start`, длина `end − start`; отдельный файл — начало 0, длина = длина файла. Положение для ползунка и времени = секунда плеера − начало главы, ограничено 0…длина.
- Положение пишется в интерфейс не чаще раза в секунду (меняется целая секунда или длина).

### 1.5. Соседние стихи и главы

Источник — **текст перевода панели** (`loadBook(moduleId, book)`, только настоящие стихи), а не разметка записи. Порядок книг — `bookList(moduleId)`.
- `neighbourVerse(ref, ±1)`: следующий/предыдущий стих текущей главы; дальше — первый стих следующей главы/последний стих предыдущей, через границу книги (пустые главы и книги пропускаются, предохранитель 400 шагов). Нет дальше (до Бытия 1:1 / после последней главы) — `null`, ничего не происходит.
- `neighbourChapter(ref, ±1)`: **первый стих** соседней главы (через границу книги).
- Если **главы** звучащего стиха нет в тексте перевода — отсчёт идёт от ближайшей по номеру главы (в коде есть запасной поиск); если нет самого стиха внутри существующей главы — берётся ближайший больший/меньший номер.

### 1.6. Сохраняемое

| Ключ | Что | Формат |
|---|---|---|
| `audioRate` | скорость | prefs-строка с JSON-числом (`"1.25"`); по умолчанию 1 |
| `audioVolume` | громкость плеера | JSON-число 0…1; по умолчанию 1. Это громкость **внутри приложения**, не системная |
| `audioSource` | выбранный чтец | JSON-строка id модуля или `null`; в интерфейсе не меняется (§1.3) |
| `settings.audioFollowsTranslation` | «Озвучка — на языке перевода» | bool в объекте `settings`, по умолчанию **true** |
| `offlineAudio` | скачанные книги | JSON-объект (§10.2); служебный ключ, в файл «Мои данные» и резервные копии **не входит** |
| `autoAudioList` | аудиомодули, которые уже пробовали поставить сами | список строк (§15) |

Таймер сна, состояние «играет», позиция — **не сохраняются** (после перезапуска проигрывателя нет).

## 2. Состояние движка (`AudioState`) — что хранится, пока включено аудио

- `active` — аудио включено (мини-проигрыватель виден). `playing` — звук идёт (по желанию человека). `loading` — грузится запись/буферизация (на кнопке — крутилка).
- `pane`, `moduleId` — панель и **перевод, текст которого читается**; `ref` — звучащий стих (книга, глава, стих).
- `source` — id аудиомодуля; **`null` — записи нет** (показывается только сообщение).
- `rate` (0,75 / 1 / 1,25 / 1,5), `volume` (0…1), `sleep` (таймер сна: «N минут» с моментом окончания, либо «до конца главы» с книгой и главой), `error` (текст ошибки/сообщения), `follow` (текст идёт за чтецом, §12).
- `canExpand` = `active && ref != null && source != null` — раскрыть полноэкранный проигрыватель можно только когда есть запись.
- Позиция в записи (`TimeSnap{pos, len}`) — секунды **внутри главы** и длина главы; ведётся отдельно.

## 3. Где что находится

```
[ чтение: панель ]──────────────────────────────────────────────────
   ‹ (пред. глава)      ◎ «Слушать»  (скрыта, пока аудио включено)      › (след. глава)
──────────────────────────────────────────────────────────────────
[ «К плану · N из M» ]  (плашка планов, если читают вне плана)
[ ┌ мини-проигрыватель (капсула) ┐ ]   <- Hub.audioBar
[ нижние вкладки ]
```

Мини-проигрыватель стоит в `bottomNavigationBar` главного экрана **над** местом под вкладки; стрелки глав и кнопка «Слушать» в панелях стоят над ним (при раскрытии настроек проигрывателя опускаются вместе с его фоном).
Полноэкранный проигрыватель — отдельный маршрут (`PageRouteBuilder`, въезжает снизу 300 мс, уезжает 260 мс); нижние вкладки остаются поверх него, его кнопки — над ними; нажатие на вкладку закрывает проигрыватель [из комментария в коде].
Окно открывается один раз (флаг `_open`): повторные нажатия, пока оно открыто, ничего не делают.

## 4. Кнопка «Слушать» на панели (`ListenFab`)

- **Где:** внизу по центру панели чтения, над мини-проигрывателем и вкладками; слева и справа в том же ряду — круглые стрелки «Предыдущая глава» / «Следующая глава».
  Круг 44 pt, значок наушников. На iOS 26 при небольшом числе панелей (`panes ≤ glassMaxPanes`) — системная стеклянная кнопка с цветом акцента.
- **Когда видна:** только пока аудио **не** включено (в любой панели): `AudioEngine.state.active == false` → кнопка пропадает, как только аудио включилось, и возвращается после ✕.
- **Подпись:** подсказка «Слушать с {ref}» (`{ref}` — место этой панели сейчас, `livePositions[pane]`, иначе `panes[pane].ref`), для VoiceOver «Слушать с этого места: {ref}».
- **Нажатие** → `openAudioFrom(pane)`:
  1. если аудио уже включено в этой панели с записью и **стоит на паузе** — продолжить (`resume`); если уже играет — ничего;
  2. иначе — запуск с места панели (`livePositions[pane]` или `panes[pane].ref`), перевод — тот, что открыт в этой панели (`panes[pane].moduleId`).

## 5. Запуск и ход воспроизведения

### 5.1. Запуск (`listenFrom`)

Вызывается из всех входов с (панель, перевод, стих). Движок запоминает контейнер приложения, ищет запись (§1.3) и:
- есть запись → `start(pane, moduleId, ref, source)`;
- нет записи → `_showMessage` (§5.3).

### 5.2. `start`

1. Останавливает текущее воспроизведение (поколение `_gen++`, плеер на паузу).
2. Начинает следить за местом панели и сменой её перевода (§12, §5.8).
3. Состояние: `active=true`, `pane`, `moduleId`, `ref`, `source`, `error=null`, `playing=true`, `follow=true`; метка «человек листал» сбрасывается.
4. `_playFrom(ref)`.

### 5.3. Записи нет

`_showMessage`: плеер останавливается; состояние `active=true, playing=false, loading=false, source=null, ref=<запрошенный стих>, error="Для этой главы нет аудиозаписи.", follow=true`.
Что видно: **мини-проигрыватель появляется** (место = запрошенный стих, под ним сообщение), кнопка ▶ ничего не делает, ⏮/⏭ ничего не делают, скачивания нет, раскрыть нельзя, ✕ закрывает.
Тот же текст появляется и позже: если дошли до главы, которой нет в записи (§5.6).

### 5.4. `_playFrom(ref)`

1. **Таймер «До конца главы»:** если он стоит и `ref` в **другой** главе/книге, чем та, где его включили → таймер снимается, звук ставится на паузу, воспроизведение **не начинается**.
2. `ref` записывается в состояние. Нет записи (`source == null`) → `playing=false`, выход.
3. `_playRecorded(ref)`.

### 5.5. `_playRecorded(ref)` (загрузка и старт)

1. Берёт/создаёт плеер (`just_audio`), ставит громкость, подписывается на положение, состояние обработки и «играет»; один раз поднимает `audio_service` (§14).
2. Если загружена **не эта** глава (другой ключ `Книга.глава` или другой модуль): `loading=true`; читает аудиомодуль; нет записи главы → `loading=false, playing=false, error="Для этой главы нет аудиозаписи."`, выход.
3. Если файл главы ≠ уже загруженному: смотрит локальную копию (§10.3): **есть → `setFilePath`, нет → `setUrl(url)`**.
4. Запоминает «время» главы, обнуляет время (`0`), публикует название для экрана блокировки.
5. Ставит скорость `rate`, перематывает на `startFor(ref.verse)`, запускает звук, `loading=false`, `error=null`.
6. Устаревшие ожидания (поколение сменилось: человек уже нажал другое) молча бросаются.
Любая ошибка → `_fail` (§5.7).

### 5.6. Ход: звучащий стих, конец главы

- Положение плеера приходит часто; время обновляется раз в секунду. Звучащий стих = `verseAt(позиция)`; если он отличается от `ref.verse` → `ref` меняется (книга/глава остаются), что запускает подсветку и ведение текста (§12–13). Пока идёт загрузка/перемотка (`_switching`) стих не трогается.
- **Общий файл:** как только позиция ≥ `end − 0,05` — глава кончилась (`_chapterEnded`).
- **Отдельный файл:** конец файла (`completed`) → тоже `_chapterEnded`, но не чаще раза в 2 секунды после предыдущего перехода.
- `_chapterEnded`:
  1. следующий стих = первый стих следующей главы по тексту перевода; **нет** (конец Библии) → пауза;
  2. стоит «до конца главы» → таймер снимается, **пауза** (ссылка остаётся на последнем стихе главы);
  3. следующая глава в **том же файле и вплотную** (`start` в пределах 1 с от `end` текущей) → просто продолжаем без перемотки, время главы = 0, `ref` = её первый стих;
  4. иначе — `_playFrom(следующий стих)`: если у записи **нет** следующей главы (нет книги, разрыв) — переходит на неё, но показывает «Для этой главы нет аудиозаписи.» и звук стоит; закрытия аудио нет.

### 5.7. Ошибки сети (`_fail`)

Плеер не смог загрузить/играть → `loading=false, playing=false`, загруженная запись забывается. Проверка: поиск адреса `aobible.app` за 3 с:
- удалось → «**Запись не загрузилась. Проверьте интернет.**»;
- не удалось → «**Нет интернета. Чтобы слушать без сети, скачайте книгу заранее: Настройки → «Аудио».**»
Текст показывается в мини-проигрывателе (под местом) и красным в раскрытом. Снимается при следующем ▶ / новом стихе / новой записи.

### 5.8. Смена перевода панели во время чтения вслух (`_onModule`)

Работает, только если `settings.audioFollowsTranslation != false` и аудио включено с записью, а `moduleId` панели изменился.
- Запись подходит и к новому переводу → звук идёт дальше, меняется только `moduleId` (текст в раскрытом проигрывателе и подсветка — на новом переводе).
- Не подходит → ищется запись на языке нового перевода (`audioSource`, если подходит, иначе первая из `recorded`) **для текущей главы**; найдена → `start` с того же стиха (`ref`); если звук был на паузе — сразу ставится на паузу;
  не найдена → ничего не меняется (продолжает звучать прежняя запись, `moduleId` остаётся старым).

## 6. Мини-проигрыватель (`AudioBar`)

Показывается, пока `active`. Ширина до 640 pt по центру, поля 8 по бокам, 4 сверху, 8 снизу; форма — капсула.
Внутри сверху вниз: **подпись скачивания** (если есть, §10.4) → **панель настроек** (если раскрыта, §7) → **главный ряд**.

### 6.1. Главный ряд, слева направо

| Элемент | Подпись (VoiceOver) | Нажатие |
|---|---|---|
| ⏮ | «Предыдущий стих» | `stepVerse(-1)` |
| ▶ / ⏸ / крутилка (круглая, крупнее остальных) | «Пауза» (когда играет) / «Слушать» | играет → `pause`; иначе → `resume`. Крутилка вместо значка, пока `loading` |
| ⏭ | «Следующий стих» | `stepVerse(+1)` |
| Информация (занимает остаток ширины) | «{ref} — Открыть проигрыватель» | см. §6.2–6.3 |
| Стрелка вниз «скачать» | «Скачать {книга} для прослушивания без интернета» / «{книга} скачана…» | §10 (только когда есть запись `source`) |
| Ползунки-«настройки» | «Настройки чтения вслух» | раскрыть/свернуть панель §7; включённая подсвечена |
| ✕ | «Закрыть аудио» | `stop()` |

- **Нажатие на свободную часть ряда (кроме кнопок) и свайп вверх** (скорость вверх быстрее 250 px/с) → раскрыть полноэкранный проигрыватель — **только если** `canExpand` (есть запись). При сообщении «записи нет» не раскрывается.
- Тап по надписи места делает то же (ряд целиком — одна область нажатия).

### 6.2. Что в «информации»

- **Строка 1** — звучащее место `{Ин. 3:16}` (сокращённо, обычная форма `formatRef`; пока `ref == null` — пусто).
- **Строка 2** (серым, до 2 строк) — собирается так: если есть ошибка/сообщение — её текст; иначе части через « · »:
  «сон через {n} мин» (таймер на минуты; `n` — оставшиеся минуты, округлённо, не меньше 1; обновляется раз в 15 с) и/или «до конца главы» (таймер до конца главы). Нет ни ошибки, ни таймера — строки 2 нет.
  Строка 2 не показывается, пока текст «оторван» (§6.3).

### 6.3. Если человек ушёл от звучащего места (`follow == false`)

Строка 1 превращается в плашку **«↰ {Ин. 3:16}»** (подсказка «К звучащему месту»): нажатие → `resumeFollow(jump: true)` — текст возвращается к звучащему стиху и снова идёт за чтецом.
Под ней — плашка **«▶ Слушать отсюда · {Мф. 2:5}»** (место = то, что сейчас в панели, `livePositions[pane]`; подсказка «Слушать отсюда: {ref}»): нажатие → запуск с этого места (§5.1) в той же панели.
Подпись подбирается по ширине, берётся самая полная, что помещается целиком: «Слушать отсюда · {ref}» → «Слушать отсюда» → «Отсюда».
Эти плашки есть, только если у панели есть живое положение.

### 6.4. Шаги по стихам (`stepVerse`)

`resumeFollow()` (текст снова идёт за чтецом), затем `neighbourVerse(ref, ±1)` по тексту перевода (§1.5): нет → ничего; есть → плеер на паузу, `ref` = соседний, `playing=true`, `_playFrom(он)`.
Если соседний стих в этой же главе — перемотка внутри уже загруженной записи на `startFor(стих)`; если в другой главе — загрузка её записи (крутилка), для общего файла того же URL заново не грузится.
Нет «повторить текущий стих, если прошло больше N секунд» — ⏮ **всегда** идёт на предыдущий стих. На первом стихе главы ⏮ ведёт на **последний стих предыдущей главы** (через границу книги).
Стих, которого нет в разметке времени, начнётся с начала главы/файла (§1.4).

### 6.5. Закрытие (✕ / `stop`)

Останавливает звук, снимает таймер сна, перестаёт следить за панелью, освобождает плеер, обнуляет время, `active=false`, `ref=null`, `error=null`, `sleep=null`; экрану блокировки сообщается «ничего не играет».
Мини-проигрыватель исчезает, кнопка «Слушать» на панелях возвращается. Если раскрытый проигрыватель был открыт — он закрывается сам.

## 7. Панель настроек мини-проигрывателя

Раскрывается над главным рядом внутри капсулы (анимация 280 мс; стрелки глав в панелях едут вниз вместе с фоном). Две подписанные строки с сегментированными переключателями:

- **«Скорость»:** `0,75×` · `1×` · `1,25×` · `1,5×` (тексты: целое без дроби «1×», иначе «0.75×»/«1.25×»/«1.5×» — число как в Dart, с точкой). Выбор → `setRate`: сохраняет `audioRate`, меняет скорость плеера сразу, обновляет экран блокировки.
- **«Таймер сна»:** `Выкл` · `15 мин` · `30 мин` · `60 мин` · `Конец главы`. Выбор → `Выкл`: снять; `Конец главы`: `setSleepChapter`; число: `setSleepMinutes`.
  Если таймер поставлен колесом (§9) на другое число минут (45, 90…) — ни одна кнопка не отмечена.

## 8. Раскрытый проигрыватель (`AudioPlayerPage`)

Открывается из мини-проигрывателя (нажатие / свайп вверх). Закрывается: стрелка вниз; свайп вниз за шапку; ✕ (останавливает аудио); сам закрывается, если аудио остановили или записи нет.
Максимальная ширина контента — 560 pt по центру. Фон — градиент от цвета акцента к фону темы.

### 8.1. Шапка (область свайпа вниз)

- Ручка (горизонтальная полоска) сверху.
- Слева круглая кнопка **«⌄»** (VoiceOver «Свернуть проигрыватель») — закрыть экран.
- По центру: **название главы** — полное имя книги и номер главы («От Иоанна 3»); под ним мелко (до 2 строк): «**{название перевода} · {название записи}**» (имя установленного модуля перевода и `title` аудиомодуля, пустые части пропускаются).
- Справа пустое место того же размера (для симметрии).
- **Свайп вниз за шапку:** экран тянется за пальцем (до 600 pt); отпустили — закрывается, если сдвиг > 110 pt или скорость вниз > 700 px/с, иначе возвращается.

### 8.2. Стихи главы — «караоке» (центральная часть)

- Список **всех стихов текущей главы из текста перевода `moduleId`** (без разметки; заголовков нет). Каждая строка: маленький номер стиха цвета акцента (0,5 от размера) и текст жирным. Размер = ширина экрана × 0,056, в пределах 20,8…29,6 pt, межстрочный 1,3.
- Сверху и снизу область плавно «растворяется» (маска 0–15 % и 85–100 %); сверху и снизу в списке отступ 45 % высоты области, чтобы первый и последний стих можно было поставить по центру.
- **Звучащий стих** (по `ref.verse`) — чёткий, полной яркости; остальные — тем бледнее и размытее, чем дальше от него (расстояние `d` = |i − звучащий|, максимум 4):

  | d | 0 | 1 | 2 | 3 | 4 и дальше |
  |---|---|---|---|---|---|
  | непрозрачность | 1 | 0,5 | 0,32 | 0,22 | 0,15 |
  | размытие σ | 0 | 2 | 3 | 4 | 4,5 |

  Не звучащие строки слегка уменьшены (0,95 от левого края). Если звучащего стиха нет в списке (нет в тексте) — все строки с `d = 4`.
  Смена яркости — плавно 500 мс.
- **Ведение:** при смене звучащего стиха список плавно (450 мс) прокручивается так, что стих стоит на 40 % высоты области сверху; при первом открытии — без анимации.
- **Человек листает пальцем:** режим «вручную» — размытие снимается (звучащий 1, остальные 0,62, без уменьшения, смена 200 мс); автоведение выключено. Через **3,5 с** после последнего касания/прокрутки режим возвращается, и список плавно уезжает к звучащему стиху.
- **Нажатие на стих:** режим «вручную» сбрасывается; `playVerse(стих)` — запись идёт **с начала этого стиха** (в той же главе; звук включается, если был на паузе; ошибка снимается).
- Если у перевода нет текста этой главы — список пуст.

### 8.3. Нижняя часть (сверху вниз)

1. **Ошибка/сообщение** (красным, по центру) — если есть.
2. **Подпись скачивания** (по центру, без рамки) — если есть (§10.4).
3. **Перемотка:** ползунок 0…длина главы (пока длина неизвестна — неактивен); при перетаскивании значение меняется сразу, при отпускании `seekChapter(секунды)` — перемотка внутри главы (секунды от начала главы), звучащий стих пересчитывается. Под ним слева прошедшее «0:05», справа «−осталось» («−2:31»); формат `clock`: «м:сс», с часами «ч:мм:сс». VoiceOver: «Место в записи» / «{cur} из {total}».
4. **Управление** по центру, интервал 28 pt: ⏮ (предыдущий стих, значок 38, зона 60×60) · **большая кнопка ▶/⏸/крутилка 78 pt** · ⏭ (следующий стих).
5. **Громкость:** значок тихого динамика — ползунок 0…1 — значок громкого. Меняет `audioVolume` сразу и сохраняет при каждом движении. VoiceOver «Громкость», значение «{n}%».
6. **Ряд «чипов»** (разведены по краям, интервал 8):
   - чип **скорости** с текстом «1×» — нажатие **переключает по кругу** 0,75× → 1× → 1,25× → 1,5× → 0,75× (VoiceOver «Скорость: 1×»);
   - чип **таймера сна** со значком луны (когда таймер включён — ещё и текст «15 мин»/«Конец главы», чип подсвечен; VoiceOver «Таймер сна: Выкл») — нажатие открывает окно таймера (§9);
   - кнопка **скачивания** книги (если есть `source`) (§10);
   - **✕** (VoiceOver «Закрыть аудио») — `stop()`.
- Расстояния между рядами 10 pt (14 при высоте окна ≥ 760). Нижний отступ: если есть нижние вкладки — над ними (высота вкладок + 6), иначе `max(22, нижний отступ экрана − 8)`.

### 8.4. Что нажатия делают с воспроизведением

| Действие | Результат |
|---|---|
| ▶/⏸ | пауза/продолжение (как в §6.1) |
| ⏮ ⏭ | `stepVerse(∓1)`, §6.4 |
| Нажатие на стих | `playVerse`, §8.2 |
| Перетащить ползунок | `seekChapter` |
| Громкость | `setVolume` |
| Чип скорости | `setRate(следующая)` |
| Чип таймера | окно §9 |
| ⌄ / свайп вниз | свернуть (звук продолжает идти; мини-проигрыватель остаётся) |
| ✕ | остановить и закрыть всё |

## 9. Таймер сна

### 9.1. Окно таймера (из чипа в раскрытом проигрывателе)

Нижний лист шириной до 560 pt, без шапки и крестика (закрывается смахиванием/нажатием вне листа). Сверху вниз:
1. **Лента минут** — горизонтальная прокрутка от 0 до 120 минут, шаг 12 pt на минуту. Метка каждой минуты; каждая пятая — ярче и с числом сверху. Посередине внизу — треугольный указатель. Начальная позиция: текущие минуты таймера, иначе **15**.
   При прокрутке текущее значение = ближайшая минута к указателю; каждый переход на новую минуту — лёгкая вибрация (`selectionClick`); остановили — лента доезжает до целой минуты (200 мс). Нажатие на метку подводит её под указатель. VoiceOver: «Таймер сна», значение «{n} мин».
2. Ряд: слева кнопка **«Запустить таймер»** (при значении 0 — приглушена и не нажимается), справа **большое время** `М:00` или `Ч:ММ:00` (`fmtMin`: 15 → «15:00», 90 → «1:30:00»).
   Нажатие «Запустить таймер» → `setSleepMinutes(минуты)`, лист закрывается.
3. Ряд пилюль (слева, с переносом): **«До конца главы»** → `setSleepChapter`, лист закрывается; **«Выключить таймер»** (только если таймер включён) → `clearSleep`, лист закрывается.

### 9.2. Правила движка

- `setSleepMinutes(m)`: старый таймер отменяется; `m` пусто или ≤ 0 → таймер выключен; иначе запускается таймер на `m` минут и записывается «до какого момента»; по срабатыванию — **пауза** и таймер снимается. Звук на паузе не снимает таймер (сработает и поставит паузу ещё раз).
- `setSleepChapter()`: записывается книга и глава **текущего звучащего стиха**. Срабатывает двумя путями: когда глава заканчивается (§5.6 п. 2) и когда человек шагом/нажатием на стих уходит в другую главу (§5.4 п. 1). В обоих случаях таймер снимается и ставится пауза.
- Таймер снимается при `stop()`; при смене записи (`start`) — **не** снимается (кроме самого срабатывания).
- Показ: в мини-проигрывателе «сон через {n} мин» / «до конца главы» (§6.2); в мини-панели выбран сегмент (§7); в раскрытом — чип (§8.3).

## 10. Скачивание книги (аудио без интернета)

### 10.1. Что скачивается

Скачивается **книга** (`book` = книга звучащего стиха) **записи, которая сейчас выбрана** (`source`): все файлы глав этой книги без повторов (`urlsOf(book)`; на несколько глав бывает один файл — общий скачивается один раз).

### 10.2. Формат `offlineAudio` (prefs)

Одна JSON-строка: объект, ключ — `{id аудиомодуля}|{id книги}` (вертикальная черта), значение — `{at, files, bytes}`:
`{"audio-rst-nt-wwjd|John": {"at": 1761500000000, "files": 21, "bytes": 52428800}}` — `at` время окончания (мс Unix), `files` число файлов (`urlsOf`), `bytes` общий размер.
Запись добавляется **только после успешной загрузки всех файлов книги**. «Книга скачана» (`isBookOffline`) = **есть запись в `offlineAudio`** (наличие файлов не проверяется). Ключ **не входит** в «Мои данные» и в резервные копии.

### 10.3. Где лежат файлы и как проигрыватель их находит

- Папка: `Application Support/audio/`. Имя файла по адресу `url` (одно и то же при каждом запуске): хэш FNV-1a с двумя накопителями —
  `h1 = 0x811c9dc5`, `h2 = 0x01234567`; для каждого байта `b` UTF-8 адреса: `h1 = ((h1 ^ b) * 0x01000193) & 0xffffffff`, `h2 = (((h2 + b) * 0x2f0b4a27) ^ (h2 >> 7)) & 0xffffffff`;
  имя = `hex(h1)` + `hex(h2)` (шестнадцатеричные без ведущих нулей, строчные) + расширение: `m4a`, если в адресе (в нижнем регистре) есть «.m4a», иначе `ogg`, если «.ogg», иначе `mp3`.
- Проигрыватель перед загрузкой главы ищет файл с таким именем и размером > 0: **нашёл — играет из него** (независимо от записи в `offlineAudio`), нет — из сети.

### 10.4. Кнопка и подпись

**Кнопка** (в мини-проигрывателе рядом с «настройками», в раскрытом — в ряду чипов; одно состояние на обе):
- не скачана: значок «стрелка вниз»; подсказка «Скачать книгу»; VoiceOver «Скачать {книга} для прослушивания без интернета»;
- качается: вокруг значка кольцо прогресса (доля = готовых файлов / всех), значок меньше;
- скачана: зелёная галочка-кружок; подсказка «Скачано»; VoiceOver «{книга} скачана для прослушивания без интернета».

**Нажатие:**
1. Идёт другая загрузка — игнорируется (одновременно качается только одна книга).
2. Книга скачана → показывается **подпись** «**«{Книга}» в телефоне — слушайте без интернета**» (зелёным) со ссылками «**удалить**» (удаляет книгу, подпись пропадает) и «**скрыть**».
3. Иначе — загрузка. Подпись: «Скачиваю «{Книга}»…» → по ходу «**Скачиваю «{Книга}»: {done} из {total} · {size}**» (размер вида «3.4 МБ»: `байты / 1 048 576`, один знак после **точки** (Dart `toStringAsFixed`) до 10 МБ, дальше без дроби; запятая не подставляется) →
   по окончании зелёным «**«{Книга}» скачана ({size})**». Ошибка — текст ошибки (серым), без зелёного.

Подпись (`DownloadNote`) стоит: в мини-проигрывателе — **самой верхней строкой капсулы** (с линией снизу); в раскрытом — над ползунком перемотки, по центру. Обе показывают одну и ту же подпись; ссылка «скрыть» убирает её.
Кнопки «остановить» в интерфейсе **нет** (флаг отмены в коде есть, но вызвать его нечем).

### 10.5. Как идёт загрузка (`downloadBook`)

Книга без файлов → ошибка «К этой книге нет аудиозаписей.». Файлы идут **по одному, подряд**. Файл уже лежит (размер > 0) — пропускается (но учитывается в размере). Иначе GET с повторной попыткой не делается;
код ≠ 200 → «**Запись не скачалась (ошибка {status}). Проверьте интернет.**»; обрыв сети (`SocketException`) — тот же текст со статусом 0. Загружается во временный файл `имя.part`, по окончании переименовывается;
при ошибке/остановке `.part` удаляется. Уже скачанные файлы остаются (повторное нажатие докачает с нужного). Соединение: тайм-аут подключения 20 с, свой User-Agent.

### 10.6. Удаление (`removeBook`)

## 12. Текст идёт за чтецом (`follow`)

- Пока `follow == true`, на **каждую смену звучащего стиха** движок переводит панель к нему: `panesProvider.navigate(pane, ref)` — **тот же переход, что «Перейти»** (с миганием стиха и записью в историю панели) [уточнить на телефоне: заметно ли мигание на каждом стихе и растёт ли история переходов].
  Метка «это наш переход» (`_ownNavAt`) держится 1,5 с.
- Если положение панели изменилось **не по нашему переходу** (человек листает, нажал «Перейти»…) и с нашего перехода прошло больше 1,5 с → `follow = false`, запоминается момент.
  С этого момента: в мини-проигрывателе вместо места — плашки «↰ …» и «▶ Слушать отсюда» (§6.3); подпись (строка 2) скрыта; текст за чтецом не идёт.
- **Само возвращается:** при следующей смене звучащего стиха, если человек не листал уже **≥ 4 с**, `follow = true` и текст переводится к стиху. Пока листает — не возвращается.
- Явно возвращает: плашка «↰ {место}» (с прыжком), а также любое управление — ⏮, ⏭, нажатие на стих в раскрытом, перемотка, шаг по главе (они вызывают `resumeFollow()` без прыжка, а следом идёт смена стиха → текст едет сам).
- Следят за **той панелью, где включено аудио**; запуск в другой панели переключает наблюдение.
- Свайп, листание главы стрелками и т. п. в панели — тоже «человек листает».

## 13. Подсветка звучащего стиха в чтении

В панели, где включено аудио, у стиха `ref` (книга, глава, стих) появляется фон цвета акцента **16 %**, если `moduleId` панели = `moduleId` аудио. Условия: аудио `active`, `ref != null`, та же панель (`pane`), тот же перевод, та же книга/глава/стих.
Перерисовка запускается при смене `active`, `pane`, `ref`. В режиме «Как книга» подсветка тоже действует (она — фон, а не значок) [уточнить на телефоне].

## 14. Фон, экран блокировки, прерывания

- `Info.plist`: `UIBackgroundModes = audio` — звук не прерывается при блокировке и сворачивании.
- Экран блокировки/Пункт управления (через `audio_service`, обработчик `AoAudioHandler`):
  - **Название** (`MediaItem`): `title` = «{Полное имя книги} {глава}» (например «От Иоанна 3» — **без номера стиха**), `album` = `title` аудиомодуля, `artist` = имя модуля перевода (откуда читается текст), `duration` = длина главы (если известна). `id` = «{модуль}|{Книга}.{глава}». Название обновляется при смене главы.
  - **Кнопки** (в коде): предыдущая глава · ▶/⏸ · следующая глава · стоп; системные действия: перемотка (`seek`), следующая, предыдущая. [уточнить на устройстве: на экране блокировки iOS «стоп» обычно не показывается]
    - ▶ → `resume`; ⏸ → `pause`; ⏹ → `stop` (закрывает аудио);
    - «следующая» → `stepChapter(+1)` (первый стих следующей главы);
    - «предыдущая» → `stepChapter(−1)`: если в главе уже **больше 4 с** — в начало этой главы (первый стих), иначе — первый стих предыдущей главы;
    - перемотка → `seekChapter(секунды)` — положение **внутри главы**.
  - Состояние (`PlaybackState`) обновляется при смене «играет/грузится», главы, скорости: положение (округлённая секунда), скорость, «загружается/готово».
- **Прерывания** (звонок, другое приложение остановило звук): если плеер перестал играть, а человек не ставил паузу и не идёт загрузка → состояние `playing=false` (кнопка показывает «Слушать»). Возобновление — вручную.
- Плеер освобождается при `stop()` (декодер и потоки не держатся без дела); создаётся заново при следующем запуске.
- Категория звуковой сессии iOS задаётся пакетами `just_audio`/`audio_service` по умолчанию **[уточнить]**.

## 15. Автоустановка записей (`autoInstallAudio`, после старта)

При запуске (если есть сеть; нет сети — молча выходит и пробует в следующий раз): каталог читается, для каждой записи каталога типа `audio` без флага `unavailable`:
1. Уже установлена и `meta.catalogVersion != version` каталога → переустанавливается (кэш забывается).
2. Не установлена: пропускается, если id уже в `autoAudioList` (пробовали — не ставим заново удалённое человеком) или **ни один установленный перевод Библии не подходит** (`fitsTranslation(translation, id перевода)` для всех установленных переводов).
3. Иначе id **сразу** добавляется в `autoAudioList` (сохраняется), запись ставится; ошибка установки — id убирается из списка (попробует в следующий раз).
Аудиомодули маленькие, ставятся сами; пользователь не видит запроса.
Отдельно при старте удаляется папка `narrator` (голос прежнего «ИИ-диктора») — к Swift не относится.

## Расхождения со Swift (что нет / что иначе)

Сравнено с `swift/AOBible/Core/AudioEngine.swift` (далее **AE**), `swift/AOBible/Views/AudioViews.swift` (**AV**), `Views/ReaderView.swift` (**RV**), `Views/MoreView.swift` (**MV**), `Core/Starter.swift` (**ST**), `RootView.swift` (**RT**).

### А. Выбор записи и ошибки
1. AE `listen`: `fits.first ?? other.first` — при отсутствии записи для перевода играет **запись другого перевода/языка**; Flutter в этом случае показывает «Для этой главы нет аудиозаписи.» (§1.3). Для главы без записи совсем AE показывает **alert «Аудио»** с текстом «К этой главе нет аудиозаписи. Установите записи: «Ещё» → «Аудио».» (RV `.alert`), а не мини-проигрыватель с сообщением; `active` остаётся `false` — мини-проигрывателя нет.
2. Нет сохранённого выбора `audioSource` (читается/пишется Flutter-версией только теоретически). В AV есть меню «**Чтец**» (список записей этой главы) и «**Текст**» (выбор перевода, из которого берутся слова) — **этого нет во Flutter** (там текст = перевод панели, чтец = первый подходящий). Можно оставить как расширение.
3. Нет сообщений об ошибках сети («Запись не загрузилась…», «Нет интернета…»): AE при сбое просто не играет, `error`/`message` не ставятся.
4. Нет переключателя «Озвучка — на языке перевода» в движке: AV создаёт `@AppStorage("audioFollowsTranslation")` и показывает «Запись на языке перевода» (другой текст), но AE **его не читает**, смены перевода во время чтения вслух не отслеживает (§5.8). Ключ хранится в `UserDefaults`, а не в `settings` (JSON).
5. AE не сохраняет `audioRate`, `audioVolume`; скорость после перезапуска снова 1×.

### Б. Ход воспроизведения
6. AE `previousVerse`: если от начала стиха прошло > 2 с — **повтор текущего стиха**; Flutter — всегда предыдущий стих (§6.4). Соседние стихи AE берёт из **разметки записи** (`ch.verses`), Flutter — из **текста перевода** (стихи без разметки времени тоже учитываются).
7. AE `nextChapter`: нет следующей главы в записи → `stop()` (закрывает аудио). Flutter: переходит на главу без записи и показывает «Для этой главы нет аудиозаписи.»; нет следующей главы вообще — **пауза**, не закрытие (§5.6).
8. AE строит новый `AVPlayer` на каждое `play(...)`; шаги внутри одного файла и подряд идущие главы общего файла перематывают заново/перегружают. Flutter при шаге внутри главы просто перематывает, при общем файле «вплотную» продолжает без перемотки (§5.6 п. 3).
9. **Ползунок и время** в AV показывают положение в **файле** (`position = sec` плеера, `duration` = длина файла). Для общих файлов (KJV, BSB, Luther) это неверно: нужно «секунды внутри главы» и «длина главы» (`end − start`), §1.4. Ползунок перемотки при общем файле у AE перемотает в чужое место файла.
10. AE `tick` вызывает конец главы при `sec >= end` (Flutter: `end − 0,05`) — совпадает по смыслу; нет защиты от двойного срабатывания (`_advancing`, 2 с) и нет обработки `completed` отдельным путём.
11. **Прерывания** (звонок и т. п.): AE не слушает `AVAudioSession.interruptionNotification` — после звонка `playing` может остаться `true`, а звук стоять. Flutter переводит кнопку в «Слушать» (§14).
12. Таймер сна: AE — только минуты 15/30/45/60 (в мини-меню и в «списке»), счёт секундами (`sleepLeft`), показ «· сон m:ss»; Flutter — Выкл/15/30/60/«Конец главы» в панели + лента 0–120 минут с «Запустить таймер» + «До конца главы» + «Выключить таймер», показ «сон через {n} мин» / «до конца главы» (§7, §9). **Нет «до конца главы».**
13. Скорости AE: 0,75 / 1 / 1,25 / 1,5 / **2**; Flutter — без 2× (§7). В раскрытом Flutter чип скорости переключает по кругу, AE — меню.

### В. Экран блокировки
14. AE: кнопки next/previous = **стих**, `nowPlayingInfo`: `title` = «Книга гл:стих», `artist` = `pack.title`; нет `stop`, нет перемотки (`changePlaybackPositionCommand`), нет `duration`, позиция обновляется только при смене стиха/паузе. Flutter: next/previous = **глава** («назад» после 4 с — в начало главы), `title` = «Книга гл», `album` = `title` записи, `artist` = имя перевода, есть стоп, перемотка, длина главы (§14).
15. AE: `setCategory(.playback, mode: .spokenAudio)` — осознанный выбор; Flutter — по умолчанию пакетов [уточнить]. `UIBackgroundModes = audio` в Swift-проекте есть (`swift/project.yml`, строка 63) — совпадает.

### Г. Чтение: ведение текста, подсветка, кнопка
16. **Нет ведения текста за чтецом** и всего, что с ним связано (§12): `follow`, переход панели к звучащему стиху, плашки «↰ место» и «▶ Слушать отсюда» в мини-проигрывателе, самовозврат через 4 с. AE не знает о панелях (кроме `moduleId`).
17. Подсветка звучащего стиха (RV `background`) есть, но условие — только `moduleId` и книга/глава/стих; Flutter дополнительно требует **ту же панель** (`pane`). При двух панелях с одним переводом подсветятся обе.
18. Кнопка-наушники (RV `safeAreaInset`) показывается **всегда** (в Flutter скрыта, пока аудио включено) и каждый раз вызывает `audio.listen` заново (в Flutter при паузе в той же панели — `resume`, при игре — ничего) (§4). Подпись/подсказка «Слушать с {ref}» отсутствует.
19. «Аудио» стоит в **«Ещё»** (MV), хотя во Flutter только в «Настройках»; пункт «Слушать с этого места» в MV показывается всегда (во Flutter — по флагу `menu.listen`).
20. Мини-проигрыватель — `tabViewBottomAccessory` (системная нижняя панель iOS 26), что допустимо; но его состав другой: в AV нет кнопок «скачать книгу», «настройки» (панели «Скорость»/«Таймер сна» заменены меню `ellipsis.circle`) и отдельной ✕ («Закрыть проигрыватель» внутри меню), нет подписи скачивания, нет строки ошибки; строка 2 = `pack.name` + « · сон m:ss» (Flutter: ошибка или «сон через {n} мин»/«до конца главы»). Нет «свайп вверх — раскрыть» (раскрывается только нажатием).

### Д. Раскрытый проигрыватель
21. Шапка AV: обложка-иллюстрация (книга и номер главы), «Книга гл:стих», `pack.title`, звезда (любимый стих), меню «К тексту» / «Закрыть проигрыватель»; Flutter: ручка, «⌄», «Книга глава» и «перевод · запись», **без обложки, без звезды, без меню** (§8.1). Режим «без слов» (обложка вместо стихов) и AirPlay-кнопка, список скорости/таймера — расширения Swift; во Flutter их нет.
22. «Караоке» AV: звучащий 1, остальные 0,38 и размытие 2,5 — **одинаково для всех**; нет градации по расстоянию (1 / 0,5 / 0,32 / 0,22 / 0,15 и σ 0 / 2 / 3 / 4 / 4,5), нет уменьшения, нет номеров стихов в строках, фиксированный размер 31 (Flutter: ширина × 0,056 в пределах 20,8–29,6), центрирование по центру (Flutter: 40 % сверху).
    **Нет режима «вручную»:** AV при любой смене стиха снова прокручивает к звучащему (даже если человек листает); Flutter при ручной прокрутке снимает размытие и 3,5 с не мешает (§8.2).
23. Нет подписи скачивания и кнопки скачивания в раскрытом проигрывателе; нет красного текста ошибки.
24. Громкость: AV — системный `MPVolumeView`; Flutter — собственный ползунок (`audioVolume`, громкость плеера). Для iOS системная громкость допустима; тогда `audioVolume` игнорируется.
25. Время `clock` в AV: «м:сс» без часов (для записей > 60 мин даёт «65:03»); Flutter: «ч:мм:сс».
26. AV не закрывается сам, если аудио остановили извне (показывается «Ничего не звучит»); Flutter закрывает экран.

### Е. Скачивание и окно «Аудио»
27. AE `OfflineAudio`: не пишет `offlineAudio` в prefs; «скачана» = **все файлы книги лежат на диске** (`isBookOffline`); размеры считаются по файлам. Следствия: книга, скачанная Flutter-версией, определяется по файлам (имена совпадают — FNV-1a, §10.3; при том же контейнере приложения), но **список «Скачано {n} кн. · {size} МБ» из §11 строится иначе**.
28. AE `remove` удаляет **все** файлы книги, не проверяя, нужны ли они другой скачанной книге (общие файлы KJV могут пересекаться по книгам) (§10.6).
29. AE качает через `URLSession.download` во временное место и переносит; `.part`, повтор, тайм-аут 20 с и User-Agent не заданы; при ошибке исключение проглатывается (`catch` без сообщения), прогресс просто исчезает. Нет текстов «Запись не скачалась (ошибка {status}). Проверьте интернет.» и «К этой книге нет аудиозаписей.».
30. Окно «Аудио» (AV `AudioSettingsView`) — другое: **список всех книг всех установленных записей** с кнопками «скачать» / «удалить» (корзина без подтверждения «Удалить/Отмена») и прогрессом с кнопкой остановки; нет строки «Скачано {n} кн. · {size} МБ», нет «{модуль} · {N} МБ», нет уведомления «Удалено из телефона: {book}», пустое состояние другое: «Записей пока нет. Установите их: «Ещё» → «Библиотека модулей» → «Аудио».»
    Для Flutter-поведения: скачивание — из проигрывателя, окно — только список скачанного (§11). Допустимо оставить Swift-вариант как расширение, но тексты §11 нужны для скачанных.
31. Название переключателя в AV: «Запись на языке перевода» + footer «Поменяли перевод во время чтения вслух — запись подбирается на его языке.»; Flutter: «Озвучка — на языке перевода» + «Сменили перевод во время чтения вслух — запись переключится на его язык (если такая запись есть)».

### Ж. Автоустановка
32. ST ставит недостающие записи к установленным переводам по `autoAudioList` и пропускает `unavailable` — как Flutter (§15); **нет обновления уже установленных** при смене версии каталога (Flutter: переустановка + сброс кэша разобранного модуля, `forgetPack`).

### З. Что совпадает
`AudioChapter.startFor` / `verseAt` (запас 0,05 с) / `shared`; разбор модуля (`url`, `verses`, `start`, `end`); `audioFits` = `fitsTranslation`; имена файлов (FNV-1a, расширения); папка `audio/`; подсветка звучащего стиха 16 %; скорость 0,75–1,5; тапом по стиху в «караоке» запись идёт с него; минимум: пауза/продолжение, ⏮/⏭ по стихам, закрытие.
