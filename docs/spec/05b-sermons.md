# 05b. Проповеди — как работает Flutter-версия

Составлено по полному чтению: `lib/features/sermons/{screen_on,sermon_add,sermon_pdf,sermon_store,sermons,sermons_sheet}.dart`.
Чтобы связать окна, дополнительно читались: `lib/features/plans/{ui_kit,loc}.dart` (уведомления «Отменить», `showPage`, `ConfirmIcon`, даты, склонение), `lib/features/shell/more_sheet.dart` (пункт в «Ещё»),
`lib/ui/home_screen.dart` (`Hub.underBar`), `lib/ui/ios_style.dart` (`IosSwipe`), `lib/ui/kit.dart` (`showAobSheet`, `closeToReader`), `android/.../MainActivity.kt` и `ios/Runner` (экран «не гаснет»),
а также `docs/spec/03-bookmarks.md` §15 (вход «В проповедь» из выделения — **здесь не повторяется**, только уточняется).
Дизайн не нужен: только функциональность, расположение, значения, тексты. **[уточнить]** — не видно из прочитанных файлов. **[Swift]** — коротко о расхождении; полный список — в последнем разделе.

Все видимые строки во Flutter проходят через `t('русский текст')`; ключ перевода — сама русская строка, подстановки — `{имя}`.

## 0. Из чего состоит «Проповеди»

| Часть | Что это |
|---|---|
| Список проповедей | поиск, сортировка, серии, смахивание для удаления, «Создать» (§3) |
| Редактор | название, подзаголовок, серия, блоки (стих / текст / заметка), перестановка, переводы у стиха, «Часть стиха», «Отменить/Повторить», размер текста (§4) |
| «Добавить стих» | поиск слов/ссылки по Библии, добавление в нужное место проповеди (§5) |
| «Добавить в проповедь» | окно из чтения: выбрать проповедь или создать; экран «Добавлено» (`03` §15, здесь §6) |
| Значок «стих есть в проповеди» | в тексте чтения у стиха; нажатие открывает проповедь (§9) |
| «Вернуться к проповеди» | полоса под верхним меню после перехода из проповеди в Библию (§9) |
| «Кафедра» | крупный текст для чтения на служении (§10) |
| «Поделиться» и «Печать и PDF» | текст и PDF-страница проповеди (§11) |

Входы: «Ещё → **Проповеди**» (порядок 20, по флагу `menu.sermons`, по умолчанию включён) — открывается **страницей** (на всю высоту, вкладка «Ещё» подсвечена);
выделение стихов → «⋯» или строка под стихом → «В проповедь» (окно 70 % высоты); «Часть стиха» → «В проповедь»; значок у стиха; полоса «Вернуться к проповеди»; экран «Добавлено» → «Открыть проповедь».

## 1. Данные

### 1.1. Хранилище

Ключ prefs **`sermons`** — одна JSON-строка: **список** объектов-проповедей. Формат **тот же, что в веб-версии**; записи хранятся как `Map` — **неизвестные поля сохраняются как есть**.
Любое изменение записывает **весь список** заново. Повреждённый/отсутствующий JSON → пустой список. В «Мои данные» ключ входит (`03` §12).
Порядок списка в хранилище = порядок создания «новые сверху» (создание и копия вставляются **в начало**; правка порядок не меняет).

Другие ключи этой области:

| Ключ | Что | Формат |
|---|---|---|
| `sermonSort` | сортировка списка | prefs-строка с JSON-строкой: `"recent"` или `"alpha"` (с кавычками!); читается как `== '"alpha"'`, иное — «недавние» |
| `sermonZoom` | размер текста в редакторе | **число (double)** 0,8…1,6, шаг 0,1, по умолчанию 1; пишется через `setDouble` (не JSON-строка) |
| `pulpitSize` | размер текста «Кафедры» | prefs-строка с JSON-числом (`"26"`), 18…60, по умолчанию 26 |
| `searchScope`, `searchWhole` | область и «целые слова» в «Добавить стих» | JSON-строки (`"all"`/`"OT"`/`"NT"`/`"book"`; `true`/`false`), **общие с основным поиском** |

### 1.2. Проповедь

```json
{ "id": "m3k1x2a00", "title": "Благодать", "subtitle": "…", "series": "Послание к Римлянам", "date": "2026-10-15",
  "blocks": [ … ], "altDefault": [ {"m":"kjv","n":"KJV"} ], "createdAt": 1760000000000, "updatedAt": 1760000500000 }
```

- `id` — время создания в мс в системе по основанию 36 + счётчик по основанию 36 из ≥ 2 знаков (`newId`; для блоков тот же генератор).
- `title` — название; при создании пустое/пробелы заменяется на «**Новая проповедь**»; в редакторе его можно стереть до пустого.
- `subtitle` — подзаголовок/описание (необязательно, многострочный). `series` — серия (необязательно).
- `date` — строка `ГГГГ-ММ-ДД` (разбирается `DateTime.tryParse`); при создании — **пустая строка `''`**. **В интерфейсе Flutter поля даты нет** (метод `setDate` нигде не вызывается): дата может прийти только из веб-версии/файла. Если она есть — показывается в списке, «Кафедре», «Поделиться» и PDF.
- `createdAt`, `updatedAt` — мс Unix. `updatedAt` обновляется при каждой правке человека (§1.8); **автозаполнение** (разбивка диапазона по стихам, тексты переводов) его **не** меняет.
- `altDefault` — список `{m: id перевода, n: название}`: переводы, которые сами подключаются к новым стихам этой проповеди (§8). Может отсутствовать.

### 1.3. Блоки (`blocks`, порядок в массиве = порядок в проповеди)

| `type` | Поля | Что это |
|---|---|---|
| `verse` | `id`, `book`, `chapter`, `verse`, `to`, `text`, `texts?`, `moduleId`, `part?`, `alt?` | стих или несколько стихов подряд (одной главы) |
| `text` | `id`, `text` | свой текст: абзацы, **жирный**, *курсив* |
| `note` | `id`, `text` | «заметка для себя»: в «Поделиться» не уходит, в PDF и «Кафедру» уходит (§11, §10) |

Поля `verse`-блока:
- `book` (OSIS-id), `chapter`, `verse` — первый стих; **`to`** — последний стих диапазона либо `null` (один стих). Диапазон — только стихи **подряд и одной главы**.
- **`text`** — текст стиха/стихов в том виде, как был на момент добавления (**снимок**: при смене перевода не меняется). Для диапазона — все стихи **одной строкой через пробел** (чтобы читали и старые версии).
- **`texts`** — тот же текст **по стихам**: список строк длиной `to − verse + 1`; есть у диапазона (у одиночного стиха нет). Нужен, чтобы показать каждый стих с нового абзаца и убрать любой из середины. Если длина не совпала — блок считается «без разбивки» и показывается одним абзацем.
- **`moduleId`** — перевод, из которого взят текст (нужен для «Часть стиха» и подписи « · {перевод}»). Берётся из панели; в «Добавить стих» — перевод панели, если это Библия, иначе первая установленная Библия.
- **`part: true`** — «часть стиха»: `text` — только выбранные слова (§7). У части `to` всегда `null`. Часть никогда не склеивается с соседним стихом.
- **`alt`** — подключённые переводы: список `{m: id, n: название, t: [текст по стихам], il?: true}`; `t` — строки по стихам блока (для подстрочника `il: true` — с разметкой слов `{слово|Стронг|морфология|оригинал}`) (§8).

Идентификаторы блоков `id` — строки, уникальные в проповеди. При «копии» все `id` блоков заменяются новыми.

### 1.4. Склейка стихов в блоки (`versesToBlocks`)

Стихи добавляются по порядку. Новый стих **присоединяется к предыдущему блоку**, если: он не «часть», предыдущий блок тоже не часть, та же книга и глава, и номер ровно на 1 больше последнего (`to ?? verse`).
Присоединение: `to = номер`, `texts = [...прежние (или [text]), новый]`, `text = прежний + " " + новый`. Иначе — новый блок с `to = null`, `moduleId` = перевод (или заданный у элемента), `part: true` только у части.
Пример: выбраны Ин 3:16, 17, 18 и Ин 3:20 → два блока «Ин 3:16–18» и «Ин 3:20».

### 1.5. Убрать один стих из диапазона (`removeVerseFrom`)

- Одиночный стих или блок без разбивки (`texts` нет) — блок убирается целиком.
- Диапазон: стих вне диапазона — блок не меняется; иначе блок **распадается на части до и после** убранного стиха. Часть до — сохраняет `id` блока, часть после — новый `id` (если убрали первый стих — часть после сохраняет `id`).
  Каждая часть: `verse`/`to` пересчитаны (`to = null`, если остался один стих), `text` = стихи через пробел, `texts` — если стихов больше одного, у каждой части **те же `moduleId`, `part`, `alt`**, а `alt[].t` режутся по тем же стихам.

### 1.6. Разметка своего текста (`fmtParts`)

Регулярное выражение: `\*\*([^*\n]+)\*\*|\*([^*\n]+)\*`. `**…**` — жирный, `*…*` — курсив; внутри метки нет `*` и перевода строки; метки не вкладываются; одиночные `*` без пары остаются в тексте буквами.
Разбор делается по всему тексту сразу; переводы строки сохраняются как абзацы (`\n`). Для «Поделиться» метки **убираются** (`plainFmt`); в PDF — жирный/курсив настоящим начертанием; в редакторе/«Кафедре» — начертанием.

### 1.7. Подпись места (`blockRef` / `blockRefFull`)

- Короткая: `{сокр. имя без точки} {глава}:{стих}[–{to}][ (часть)]` — «Ин 3:16–18», «Ин 3:16 (часть)» (сокращённое имя из справочника, **без** завершающей точки: `Ин.` → `Ин`).
- Полная: `{полное имя} {глава}:{стих}[–{to}][ (часть)]` — «От Иоанна 3:16–18». Диапазон — длинное тире «–».
- Надпись «(часть)» — `t('(часть)')`.

### 1.8. Правила изменения (`SermonsNotifier`)

| Действие | Правило |
|---|---|
| Создать | `{id, title (или «Новая проповедь»), date:'', blocks:[], createdAt=updatedAt=now}`, вставляется **в начало** |
| Удалить | убирается из списка |
| Копия (`duplicate`) | глубокая копия; название «**{название} — копия**»; новые `id` проповеди и блоков; `createdAt=updatedAt=now`; **в начало** списка |
| Вернуть после удаления (`restore`) | вставляется **на прежний индекс** (обрезается до длины списка), если проповеди с таким `id` ещё нет |
| Название / подзаголовок / серия / дата | записываются при каждом знаке; `updatedAt=now` |
| Добавить стихи (`addVerses(id, items, moduleId, at)`) | склейка §1.4; блоки вставляются на позицию `at` (индекс блока, 0…длина) или в конец; если у проповеди есть `altDefault`, к **каждому** новому блоку добавляются эти переводы (кроме совпадающего с основным) с пустыми `t` (тексты допишутся, §8) |
| Добавить свой блок | `addTextBlock(after, type)`: `type` — `text` или `note`; пустой блок вставляется после блока `after` (`-1` — в самое начало; `null` — в конец) |
| Правка текста блока | `updateBlock(…, {text})` на каждый знак; `updatedAt=now` |
| Часть стиха | `setPart(блок, text, part)`: `text` заменяется; признак `part` снимается и, если `part=true`, ставится заново |
| Убрать блок / стих | §1.5; блок целиком |
| Переставить | `moveBlock(from, to)`: блок вынимается и вставляется на `to` (позиция уже после удаления) |
| Вернуть блоки | `restoreBlocks(id, blocks)` — весь массив как был |
| Заменить проповедь | `replace(next)` — для «Отменить/Повторить» (§4.2); `updatedAt` = сейчас |
| Переводы у стиха | §8 |
| `fillVerseTexts` (старые проповеди) | у блока-диапазона без `texts` берутся стихи из `moduleId` блока (или перевода окна); если вместе они дают ровно сохранённый `text` (сравнение с нормализацией пробелов) — записывается `texts`. Текст и `updatedAt` не меняются. Каждый блок пробуется один раз за запуск |

## 2. Где что находится

```
«Ещё» → Проповеди ───────────────► страница «Проповеди» (список) ─► строка ─► тот же экран, режим «Проповедь» (редактор)
чтение: выделение → «В проповедь» ─► окно «Добавить в проповедь» (70 %) ─► экран «Добавлено» ─► «Открыть проповедь» ─► страница с редактором
чтение: значок свитка у стиха ──► страница с редактором той проповеди, где стих есть
проповедь: нажатие на стих ─────► закрыть всё, панель идёт к стиху ─► под верхним меню полоса «Вернуться к проповеди «…»»
редактор: «Кафедра» ────────────► полноэкранная «Кафедра»
```

Окно «Проповеди» — один и тот же экран-страница, внутри которого переключается **список ⇄ редактор ⇄ «Добавить стих»** (стрелка «назад» в шапке).
Если страницу открыли сразу на конкретной проповеди (`open: id` — из значка у стиха, из полосы «Вернуться…», из «Открыть проповедь») — **стрелки «назад» к списку нет** (только закрытие), пока человек не откроет другую проповедь (например, копию через «Сделать копию»).

## 3. Список проповедей

Заголовок страницы «**Проповеди**». Сверху вниз:

1. **Поле создания:** строка ввода с подсказкой «**Новая проповедь**» и кнопка «**+ Создать**» справа. «Готово» на клавиатуре = «Создать». Создаётся проповедь (пустое название → «Новая проповедь»), поле очищается, клавиатура скрывается, **сразу открывается редактор** этой проповеди.
2. **Пусто** (проповедей нет): значок свитка, жирное «**Проповедей пока нет**», под ним (до 300 pt) «**Создайте проповедь и добавляйте стихи прямо при чтении: зажмите стих → «В проповедь».**»
3. **Есть проповеди:**
   - поле «**Поиск по проповедям**» (высота 44): без учёта регистра ищет подстроку в названии, подзаголовке, серии и **в каждом блоке**: для стиха — «{полная подпись} {text}», для остальных — `text`. Обновляется на каждый знак.
   - сегментный переключатель «**Недавние** · **По алфавиту**»: «Недавние» — по `updatedAt` убыванию; «По алфавиту» — по названию (без регистра). Выбор сохраняется (`sermonSort`).
   - **Строки.** Если есть серии: группы по названию серии (алфавит без регистра), у каждой заголовок «слой + НАЗВАНИЕ» (на iPhone-стиле без ПРОПИСНЫХ); в конце группа «**Без серии**». Нет ни одной серии — один список без заголовков. Внутри группы порядок по выбранной сортировке.
   - Ничего не найдено — по центру «**Ничего не найдено**» (серым).

**Строка проповеди** (`SermonRow`): слева значок свитка (цвет акцента); название (жирно); под ним мелко (серым):
`{N место/места/мест}` и далее ` · {дата}` (если у проповеди есть `date`; формат `fmtDay(full, year)`: «15 октября 2026»), иначе ` · изменена {дата}` («изменена 15 окт.», `updatedAt`). `N` = число **блоков-стихов** (не число стихов): «1 место» / «2 места» / «5 мест» (`tx` по правилам русского).
Серия в строке не показывается.

- **Нажатие на строку** → открывается редактор этой проповеди (в том же окне).
- **Смахивание влево:** показывается кнопка «**Удалить**» (корзина). **Смахнули далеко** (дальше ~60 % ширины или резко) или нажали кнопку → проповедь **удаляется сразу** и внизу уведомление «**Проповедь «{название}» удалена**» с кнопкой «**Отменить**» (≈6 с) → возвращает проповедь на прежнее место списка.
  (Вариант без стиля iPhone — красная полоса «корзина + Удалить» за строкой, полное смахивание удаляет.) Нажатие по открытой строке или смахивание вправо закрывает кнопку.

## 4. Редактор проповеди

Шапка окна: стрелка «назад» (§2), по центру — **переключатель размера «− 100% +»** (заменяет заголовок «Проповедь»), справа значки: **принтер** («Печать и PDF»), **«поделиться»**, **«Отменить»** (↶), **«Повторить»** (↷).
Значки «Печать и PDF» и «Поделиться» бледные и не нажимаются, пока в проповеди **нет блоков**. «Отменить»/«Повторить» бледные, пока нечего отменять/повторять.

### 4.1. Размер текста «− 100% +»

Меняет размер текста **в редакторе** — базовые размеры умножаются на множитель: стих 16,8 pt, подключённые переводы 15,7, свой текст 16, заметка 14,7. Диапазон 80 %…160 %, шаг 10 % (кнопки «−» «Мельче» и «+» «Крупнее»; на пределе — бледные); нажатие на проценты — снова 100 %. Сохраняется (`sermonZoom`), общее для всех проповедей. На «Кафедру» не влияет (там свой размер, §10).

### 4.2. «Отменить» / «Повторить»

- История живёт, пока открыта страница и эта проповедь; **до 50 шагов**; при открытии другой проповеди сбрасывается. Снимок — вся проповедь (без `updatedAt`). При изменении любого поля проповеди, кроме набора текста, добавляется шаг.
- **Набор текста** в одном блоке или в названии склеивается в один шаг, если пауза между знаками < 800 мс. Любая другая правка завершает склейку.
- «Отменить» → предыдущий снимок записывается как обычная правка (сохраняется в `sermons`, `updatedAt` = сейчас: `replace` проходит через общий `_touch`), «Повторить» — вернуть. Новая правка после «Отменить» очищает «Повторить».
- Автозаполнение разбивки/переводов (§1.8, §8) тоже попадает в историю как шаг [уточнить на телефоне: заметно ли на новых проповедях — там `texts` уже есть].

### 4.3. Верх редактора (шапка списка блоков)

1. **Название** — поле, подсказка «**Название проповеди**», крупно и жирно; при вводе под ним линия цвета акцента.
2. **Подзаголовок** — многострочное поле (растёт), подсказка «**Подзаголовок или описание**», серым.
3. Тонкая линия-разделитель.
4. **Серия** — значок «слои» и поле «**Серия (необязательно)**». Пока поле в фокусе и есть уже заданные серии, в которых встречается введённая подстрока (и не равные ей) — под полем **плашки с названиями серий**; нажатие подставляет название. Серии берутся со всех проповедей.
5. Большая кнопка «**Кафедра**» (значок презентации): открывает «Кафедру» (§10). **Неактивна, пока нет блоков.**
6. **Нет блоков:** карточка-подсказка: жирно «**Как добавить стих:**» и «зажмите стих в Библии и нажмите «В проповедь» — или найдите его кнопкой «Стих» ниже.»; ниже жирно «**Свой текст**» и «— кнопка «Текст». Чтобы переставить блок, зажмите его и тяните.»
   **Есть блоки:** строка-вставка (§4.4) **перед первым блоком**.

### 4.4. Строка вставки между блоками

Между всеми блоками (и в самом начале) — ряд из трёх капсул на пунктирной линии: «**+ Текст**» (подсказка «Добавить текст»), «**+ Стих**» («Добавить стих»), «**+ Заметка**» («Заметка для себя»).
- «Текст» / «Заметка» → создаётся **пустой** блок этого типа **в этом месте** (после блока выше), в нём сразу курсор и открыто редактирование (§4.6).
- «Стих» → экран «Добавить стих» (§5) с позицией вставки «сюда».
Когда блоков нет — вместо строки вставки внизу две кнопки в строку на всю ширину: «**+ Текст**» (свой текст в конец) и «**(лупа) Стих**» (поиск стиха); кнопки «Заметка» тогда нет.

### 4.5. Карточка-стих (`verse`)

Сверху вниз:
1. **Ссылка** (акцентом, жирно): `{короткая подпись} · {название перевода}`, «Ин 3:16–18 · Синодальный» (название — имя модуля `moduleId`; если не найден — его id; нет `moduleId` — без части « · …»). Нажатие → к стиху в Библии (§9) — **на первый стих блока**.
   В правом верхнем углу карточки — корзина (§4.8).
2. **Текст.** Один стих или блок без разбивки — один абзац. Диапазон с разбивкой — каждый стих **с новой строки**, с маленьким номером акцентом слева и крестиком «✕» справа (§4.8). Нажатие по тексту стиха → к этому стиху в Библии (§9).
   Размер и шрифт — как в чтении (шрифт читалки, межстрочный 1,5).
3. **Подключённые переводы** (если есть) под основным текстом (§8).
4. **Нижняя строка** под пунктиром: слева капсула перестановки «⠿ │ ↑ │ ↓» (§4.7), затем значок «Переводы» (если не идёт выбор части), затем кнопка «Часть стиха» / «Весь стих» (§7); справа при выборе части «Отмена» и «Готово».
5. С левого края карточки — вертикальная акцентная полоса: стих отличается от текста при прокрутке.

### 4.6. Карточка-текст и заметка (`text`, `note`)

- Заметка: сверху маленькая подпись «**Заметка для себя**» со значком; карточка чуть приглушена; текст курсивом.
- **Показ:** текст с оформлением (жирный/курсив) — по нажатию переходит в правку (курсор в конце).
- **Правка** (поле растёт): над полем два значка — «жирный» (B, подсказка «**Жирный**») и «курсив» (I, подсказка «**Курсив**»): оборачивают выделенный текст в `**…**` / `*…*` (или ставят пару меток под курсор и ставят курсор внутрь); поле остаётся в фокусе; изменение сразу записывается. Подсказка в пустом поле: «**Мысль, пояснение, пример…**» (текст) и «**Подсказка себе: пауза, вопрос залу…**» (заметка).
- Выход из правки (потеря фокуса) — возвращается показ. **Пустой блок (только пробелы) при выходе удаляется сам.** Блок, созданный только что (`fresh`), открывается сразу в правке.
- В правом верхнем углу — корзина «Удалить текст» (§4.8).

### 4.7. Перестановка блоков

- **Зажать блок** (долгое нажатие в любом месте карточки, ≈0,5 с) → лёгкая вибрация, карточка «поднимается» (тень) и перетаскивается вверх/вниз; отпустили — `moveBlock`. Во время переноса поднимается только карточка, не строки вставки.
- В нижней строке карточки капсула «⠿ │ ↑ │ ↓»: подсказка у «⠿» — «**Зажмите, чтобы перетащить**» (сама «⠿» не ручка, тянуть можно за любую часть карточки); «↑» («**Переместить выше**») и «↓» («**Переместить ниже**») двигают блок на одно место; у первого блока «↑», у последнего «↓» бледные и не нажимаются.

### 4.8. Удаление: что с подтверждением и что с «Отменить»

| Что | Как | Подтверждение | «Отменить» (уведомление) |
|---|---|---|---|
| Блок целиком (корзина в углу карточки) | нажать корзину | первое нажатие превращает её в красную кнопку «**Удалить**» (≈3 с, потом возвращается), второе — удаляет | **нет** (вернуть можно значком «Отменить» в шапке окна) |
| Один стих из диапазона (✕ справа) | нажать ✕ | то же: «**Убрать**» | «**Убрано: {подпись стиха}**» + «Отменить» (≈6 с) |
| Подключённый перевод (✕ у названия перевода) | нажать | **сразу, без вопроса** | «**Убрано: {название перевода}**» + «Отменить» |
| Проповедь целиком (внизу «Удалить проповедь») | нажать | первое нажатие меняет надпись на «**Удалить проповедь?**» (≈3 с), второе — удаляет и возвращает к списку | **нет** |
| Проповедь в списке (смахивание) | §3 | нет (сразу) | «Проповедь «{название}» удалена» + «Отменить» |

Подсказки корзин: «Удалить стих из проповеди» (стих) / «Удалить текст» (текст, заметка); крестик в диапазоне — «Убрать стих»; в переводе — «Убрать: {название}».
Подпись стиха в «Убрано: …» — короткая (§1.7); для одного стиха диапазона — `{Книга} {глава}:{стих}`.

### 4.9. Низ редактора

- Если блоков нет — ряд «+ Текст» / «(лупа) Стих» (§4.4).
- Затем по центру неброские кнопки: «**Сделать копию**» (создаёт копию §1.8 и **открывает её** в окне; теперь «назад» ведёт к списку) и «**Удалить проповедь**» (двухшаговая, §4.8).

### 4.10. Новый блок после добавления стихов

Когда человек вернулся из «Добавить стих» с новым блоком (кнопкой-ссылкой, §5), список прокручивается так, чтобы **первый новый блок был на 40 % высоты**, и вокруг него на 1,4 с загорается рамка цвета акцента, плавно гаснет.

### 4.11. Подстрочник в проповеди

Подключённый перевод-подстрочник показывается столбиками (§8). Нажатие на слово с номером Стронга открывает **статью Стронга поверх проповеди** (`Hub.openStrong`, «назад» возвращает в проповедь; `closeToParent: true`).

## 5. «Добавить стих» (`VersePicker`)

Тот же экран-страница, режим «подэкран»: заголовок «**Добавить стих**», подзаголовок — название проповеди, стрелка «назад» → к редактору. Перевод поиска: перевод панели окна, если он Библия, иначе первая установленная Библия.

Сверху (прокручивается вместе со списком):
1. Поле «**Слово, фраза или ссылка**» (автофокус). Клавиша «Готово»: если введена ссылка — добавить её; иначе — искать.
2. Сегментный переключатель области: «**Вся Библия** · **ВЗ** · **НЗ** · **{сокр. имя книги первой панели}**» (общая с основным поиском, `searchScope`).
3. Переключатель «**Только целые слова**» с пояснением «**Иначе «свет» найдёт и «светильник»**» (общий, `searchWhole`).
4. Если введённое **разобралось как ссылка** («Ин 3:16», «Ин 3:16-18», «Пс 22»): большая кнопка «**+ Добавить в проповедь: {подпись}**». Подпись: «**Полное имя гл**» для целой главы («Пс 22» без номера стиха) или «**Полное имя гл:ст[–конец]**».
5. Если ссылкой не разобралось и длина ≥ 2 знаков — после паузы **350 мс** запускается поиск по тексту перевода (область/целые слова учитываются); пока идёт — крутилка; результат: строка «**Найдено: {n}**» (если ничего не нашлось — к ней добавляется « — попробуйте другую форму слова или отключите «целые слова».»).

**Что делает ссылка** («+ Добавить…» / «Готово»): берутся стихи из выбранного перевода (до 400 строк; «Пс 22» без номера стиха — вся глава); ничего не нашлось → уведомление «**Такого места нет в выбранном переводе.**».
Иначе — все стихи добавляются одним вызовом (склейка в один блок, §1.4) на выбранную позицию вставки; уведомление «**Добавлено в проповедь: {подпись}**»; **экран возвращается к редактору** и прокручивается к новому блоку (§4.10).

**Результаты поиска** (по 200, внизу «**Показать ещё ({n})**» — ещё 200): строка = короткая подпись стиха (акцентом, жирно) и отрывок (до 3 строк, найденные слова выделены); справа «**+**».
- Нажатие на строку добавляет **этот стих** (текст берётся из перевода) на позицию вставки; уведомление «**Добавлено в проповедь: {Ин. 3:16}**» (подпись — обычная `formatRef`); **экран остаётся на списке** (можно добавлять дальше); позиция вставки сдвигается после добавленного (чтобы следующий встал следом). Значок «+» плавно сменяется галочкой («**Уже в проповеди**», подсказка вместо «Добавить в проповедь»), если стих уже в этой проповеди **не как часть** (проверяется по диапазонам блоков).
- Позиция вставки: «Стих» из строки вставки — между блоками (индекс блока); из нижней кнопки — в конец.

## 7. «Часть стиха» в проповеди

Для блока **одного стиха** (`to == null`), у которого найден текст в его модуле (`moduleId`), в нижней строке карточки есть одна кнопка по ситуации:
- у полного стиха — «**Часть стиха**» (значок выделения текста) → режим выбора;
- у части (`part: true`) — «**Весь стих**» (значок цитаты) → **текст возвращается к полному** из модуля, признак `part` снимается.
Режим выбора: текст карточки заменяется **полным текстом стиха** (из модуля блока), слова нажимаются; под текстом, пока ничего не выбрано, курсивом (серым) подсказка «**Нажмите на первое и последнее слово.**».
Нажатие на слово ищет ближайшее слово (допуск 1 знак): первое нажатие — начало, второе — конец (в любом порядке); третье начинает заново. Выбранный отрезок закрашивается цельной плашкой (акцент 24 %).
Внизу справа: «**Отмена**» (выйти без изменений) и «**Готово**» (недоступна, пока не выбрано) → в блок записывается `text` = выбранный отрезок (`partText`: от начала первого слова до конца последнего, пробелы сжаты), `part: true`; в подписи появляется « (часть)».
Кнопка «Переводы» в этом режиме скрыта. Если текст стиха в модуле больше не найден (модуль удалён) — кнопка «Часть стиха» не показывается.

## 8. Переводы у стиха (`alt`)

- Значок «Переводы» (языки) в нижней строке карточки; включён (акцент), если панель выбора открыта или переводы уже подключены. Нажатие раскрывает/сворачивает панель выбора.
- **Панель выбора:** плашки установленных Библий (не «вспомогательных»), у которых **есть этот стих** (плюс уже подключённые — чтобы их можно было снять). Порядок: основной перевод блока (отмечен, **не снимается**), затем подключённые, затем остальные. Нажатие подключает/отключает: в `alt` добавляется/убирается `{m, n}` (название = имя модуля), для новых `t = []`.
  Ниже, если подключён хоть один перевод, переключатель «**Подключать к новым стихам**»: включён, когда `altDefault` проповеди **равен** списку подключённых; включение записывает `altDefault = подключённые {m,n}`, выключение — `[]`.
- **Показ** под основным текстом: каждый перевод — строка-разделитель, название (жирно, мелко) + «✕» («Убрать: {название}», сразу, с «Отменить», §4.8), затем текст по стихам через пробел (того же размера минус чуть); нет текста — «…», все пусты — «—». Подстрочник (`il`) — столбики слов: сверху оригинал, под ним перевод; иврит — справа налево; слово со Стронгом нажимается (§4.11).
- **Дописывание текстов** (`fillAltTexts`, автоматически при показе): если у перевода число строк `t` ≠ числу стихов блока (или признак `il` не совпал с типом модуля) — `t` пересчитывается: для каждого стиха текст из этого модуля (`verseText`; для подстрочника — `verseRaw` с разметкой слов); нет стиха — `''`; `il: true` ставится, если у модуля есть признак `interlinear`. `updatedAt` не меняется.

## 9. Связь с чтением

**Значок «стих есть в проповеди».** В тексте чтения у каждого стиха, который входит в диапазон какого-либо `verse`-блока любой проповеди (проверка по `book.chapter` и `verse…to`; части тоже считаются), после номера стиха стоит маленькая плитка со значком свитка (размер ≈ 1,05 размера шрифта, фон акцента 16 %).
В режиме «Как книга» значков нет. Подпись для VoiceOver «Стих есть в проповеди. Открыть проповедь», подсказка «Открыть проповедь». Нажатие → страница «Проповеди», открытая **на проповеди, где стих есть** (если их несколько — на самой недавно изменённой по `updatedAt`). Значки пересчитываются при любом изменении проповедей.

**Переход из проповеди в Библию.** Нажатие на подпись или на текст стиха в карточке-стихе:
1. закрываются **все** окна до чтения (`closeToReader`),
2. панель окна (`pane`) переходит к этому стиху (`navigate` — с миганием и записью в историю),
3. запоминается «вернуться»: `{панель, id проповеди}` (в памяти, не сохраняется).

**Полоса «Вернуться к проповеди».** Под верхним меню панели `pane` (высота 40, цвет верхней панели, во всю ширину; въезжает/уезжает сверху за 260 мс): стрелка «←» и текст «**Вернуться к проповеди** **«{название}»**» (название жирно, одна строка), справа «✕» (подсказка «Закрыть»).
Нажатие на текст → полоса исчезает, открывается страница «Проповеди» на этой проповеди; «✕» → просто убирается. Показывается только в панели, из которой ушли; если проповедь удалили — полоса пропадает.

## 10. «Кафедра»

Полноэкранный экран (`MaterialPageRoute`, `fullscreenDialog`) из кнопки «Кафедра» редактора.

**Верхняя панель** (слева направо): «**−**» («Мельче», −2) · значок «Aa» · «**+**» («Крупнее», +2) · название проповеди по центру (одна строка) · **таймер** · «**✕**» («Закрыть кафедру»).
- Размер: по умолчанию **26**, пределы 18…60, шаг 2, округляется; сохраняется (`pulpitSize`) при каждом изменении. **Щипок двумя пальцами** по тексту меняет размер пропорционально расстоянию между пальцами (тоже сохраняется); пока щиплют, прокрутка отключена.
- **Таймер проповеди:** показывает «м:сс» (с секундами, часов нет: 75 мин = «75:00»); **стартует сам при открытии**; нажатие — пауза/«Продолжить» (подсказки «Пауза»/«Продолжить»; VoiceOver «Время проповеди: м:сс»); на паузе цифры блёклые. Не сохраняется, при закрытии пропадает.
- **Экран не гаснет** на время «Кафедры» (`keepScreenOn(true/false)` через канал `aobible/screen`). **Во Flutter это сделано только на Android** (`MainActivity.kt`); на iOS канала нет, вызов молча игнорируется — экран может гаснуть. Для Swift требуется настоящее «не гаснет».

**Текст** (прокручивается; боковые поля `max(20, (ширина − 46 × размер)/2)`, сверху 24, снизу 40 % высоты экрана — чтобы можно было дочитать до середины):
1. Название — по центру, крупно (×1,5), жирно.
2. Подзаголовок (если есть) — по центру, ×0,78, серым.
3. Дата (если есть) — по центру, ×0,7, серым, полная с годом.
4. Блоки по порядку:
   - **Стих:** подпись места акцентом (полное имя, жирно, ×0,78; «(часть)» в конце) — **без названия перевода**; текст стиха шрифтом читалки (межстрочный 1,55); у диапазона каждый стих с нового абзаца, перед ним маленький номер; подключённые переводы под стихом: название мелко жирно, текст ×0,88 (подстрочник — столбиками ×0,88), показываются только если у них есть текст.
   - **Свой текст:** абзацы с жирным/курсивом, отступы сверху/снизу = размер.
   - **Заметка для себя:** **показывается** (мелко ×0,7, курсивом, серым, слева вертикальная черта) — на «Кафедре» заметки видны (подсказка себе перед читателем).
   - Пустые тексты пропускаются.
5. В конце — «**Аминь**» (серым, ×0,8, по центру, с большим отступом сверху).

## 11. «Поделиться» и «Печать и PDF»

### 11.1. «Поделиться» (значок в шапке редактора)

Открывает системное окно «Поделиться» с **текстом** (`sermonText`) и заголовком = названием проповеди. Состав (части через пустую строку):
1. название; 2. подзаголовок (если не пуст); 3. дата (если есть) — «15 октября 2026»;
4. по блокам: **стих** — «{полная подпись}\n«{тело}»», где тело = текст стиха или (диапазон с разбивкой) «16 текст\n17 текст…» (по строке на стих с номером); затем для каждого подключённого перевода «{название}: «{текст через пробел}»» (подстрочник — слова без разметки);
   **свой текст** — текст без меток `**`/`*`, обрезан по краям; **заметка для себя — не включается**; пустые блоки пропускаются.
Серия в текст **не входит**.

### 11.2. «Печать и PDF» (принтер в шапке)

Создаёт PDF (`sermonPdf`) и сразу открывает системное окно «Поделиться» с файлом (`application/pdf`, заголовок = название): печать, «Сохранить в Файлы», отправка. Имя файла = название, в котором `\ / : * ? " < > |` заменены пробелами и обрезаны края; пусто → `sermon`; расширение `.pdf`; лежит во временной папке.
Страница A4, поля слева/справа 46, сверху/снизу 50, многостраничная. Шрифты PT Serif (текст) и PT Sans (подписи) из приложения (`assets/fonts`).
Состав сверху вниз: серия (ПРОПИСНЫМИ, мелко, акцентом) · название (крупно, жирно) · подзаголовок · дата (мелко, серым, полная с годом) · отступ ·
по блокам: **стих** — подпись (полное имя, жирно, мелко, акцентом) на вертикальной акцентной линии слева; под ней каждый стих отдельной строкой на той же линии (у диапазона — с маленьким номером акцентом); затем для каждого подключённого перевода (если есть текст) — его название (мелко, серым) и текст;
**свой текст** — абзацы (по переводам строки), жирное/курсив настоящим начертанием; **заметка для себя — включается**: мелко, курсивом, серым, с тонкой серой линией слева; пустые блоки пропускаются.
(Отличие от «Поделиться»: в PDF есть серия и заметки; в тексте — нет.)

## 13. Как окна и состояния связаны (карта)

```
«Ещё» → Проповеди ──► список ──► [создать] ─► редактор            [строка] ─► редактор       [смахнуть] ─► удалено + «Отменить»
выделение → «В проповедь» (03 §15) ─► «Добавить в проповедь» ─► блоки в конец (+altDefault) ─► «Добавлено» ─► «Открыть проповедь» ─► редактор
редактор:
   шапка:   − 100% +  | принтер ─► PDF ─► системное «Поделиться»  | поделиться ─► текст  | ↶ ↷  (50 шагов)
   поля:    название / подзаголовок / серия (+ плашки серий) ; «Кафедра» ─► полноэкранный текст + таймер
   вставка: + Текст | + Заметка ─► пустой блок с курсором | + Стих ─► «Добавить стих» (ссылка / поиск) ─► назад + прокрутка и рамка к новому блоку
   блок:    нажатие на стих ─► Библия + полоса «Вернуться к проповеди» ─► снова редактор
            зажать ─► перетащить ; ↑ ↓ ; корзина ─► «Удалить» ; ✕ ─► «Убрать» ─► «Убрано» + «Отменить»
            Переводы ─► плашки ─► alt + «Подключать к новым стихам» (altDefault) ; слово подстрочника ─► статья Стронга
            Часть стиха ─► слова ─► «Готово» (part) / «Весь стих» (вернуть)
   низ:     «Сделать копию» ─► открыть копию ; «Удалить проповедь» (2 шага)
чтение: значок свитка у стиха ─► редактор той проповеди (самой недавней из содержащих стих)
```

## Расхождения со Swift (что нет / что иначе)

Сравнено с `swift/AOBible/Views/SermonsView.swift` (далее **SV**), `swift/AOBible/Core/SermonStore.swift` (**SS**), `Views/ReaderView.swift` (**RV**), `Views/PartSheet.swift` (**PS**), `Views/MoreView.swift` (**MV**), `Core/UserData.swift` (**UD**).

### А. Данные и формат
1. Хранилище SS — файл `sermons.json` в Application Support (если его нет, один раз подхватываются `flutter.sermons` из `UserDefaults`); Flutter — prefs-ключ `sermons`. В «Мои данные» (UD) ключ `sermons` передаётся как JSON-строка списка — формат совпадает.
2. **Модель SS теряет поля.** В `Sermon` нет **`altDefault`** («Подключать к новым стихам»), в `SermonBlock` — никаких неизвестных полей; при первом сохранении проповеди из Flutter эти данные **пропадают**. Flutter хранит `Map` и сохраняет всё (§1.1).
3. `Sermon.init(title:)` ставит `date = сегодня`; Flutter создаёт `date = ''` (дата в Flutter нигде не задаётся и не редактируется). SV `DatePicker «Дата»` — расширение; для Flutter-совместимости достаточно показывать дату, если она есть.
4. SS `upsert` всегда ставит `updatedAt = сейчас` на любую запись; «тихих» обновлений без отметки времени (Flutter: `fillVerseTexts`, `fillAltTexts` с `stamp: false`) в Swift нет — как нет и самого автозаполнения (§1.8, §8).
5. `ref(_:)` SS пишет « (часть)» буквально (не локализовано); `shortBook` убирает точку — как во Flutter.
6. Нет ключей `sermonSort`, `sermonZoom`, `pulpitSize` в формате Flutter: SV использует `@AppStorage("pulpitSize")` (double, по умолчанию 28; Flutter: JSON-строка, по умолчанию 26); остальных нет.

### Б. Список (SV `SermonsView`)
7. Нет ввода названия с кнопкой «Создать»: «+» в панели навигации сразу создаёт «Новая проповедь» и открывает редактор (для Flutter — поле «Новая проповедь» + «Создать»).
8. Сортировка только по `updatedAt`; **нет** «Недавние / По алфавиту» и `sermonSort`; **нет групп по сериям** («Без серии»); поиск — только название, серия, подзаголовок (во Flutter ещё **текст блоков и подписи стихов**).
9. Строка: «Название» + «дата · серия · блоков: N» (Flutter: «{N} место/места/мест · дата» либо «· изменена {дата}», серии в строке нет; N — число блоков-стихов). Нет значка свитка.
10. Пустое состояние другое: «Нет проповедей» / «Нажмите «+» или выделите стих в чтении и выберите «В проповедь».»; нужно: «Проповедей пока нет» / «Создайте проповедь и добавляйте стихи прямо при чтении: зажмите стих → «В проповедь».». Нет «Ничего не найдено».
11. Смахивание «Удалить» (`swipeActions`) удаляет **без «Отменить»**; во Flutter — уведомление «Проповедь «{название}» удалена» + «Отменить» (возврат на прежнее место) (§3).
12. «Ещё → Проповеди» в MV показывается всегда (во Flutter — по флагу `menu.sermons`) и открывается через `NavigationLink`, а не страницей на всю высоту с подсветкой «Ещё».

### В. Редактор (SV `SermonEditor`)
13. Поля — `List`/`Form`: «Название», «Подзаголовок», «Серия» (+ «Дата»); подсказки другие (нужны «Название проповеди», «Подзаголовок или описание», «Серия (необязательно)»); **нет плашек существующих серий**; кнопка «Кафедра» — значок `text.viewfinder` в панели справа и **не отключается** при пустой проповеди (во Flutter — крупная кнопка под полями, неактивна без блоков).
14. **Нет**: «Отменить/Повторить» (50 шагов, §4.2), переключателя «− 100% +» и `sermonZoom` (§4.1), «Печать и PDF» (только `ShareLink` с текстом), «Сделать копию», «Удалить проповедь» (двухшаговой), `ConfirmIcon` корзин на блоках, уведомлений «Убрано: …» с «Отменить».
15. **Перестановка:** `onMove`/`onDelete` в режиме «Порядок» (кнопка «Порядок/Готово»); нет перетаскивания долгим нажатием, нет капсулы «⠿ ↑ ↓» и стрелок (§4.7); удаление блоков — смахивание/режим правки без подтверждения.
16. **Вставка:** одно меню «Добавить блок» внизу списка («Стих», «Свой текст», «Заметка для себя») — только **в конец**; нет строк «+ Текст / + Стих / + Заметка» между блоками и в начале, нет подсказки пустой проповеди «Как добавить стих: …», нет рамки-вспышки и прокрутки к новому блоку.
17. **Блок-стих** (SV `BlockRow`): подпись — полное имя (`ref(full: true)`), **без «· {перевод}»**, **не нажимается** (нет перехода к стиху в Библии, нет полосы «Вернуться к проповеди»); диапазон — строки «16 текст…» без ✕ у каждого стиха (убрать один стих из диапазона нельзя: в SS нет `removeVerseFrom`); нет «Часть стиха» / «Весь стих», нет «Переводы» (панели выбора, `setBlockAlts`, `altDefault`, `fillAltTexts`, `fillVerseTexts`); подключённые переводы только читаются (`alt`) одной строкой «{n}: {текст}» без столбиков подстрочника и без Стронга.
18. **Блок-текст/заметка:** `TextField(axis: .vertical)` с подсказками «Свой текст: **жирный**, *курсив*» / «Заметка»; нет значков «Жирный»/«Курсив», нет показа с оформлением вне правки (метки `**` видны буквами; оформление только на «Кафедре»), пустой блок при выходе **не удаляется**; подпись заметки «Заметка для себя (не уходит в «Поделиться»)» (Flutter: «Заметка для себя»).
19. **«Добавить стих»** (SV `AddVerseSheet`) — маленький лист «Стих в проповедь»: одна строка «Ин 3:16 или Ин 3:16-18», кнопки «Отмена»/«Добавить»; **нет поиска по словам**, области (ВЗ/НЗ/книга), «Только целые слова», результатов с «+»/галочкой «Уже в проповеди», «Показать ещё», уведомлений «Добавлено в проповедь: …» / «Такого места нет в выбранном переводе.» (здесь «Не нашёл такое место в переводе.»). Ссылка без номера стиха («Ин 3») добавит **только 1-й стих**, а не главу (`RefParser.parse` возвращает `verse = 1`, `endVerse = nil`); лимит 60 стихов (Flutter: до 400). Перевод — `primaryModule` или первая установленная Библия, а не перевод панели, из которой вызвали.
20. Нет вставки на нужное место и позиции для второго, третьего добавления.

### Г. «Кафедра» (SV `PulpitView`)
21. Нет: подзаголовка, даты, номеров стихов в диапазоне (весь `b.text` одним абзацем), подключённых переводов/подстрочника, **заметок** (SV их **фильтрует**; во Flutter заметки показываются курсивом с чертой), строки «Аминь», **таймера**, кнопок «−/+» и значка «Aa» (вместо них `Slider` внизу 18…60 с шагом 2, по умолчанию 28), щипка двумя пальцами, кнопки «✕ Закрыть кафедру» (используется «назад»), поля по ширине `46 × размер`, запаса снизу 40 % высоты.

23. Экран **не гаснет**: SV ставит `isIdleTimerDisabled` — **лучше Flutter** (во Flutter на iOS это не работает, §10). Оставить.

### Д. Чтение
24. Нет значка «стих есть в проповеди» у стиха (§9) и перехода по нему; нет `Hub.underBar` / полосы «Вернуться к проповеди».
25. «В проповедь» из выделения (RV `addToSermon`, MV/RV `Menu`): подменю из **10 последних** проповедей + «Новая проповедь» (без запроса названия), уведомление «Добавлено в проповедь»; **нет** окна «Добавить в проповедь» (создание с названием, полный список, «Или выберите проповедь», экран «Добавлено» с «Открыть проповедь» / «Читать дальше», 70 % высоты) (`03` §15). `altDefault` не применяется (его в SS нет).
26. «Часть стиха» (PS): добавляет `part: true` в **последнюю** выбранную проповедь из меню (10 последних + «Новая проповедь»), сообщение «Добавлено в проповедь» зелёным; индексы слов см. `03` Д.28.

### Е. «Поделиться» и PDF
27. `SermonStore.text(_:)` почти повторяет `sermonText`: **серия не входит** — совпадает; дата — `d MMMM yyyy` по-русски всегда (Flutter: по языку интерфейса, `fmtDay`); подзаголовок обрезается — совпадает; заметки не входят — совпадает.
28. **Нет PDF** (§11.2), нет имени файла по названию, нет серии/заметок в печатной версии.

### Ж. Что совпадает
Формат блоков (`verse`/`text`/`note`, `to`, `texts`, `part`, `alt`), склейка подряд идущих стихов (`versesToBlocks`), `verseTexts`, регулярное выражение **жирного/курсива**, подпись места (`ref`, `shortBook`), `newId` (основание 36), экран «Кафедра» с `isIdleTimerDisabled`, «Поделиться» текстом без заметок.
