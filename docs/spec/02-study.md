## 0. Общее для всех окон «изучения»

### 0.1. Какие окна есть, кто их открывает, что делают «назад» и «×»

| Окно | Кто открывает | Размер при открытии | «‹ Назад» в шапке | «×», нажатие на фон, свайп вниз по шапке |
|---|---|---|---|---|
| **Выбор словаря у слова** (карточка со стрелкой) | нажатие на слово в тексте (см. §1) | карточка у слова, не лист | нет | нажатие мимо карточки закрывает **только её** |
| **Статья словаря** («Слово: …», «Статья H7225») | выбор строки в карточке слова; нажатие на номер Стронга в тексте стиха; номер Стронга в блоке проповеди (с `closeToParent`); нажатие на слово в подстрочнике; слово оригинала в «Всё о стихе»; шапка карточки Стронга в поиске | статья Стронга — **full**; статья «по словам» — **half**; из «Всё о стихе» — **normal** (сначала список словарей) | условно (§3.2) | закрывает **все** окна изучения; при `closeToParent` — только себя (вернуться в окно проповеди) |
| **Все места** (конкорданс) | кнопка «Все места (n)» внизу статьи Стронга | full | **всегда**; закрывает только себя (виден «подложенный» Стронг) | все окна |
| **Подстрочник** | «Подстрочник» в меню «⋯» панели выделения и в строке действий под стихом | full | нет (в шапке вместо этого стрелки ‹ › — соседние стихи) | все |
| **Параллельные места** | число `[⇅ n]` после стиха; пункт «Параллельные места» меню «⋯» (только один выделенный стих) | normal | нет | все |
| **Комментарий** | значок «Комментарии» панели выделения; долгое нажатие на раскрытый комментарий / на название введения; карточка «Комментарии» в «Всё о стихе»; метка комментария после стиха при `commentView = tag`; пункт библиотеки модулей для комментария | normal | нет | все |
| **Сравнение переводов** | меню «⋯» → «Сравнить переводы» | tall | нет | все |
| **Читать параллельно** (то же окно сравнения, `pick`) | значок «языки» в панели выделения, если другой перевод не один | normal | нет | все |
| **Всё о стихе** | меню «⋯» | tall | нет | все |
| **Просмотр иллюстрации** | значок иллюстрации после стиха | **весь экран** (не лист) | нет | «×» в углу или потянуть картинку вниз |

Окна накладываются друг на друга (каждое — новый слой; нижнее остаётся живым). «×», нажатие на затемнённый фон и свайп вниз
вызывают `closeAllSheets` — закрываются **все** слои разом и человек возвращается в читалку. «Назад» есть только там, где
сказано в таблице, и закрывает один верхний слой.

Следствие, которое нужно повторить: из «Всё о стихе» можно открыть «Комментарий» или «Статью словаря», но вернуться в «Всё о стихе»
нельзя (у «Комментария» нет «назад»; у статьи «назад» ведёт к её списку словарей, а не к «Всё о стихе»).

### 0.2. Рамка окна (`sheet.dart`: `showSheet`, `_Frame`, `SheetScaffold`)

- Окно выезжает снизу за 260 мс, фон за окном затемнён на 32 %, **нажатие на фон закрывает все окна**. Клавиатура поднимает окно (отступ по `viewInsets.bottom`).
- Высота — доля высоты экрана: `half` 0,5 · `normal` 0,86 · `tall` 0,92 · `full` 1,0. Верхний предел — высота экрана минус верхний
  отступ безопасной зоны минус 6 pt (то есть `full` не доходит до часов).
- **Перетаскивание высоты** — только за шапку (ручка 40×5 и строка заголовка); тело окна прокручивается отдельно.
  Пока палец ведёт, высота следует за ним без анимации (предел 0,12 … 0,96; у `full` — до 1,0); после отпускания — анимация 180 мс.
  Правила отпускания (в таком порядке):
  1. потянули вниз больше чем на 60 pt, **или** скорость вниз > 400 pt/с, **или** высота стала < 0,28 → **закрыть все окна**;
  2. у `full` — вернуть 1,0 (высота у `full` не меняется);
  3. иначе «примагничивание» к ближайшему из **0,5 · 0,86 · 0,92**, но **только не ниже той ступени, с которой начали** (потянули
     вниз, но недостаточно, — вернётся на исходную; вверх — на ближайшую выше);
  4. быстрый рывок вверх (> 1000 pt/с) → сразу 0,92.
- Шапка (слева направо): **[‹ Назад]** (только если у окна есть «назад») · заголовок (жирный, одна строка, обрезается) с
  **подзаголовком** под ним (мелкий, серый, одна строка с «…») · дополнительные кнопки окна (`headerExtra`; сейчас только стрелки
  ‹ › подстрочника) · **[×]**. Под шапкой тонкая линия. Минимальная высота строки шапки 48.
- Тело: прокручиваемый список с полями 16 слева/справа, 12 сверху, 20 + безопасная зона снизу; блоки через 12 (если не сказано иначе).
  Нижняя вкладка-панель приложения перекрывает окно — под неё добавляется отступ.
- Для Swift (iOS 26): системный `sheet` с `presentationDetents([.fraction(0.5), .fraction(0.86), .fraction(0.92), .large])`,
  стартовая ступень — из таблицы §0.1; свайп вниз закрывает **все** листы изучения (не один верхний).
  **[Swift]** сейчас почти везде `[.medium, .large]`, «закрыть всё» нет — есть «Готово», которое закрывает один лист.

### 0.4. Ссылки на стихи внутри обычного текста (`splitRefs`, `LinkedText`)

Нужны в статьях «по словам» и в комментариях. В тексте ищется шаблон (регулярное выражение):

```
((?:[1-4]\s?)?[А-ЯЁA-Z][а-яёa-z]{1,14}\.?)\s?(\d{1,3})(?:\s?[:,]\s?(\d{1,3})(?:\s?[-–]\s?(\d{1,3}))?)?
```
1. Группа 1 (название) переводится в книгу через `Books.findBookId` (`_norm` + точное совпадение с алиасом; иначе, если ≥ 3 знаков, — первый алиас, начинающийся с этого текста). Нет книги → не ссылка.
2. «Целая глава» (после названия только число, без `:стих`) — ссылка **только для сокращений**: название заканчивается точкой («Мф. 5») или в нём (без пробелов) ≤ 5 знаков («Пс 22»). Длинное слово («Книга 5») — не ссылка.
3. Ссылка = (книга, глава, стих или 1). Конец диапазона («3:16–18») **игнорируется**: открывается первый стих.
4. После найденной ссылки подряд разбираются продолжения `^(\s*[;,]\s*)(\d{1,3})\s?:\s?(\d{1,3})(?:\s?[-–]\s?(\d{1,3}))?` — **та же книга** («Быт. 23:19; 49:29–31» — вторая часть тоже ссылка на Быт). Продолжение обязательно с `глава:стих`.
5. Ссылки подчёркнуты цветом акцента (на iOS — только цвет). Нажатие вызывает действие окна: в статьях и комментариях — `openRefInOther` (§0.5).

### 0.5. Куда открываются места из окон

Две функции, обе в конце **закрывают все окна**:

- **`openRefInOther(pane, to)`** (статьи словарей, «Все места», комментарии): если окно открыто из **первой** панели (0): когда панелей меньше двух — экран делится (`toggleSplit`, вторая панель = тот же перевод на том же месте), затем место открывается **во второй панели** (индекс 1); если из любой другой панели — место открывается **в ней самой**. Переход обычный, с миганием стиха и записью в историю панели.
- **`openRefBelow(pane, to)`** (параллельные места, «Всё о стихе»): если панелей меньше 6 — **новая панель сразу под исходной** (тот же перевод, у новой мигает этот стих), остальные панели сохраняют место; если панелей уже 6 — место открывается в **панели ниже** исходной, а у нижней — в ней самой (вернуться — кнопкой «назад» панели).
- Подсказка над списком параллельных мест (`belowHint(pane, count)`): `count < 6` → «Место откроется в новой панели под этой.»; иначе `pane + 1 < count` → «Место откроется в панели ниже.»; иначе → «Место откроется здесь; вернуться — кнопкой «назад».»
- Номер панели `pane` в окнах без своего номера (подстрочник, сравнение): `paneOf(панели, moduleId)` — **первая** панель с этим переводом, если нет — 0 (не обязательно та, в которой выделяли стих).

**[Swift]** есть только `PanesStore.openSecond(from:)`: открывает место в панели **сразу ниже** исходной, а если её нет — создаёт; существующую панель ниже **перезаписывает**; при шести панелях — открывает в самой исходной. Это не `openRefBelow` (тот всегда создаёт новую панель, пока их меньше шести) и не `openRefInOther` (из первой — всегда во вторую, из остальных — в себе); подсказки над списком мест («Место откроется …») нет.

### 0.6. Данные: какие модули участвуют, таблицы, разметка

- Участвуют только **включённые** модули (`ModuleStore.installed`; выключенные небиблейские модули пропускаются — переключатель в библиотеке модулей).
  Тип модуля: `dictionary`, `commentary`, `crossrefs`, `illustrations` (их «таблицы изучения» строятся при установке; у старых установок — один раз
  при первом обращении, в фоне — `StudyData.ensure()`; пока таблиц нет, модуль считается неготовым и пропускается).
- Порядок модулей одного типа: русские (`language == 'ru'`) раньше остальных, затем по `id`. Для словарей поверх этого — ранги:
  0 — русский словарь **по номерам Стронга**, кроме `rst-symphony`; 1 — прочие русские; 2 — остальные (внутри ранга — прежний порядок).
- Таблицы SQLite (в каждом модуле своя база): `dict(key PK, word, json)` — ключ: номер Стронга («H7225») или слово в нижнем регистре; `windex(word PK, json)` — «словоформа → [[номер Стронга, число], …]» (есть только у симфонии RST+);
  `comm(book, chapter, verse, key, title, text)` — статья лежит у **первого стиха своего диапазона** (`key` — OSIS: `Gen.1.1`, `Gen.1.1-3`, `Gen.1.1-2.3`);
  `xr(book, chapter, verse, n, refs)` — параллельные места модуля; в самом переводе — таблица `xrefs(book, chapter, verse, refs)`; `illus(book, chapter, verse, json)` — список картинок `{img, thumb, title, author, year, license, src}`; `verses(id, book, chapter, verse, text)`.
- Поля статьи словаря (`json`): `lemma`, `word`, `xlit`, `pron`, `definition`, `derivation`, `text`, `original`, `renderings` — список `[слово, число]` («как переведено»), `refs` — OSIS-ссылки. В описании модуля: `dictionaryKind` (`strongs` | `words`, по умолчанию `words`), `license`, `author`, `title`, `name`, `language`, `features` (`strongs`, `interlinear`, `helper`).
  Короткие имена модулей: `desp-notes` → «Десницкий», `otnt-notes` → «Откр. НЗ» (остальные — `name`).
- **Разметка стиха** (перевод с номерами): `{слово|H1254 H853|TH8804|слово-оригинала}` — поля через `|`: текст · номера Стронга (через пробел) · морфология (через пробел) · слово оригинала (только в подстрочниках); `‹текст›` — слова, добавленные переводчиками (курсив). Слово с номером Стронга нажимается **целиком** (даже если там несколько русских слов); в обычном тексте нажимается каждое слово (`[\p{L}\p{M}]+(?:[-’'][\p{L}\p{M}]+)*`).
- Нормализация номера Стронга: `strongKey` — `^([HG])0*(\d+)([a-z]?)$` → буква в верхнем регистре + число без нулей + суффикс-буква (`H0430` → `H430`, `H1254a` → `H1254a`); `strongNum` (подстрочник) — то же, но **суффикс-буква отбрасывается** (`H1254a` → `H1254`); `strongsSame` (конкорданс) — сравнение без нулей, регистр буквы значения не имеет.
- Книга Нового Завета (`testament == 'NT'`) → префикс номеров `G`, любая другая (включая апокрифы) → `H`.

## 1. Нажатие на слово: выбор словаря (`word_popover.dart`)

### 1.1. Что видит человек
Небольшая карточка **у слова** (не лист), стрелочка-«клювик» направлена на слово. Слово подсвечено, пока открыта карточка и
статья, открытая из неё. Фон не затемнён.

```
              ▲
 ┌───────────────────────────────┐   ширина 230…340, не шире экрана−16; по содержимому
 │ ≈ приблизительно: перевод без… │  ← только если номера подобраны по симфонии
 │ 📍 Иерусалим  ·  Карта       › │  ← пункты функций с order < 100 (места)
 │ [H1254] Стронг: иврит        › │  ← статьи Стронга (плашка с номером, название модуля)
 │ [H853]  Стронг: иврит        › │
 │ благодать   Словарь Даля     › │  ← словари «по словам» (слово/форма, название модуля)
 │ 📍 …  ·  …                   › │  ← пункты функций с order ≥ 100
 └───────────────────────────────┘
```

Каждая строка: слева — плашка с номером (для номеров Стронга; ширина по тексту, цифры табличные) **или** жирное слово/форма статьи;
далее название модуля (одна строка, обрезается «…»); справа шеврон ›. Строка пункта функции: значок булавки, название места (жирно),
«·», подпись («Карта»), шеврон. Между частями 10 pt; поля внутри строки 12/11/10/11.

### 1.2. Откуда берутся строки и в каком порядке
1. `StudyData.ensure()` (таблицы готовы).
2. `lookupWord(text, strongs, morph, book, chapter, verse)` (алгоритм — §2) → список результатов по модулям, в каждом — список найденных статей.
   Плоский список статей: по модулям (в порядке §0.6), внутри модуля — в порядке найденных. Затем **стабильная сортировка**: сначала строки, ключ которых
   совпадает с `^[GH]\d` (статьи по номеру Стронга), потом остальные (словари «по словам»).
3. Пункты других функций (`Hub.wordMenuItems`) стабильно сортируются по `order`; те, у кого `order < 100` (места, `order = 10`), идут **выше** статей, остальные — **ниже**.
   Сейчас единственный источник — карты: если стих упоминает место с такой основой названия, пункт «**Название** · Карта» (нажатие открывает карту места).
4. Строка для словаря «по словам» показывает `label` статьи (`lemma` или `word`), а если он пуст — ключ. Один словарь может дать до 4 строк
   (до 3 по начальной форме / 2 по корню / 4 по основе) — каждая отдельной строкой.

### 1.3. Что происходит при нажатии
- **Строка статьи** → карточка закрывается (плавно, 140 мс) и открывается **статья** (§3) с `preselect = (модуль, ключ строки)` и `wordIndex`
  (§3.8). Размер окна: если выбранный модуль — `dictionaryKind == 'strongs'`, то **full**, иначе **half**.
- **Пункт места** → карточка закрывается, выполняется его действие (карта).
- **Нажатие мимо карточки** → закрывается только она; это нажатие не выделяет стих и ничего не открывает; подсветка слова снимается.
- Повторное нажатие на слово, пока карточка открыта, попадает на подложку и тоже только закрывает карточку (заново не открывает).
- Подсветка слова (`activeWord`) снимается, когда закрыты и карточка, и открытая из неё статья (при «×» — сразу всё).

### 1.4. Расположение карточки
- Ширина: `min 230`, `max min(340, ширина экрана − 16)`; высота не больше `высота экрана − 16`. Прокрутки внутри нет **[уточнить: при очень многих строках]**.
- По вертикали: **под словом** с зазором 10, если помещается (`низ слова + 10 + высота < высота экрана − 8 − нижний отступ`) **или** сверху не помещается
  (`верх слова − 10 − высота < 8`); иначе — **над словом**. Нижний отступ = максимум из безопасной зоны и высоты нижней панели вкладок / мини-плеера
  (карточку под них не ставят).
- По горизонтали: центр карточки на центре слова, но не ближе 8 к краям экрана. Стрелка: на уровне центра слова, но не ближе 16 к краям карточки;
  карточка под словом — стрелка на её верхней грани, над словом — на нижней.
- Для Swift допустим системный `popover` с `arrowEdge`/`presentationCompactAdaptation(.popover)`.

### 1.5. Пустое состояние
Если нет ни статей, ни пунктов функций: одна неактивная строка **«Статей для «{слово}» нет»** (мелкий серый текст) и ниже строка-кнопка
**«Словари в библиотеке»** (если библиотека доступна) — закрывает карточку и открывает **библиотеку модулей**.
`{слово}` — текст нажатого слова/фразы (`WordTap.token.text`).
**[Swift]** строка «Словари в библиотеке» не нажимается (WordViews.swift: только серый текст, и только если словарей 0).

## 2. Поиск статей для слова (`lexicon.dart`) — алгоритм

Вход: `text` (слово или фраза), `strongs`, `morph` (из разметки слова), `book`. Результаты запоминаются (последние 12 запросов по ключу `текст|номера|морфология|книга.глава.стих`).

### 2.1. Какие словари участвуют
`StudyData.dictionaries()` (§0.6), затем фильтр: словарь **по номерам Стронга** — только `language == 'ru'`; словарь «по словам» — любого языка;
**исключены** толковые к Стронгу из `lexiconIds = ['dvoretsky-gr']` (Дворецкий показывается разделом внутри статьи Стронга). Английский Стронг,
Abbott-Smith, BDB в списке не появляются. `dictionaryCount` = число словарей после фильтра.

### 2.2. Привязка слова к номерам Стронга (`Mapping`)
- Если у слова в разметке есть номера → режим **`exact`**: номера = `strongKey` каждого (в порядке разметки), морфология = коды слова.
- Иначе → режим **`approx`** (по симфонии RST+):
  1. Для каждого словаря с таблицей `windex` берётся запись для `text.toLowerCase()`, если пусто — для `text` в нормализованном виде (нижний регистр, «ё»→«е»).
  2. Берутся только номера, начинающиеся с префикса (`G` для НЗ, `H` иначе); для каждого `strongKey`; числа складываются по всем словарям (порядок — по первому появлению).
  3. Сортировка по числу по убыванию (при равенстве — по порядку первого появления), **не более 4**.
  4. Вес номера = его число / сумма чисел этих (оставшихся) 4; в окне статьи показывается как «S · NN %» (округление до целого процента).
  5. Нет ни одного → режим **`none`**.

### 2.3. Результаты по модулям
Для каждого словаря из §2.1 в его порядке:
- **По номерам Стронга**: для каждого номера `s` из `mapping.strongs` ищется статья с ключом `s`; нет — с ключом, дополненным нулями до 4 цифр (`H430` → `H0430`). Найдена → `Found(s, статья, режим mapping)`.
- **По словам**: `_findWord(text)` (§2.4).
- Модуль без найденных статей пропускается.
Затем **слияние симфонии** (`mergeSymphony`): модуль `rst-symphony` не показывается отдельной вкладкой, если его номера уже найдены в обычном словаре Стронга
(его «Как переведено» показывается внутри статьи Стронга); остаётся отдельным только для номеров, которых нет в словаре Стронга.

### 2.4. Поиск в словаре «по словам» (`_findWord`)
Ключи: `key = dictKey(text)` — нижний регистр, «ё»→«е», без ударений/титл (U+0300, U+0301, U+0483–U+0489), дореформенные буквы в современные (`ѣ`→`е`, `і`,`ѵ`→`и`, `ѳ`→`ф`), без конечного `ъ`.
По порядку, первое сработавшее правило возвращает результат:
1. **Точная форма** (`match = form`): ключи `[key, text.toLowerCase()]` в таблице `dict`; есть — **одна** статья (первая из найденных).
2. **Начальная форма** (`lemma`): основа слова `stem(key)` (отбрасывается первое подходящее окончание из списка длинных-к-коротким, если остаётся ≥ 3 знаков),
   к основе дописываются варианты окончаний: если слово «похоже на глагол» (`(ил|ел|ал|ял|ла|ли|ло|ет|ит|ут|ют|ат|ят|ешь|ишь|ете|ите|ем|им|вши|ться|тся|лся|лась|лись)$`) — сначала глагольные
   (`ить еть ать ять ть ти ться иться`), потом именные (`'' ь а я о е й ий ый ой ть ти ться ие ия`), иначе — наоборот; плюс «беглая гласная»
   (основа ≥ 3 знаков, оканчивается на 2 согласные → вставить `е`/`о` перед последней согласной, с `''` и `ь` на конце: «агнц» → «агнец»). Повторы убираются, само слово исключается.
   Берутся существующие ключи, **до 3** статей.
3. **Без приставки** (`root`): для приставок по порядку `пред пере воз вос раз рас при про под пре вы из ис на за от об до со по у с о`, если слово начинается с приставки и после неё
   остаётся ≥ 4 знаков: остаток либо сам есть ключ, либо проходит шаг 2; нашлось — **до 2** статей.
4. **Та же основа** (`stem`): ключи, начинающиеся с `stem(key)` (по алфавиту, до 50), без словосочетаний с пробелом (если искали одно слово).
   Сортировка: сначала те, у кого основа ключа совпадает с основой слова, затем по близости длины к слову, при равенстве — по алфавиту; **до 4** статей.
Списки окончаний, приставок и регулярное выражение глагола в `swift/Core/Lexicon.swift` совпадают с Flutter построчно (сверено).

### 2.5. Статья по номеру из ссылки внутри статьи (`lookupStrong(num)`)
Для каждого русского словаря **по номерам Стронга** (без Дворецкого): статья с ключом `num` **как есть** (без дополнения нулями), `match = exact`; потом то же слияние симфонии.
Используется для переходов «от H24» внутри статьи и в «Всё о стихе».

### 2.6. Толковые словари к номеру (`lexiconEntries(num)`)
Для `dvoretsky-gr`: если модуль установлен и включён и статья с ключом `num` имеет непустой `text` — разделом в статье Стронга (§3.6). В статью самой симфонии не добавляются.

## 3. Окно статьи (`dictionary_sheet.dart`)

### 3.1. Как открывается (`DictRequest`)
Поля: `text` (слово, оно же заголовок), `strongs`, `morph`, `ref` (стих), `pane`, `preselect (модуль, ключ)`, `autoOpen`, `origWord` (слово оригинала из подстрочника),
`wordIndex`, `fromInterlinear`, `closeToParent`. Кто как заполняет:
| Источник | text | strongs / morph | режим | размер |
|---|---|---|---|---|
| Выбор строки в карточке слова | текст слова | из разметки слова | `preselect` + `wordIndex` | Стронг — full, остальное — half |
| Нажатие на **номер Стронга** в тексте | сам номер («G26») | `[номер]`, `morph` **пусто** | `autoOpen` | full |
| Слово в подстрочнике | значение под словом, иначе слово оригинала | все номера слова, `[морфология]` | `autoOpen` + `origWord` + `fromInterlinear` | full |
| Слово в «Всё о стихе» | слово из перевода | из разметки | без автооткрытия (список словарей) | normal |
| Карточка Стронга в поиске («Статья словаря →») | номер | `[номер]` | `autoOpen` | full |
| Блок проповеди, номер Стронга | номер | `[номер]` | `autoOpen` + `closeToParent` | full |

### 3.2. Шапка, «назад», «×»
- Заголовок: **«Слово: {text}»**; если человек перешёл по ссылке на номер внутри статьи — **«Статья {номер}»** (напр. «Статья H24»). Подзаголовок всегда — стих, откуда открыто: «Ин. 3:16» (короткое название книги).
- **«‹ Назад»** (в таком порядке проверок): 1) был переход по ссылке на номер внутри статьи → вернуться к предыдущей статье (снять верхнюю из стопки переходов);
  2) открыто из подстрочника → закрыть это окно (подстрочник остался под ним); 3) выбран словарь (идёт статья) → вернуться к **списку словарей** (§3.4);
  4) иначе стрелки нет.
- **«×»**: закрыть все окна; при `closeToParent` — только это окно.

### 3.3. Предупреждения над списком/статьёй (только не при переходе по ссылке на номер)
- Режим `approx`: жёлтая рамка со значком: **«В переводе нет номеров Стронга. Примерные варианты по симфонии RST+:»** и после текста — плашки **«{номер} · {NN}%»**
  (моноширинный шрифт) для каждого номера.
- Режим не `exact` и результатов нет совсем: жёлтая рамка **«Не нашли это слово в оригинале.»**

### 3.4. Список словарей
Показывается, когда словарь ещё не выбран (нет `preselect`/`autoOpen`, либо `autoOpen`, но среди результатов нет словаря по номерам Стронга, либо вернулись «назад»).
- Результатов нет: пустое состояние, значок книги, заголовок **«Статей не найдено»**; под ним, если словарей 0: **«Нет включённых словарей.»**; затем кнопка-ссылка
  **«Открыть библиотеку»** (закрывает все окна и открывает библиотеку модулей), если библиотека доступна.
- Есть результаты: строки через 8 pt, по строке на модуль: значок книги, **название модуля** (жирно), под ним строка найденных статей через « · » (`label`, иначе ключ), к ней
  добавляется « · по основе слова», если хотя бы одна найдена по основе (`stem`); справа серая подпись (до 120 pt, две строки): **«{n} статьи»** если статей > 1, иначе
  **«по номерам Стронга»** / **«по словам»**. Нажатие выбирает модуль (первая статья) — открывается статья.

### 3.5. Вкладки статьи
Над статьёй (когда выбран модуль, не при переходе по ссылке):
1. если результатов (модулей) > 1 — **вкладки модулей** (подчёркнутые; подпись — название модуля); смена вкладки открывает первую статью модуля;
2. если у выбранного модуля найдено > 1 статьи — **таблетки статей**; подпись = ключ и, если есть, лемма (`H1254 בָּרָא`).
При переходе по ссылке на номер (стопка не пуста) вкладки модулей не показываются: берётся модуль выбранного словаря, иначе первый из `lookupStrong`. Нет статей по этому номеру — нажатие на ссылку ничего не делает.

### 3.6. Статья по номеру Стронга (`StrongEntry`) — разделы сверху вниз
Между разделами 22 pt.
1. **Шапка-карточка**: лемма крупно (иврит — по правому краю, справа налево); под ней одной строкой через « · »: транслитерация `xlit` (курсив), произношение `pron` (если отличается от `xlit`), **номер** (моноширинный, цвета акцента), язык — **«иврит / арамейский (ВЗ)»** для `H…` либо **«греческий (НЗ)»** для `G…`. Ниже — форма слова в стихе (§3.8).
2. **«Значение»** (`definition`) — номера Стронга `[HG]\d+` внутри текста кликабельны (§3.9).
3. **«Происхождение»** (`derivation`) — то же («от H24 (אָבִיב)»).
4. **Толковые словари** (Дворецкий) — раздел с названием модуля, текст; если длиннее 420 знаков — свёрнут до 7 строк и под ним ссылка **«Развернуть»**/**«Свернуть»**.
5. **«В Синодальном переводе»** — «Как переведено»: строки «слово — полоса — число»; данные `renderings` статьи, а если их нет и словарь не симфония — `renderings` статьи симфонии RST+ с тем же номером. Показаны 6 самых частых; под ними ссылка **«Ещё {n}»** (n = остальные), по нажатию показываются все.
   Полоса: длина = число / максимум (минимум 3 %, максимум 100 %); колонки: слово (40 % ширины) · полоса · число (36 pt, справа).
6. Текст статьи (`text`), если есть.
7. **Стихи**: подпись **«Где встречается»**, если `renderings` не `null` (даже пустой список), иначе **«Связанные стихи»**; плашки `refs` (подпись — короткая ссылка по OSIS: «Быт. 1:1–3»); нажатие → `openRefInOther`.
8. **Статистика слова** — блок «Где встречается · {перевод}» (§3.10).
9. **Источник**: «{название модуля} · {лицензия}»; если использована симфония — строка симфонии; для каждого толкового — «{название}: {автор} · {лицензия}».

### 3.7. Статья словаря «по словам» (`_wordEntry`)
Сверху вниз (блоки через 12): жирное слово (`word`, иначе ключ) · жёлтая рамка **без значка**, если найдено по основе: **«Найдено по основе «{text}» — возможно, это другое слово.»**, по корню:
**«Найдено по корню «{text}».»** (для точной формы и начальной формы — без рамки) · `original` (крупно, если есть) · текст статьи `text`, иначе `definition`, со ссылками на стихи (§0.4) · плашки `refs` со значком звена
(нажатие → `openRefInOther`) · источник «{модуль} · {лицензия}». `{text}` — текст, который искали (слово как в тексте).
**[Swift]** ссылок на стихи в тексте и плашек `refs` нет; вместо них есть ссылки «См. слово» (в Flutter их нет, §14).

### 3.8. «В этом стихе» и «Грамматическая форма» (под шапкой статьи Стронга)
Откуда берётся слово оригинала (`OrigInfo{orig, morph, num}`), по порядку:
1. Пришло из подстрочника (`origWord`) — используется оно.
2. Нажатое слово содержит греческие или еврейские буквы (`[Ͱ–Ͽἀ–῿֐–׿]`) и есть номера (читают LXX, Textus Receptus, OSHB): само слово без хвостовых знаков `.,;:·!?»«“”()[]`
   и есть слово оригинала; `morph` — первый код слова; `num` — первый номер (буква заглавная, нули убраны).
3. Есть `wordIndex` — номер слова в стихе RST+: считаются слова стиха до нажатого (слово с номером Стронга = 1, в обычном тексте — каждое слово по шаблону слова), условие: слово размечено и нажато в переводе
   `interlinearRuModule()` (`rst-plus`, иначе первый русский с `features.strongs` и без `features.interlinear`). Затем `ruInterlinear(ref)[wordIndex]` (§5.5); если у слова есть оригинал — берутся `orig`, `origMorph`, `num`.
Показ: если `orig.num` равен номеру статьи (оба без нулей) — строка **«В этом стихе»**: слово оригинала (иврит — справа налево) + « — {расшифровка морфологии}» (если расшифровать можно, §6).
Иначе (форма не определена) и режим `exact` — для **каждого** кода морфологии слова строка **«Грамматическая форма»**: расшифровка либо **«без расшифровки»**, затем код в скобках `(TH8804)` моноширинным.
Обе строки отделены от шапки тонкой линией; подпись серая, значение под ней. При переходе по ссылке на номер этих строк нет.
Замечания: сравнение номеров идёт с `strongKey` ключа статьи **без суффикса-буквы у оригинала** (`strongNum`), поэтому у `H1254a` строка «В этом стихе» не появится [как в коде]; у слова с несколькими номерами слово оригинала приписано только **первому**.

### 3.9. Ссылки на номера внутри статьи
В «Значении» и «Происхождении» каждое вхождение `[HG]\d+` — кнопка-ссылка. Нажатие: `lookupStrong(номер)`; нашлось — **статья показывается в этом же окне поверх** (стопка переходов, заголовок «Статья {номер}», «назад» снимает верхнюю),
вкладки модулей скрыты, форма в стихе не показывается. Не нашлось — ничего.

### 3.10. Блок статистики слова (`WordStatsBlock`) и «Все места»
Считается один раз на номер и запоминается: **сканирование идёт в отдельном потоке** по тексту перевода с разметкой: `rst-plus`, иначе первый русский с `features.strongs`, иначе первый с `features.strongs` (нет такого — блока нет).
Совпадения: в стихе берутся фразы `{слово|номера…|…}`, где среди номеров второго поля есть именно этот (регистр и нули **как в ключе**, без суффиксов).
Считаются: `total` (число совпадений), `verses` (стихов), `byBook` (по книгам, порядок Библии), `renderings` (слово в нижнем регистре → число; по убыванию, равные — по первому появлению), `refs` (стих и список слов).
Показ:
- Пока считается: индикатор и **«Считаю…»**. Если результата нет или `total == 0` — блока нет совсем.
- Подпись **«Где встречается · {название перевода}»**.
- Три плитки в ряд: `total` + «употребление|употребления|употреблений», `verses` + «стих|стиха|стихов», число книг + «книга|книги|книг».
- Если книг > 1 — полосы по 6 книгам с наибольшим числом (равные — в порядке Библии): короткое название книги без точки (колонка 56 pt) · полоса · число. Если книг больше шести —
  серая строка **«И ещё в {n} книгах.»** (n = книг − 6).
- Плашки первых 8 мест (короткая ссылка), нажатие → `openRefInOther`.
- Кнопка **«Все места ({verses})»** → окно «Все места» (§4).

## 4. «Все места» (`concordance_sheet.dart`)

### 4.1. Окно (full)
- Заголовок **«Все места · {номер}[ {лемма}]»**; подзаголовок (когда есть данные) — «{n} раз|раза|раз в {n} стихе|стихах · {перевод}» (две формы с числами; `st.total`, `st.verses`, `st.module`); «‹ Назад» всегда → предыдущее окно.
- Пока считается: **«Ищу все места…»**. Нет данных: серое **«В переводе со Стронгом этого слова нет.»**

### 4.2. Фильтры (до трёх рядов чипов, между рядами 8, под ними 12) и список
1. Ряд **книг** — только если книг > 1: «**Все книги**» (счётчик = число стихов) и по чипу на книгу в порядке Библии (короткое название без точки, счётчик = стихов в книге).
   Повторное нажатие на выбранную книгу снимает выбор.
2. Ряд **глав** — только если выбрана книга и в ней > 1 главы: «**Все главы**» (счётчик = стихов в книге) и «**Гл. {n}**» по возрастанию (счётчик = стихов). Повторное нажатие снимает выбор главы.
3. Ряд **вариантов перевода** — всегда: «**Все**» (счётчик = стихов в выбранных книге/главе) и **14** самых частых слов в выбранных книге/главе (счётчик = в скольких стихах слово встречается; стих считается один раз на слово;
   сортировка по убыванию, равные — по первому появлению). Выбор слова оставляет стихи, содержащие это слово.
Сброс: выбор книги сбрасывает главу и слово; выбор главы — слово; всегда сбрасывается число показанных (до 40).
- Строка списка: сверху короткая ссылка («Ин. 3:16», жирно, акцент), ниже текст стиха из того же перевода, **слова с этим номером выделены** (подложка акцента 22 %): слово выделяется,
  если среди его номеров есть этот (`strongsSame`). Строка — во всю ширину окна, под ней линия. Нажатие → `onOpen` (из статьи — `openRefInOther`: открывает место и закрывает все окна).
- Порция: **40** мест; внизу большая кнопка **«Показать ещё ({осталось})»** добавляет ещё 40.
- В режиме «в поиске» (карточка Стронга): те же ряды и строки, но обычным списком внутри страницы, порция 200; список ограничен частью Библии из настроек поиска; если ничего не осталось —
  **«В этой части Библии мест нет.»**

### 4.3. Карточка Стронга в поиске (`StrongSearchCard`, `Hub.strongSearchCard`)
Показывается в результатах поиска по запросу-номеру (`G26`, `H7225` …). Верх — карточка: **«Номер Стронга {номер}»**, лемма (иврит — справа налево), транслитерация, значение (первые 160 знаков и «…»), последняя строка **«Статья словаря →»**
(если вызывающий разрешил). Нажатие на карточку: запоминает запрос в истории поиска и открывает **статью full** с `autoOpen`. Под карточкой — «Ищу все места…», затем места (§4.2, режим поиска).
Если номера нет ни в одном русском словаре Стронга (кроме симфонии) — **карточка и места не показываются вовсе**.

## 5. Подстрочник (`interlinear_sheet.dart`, `interlinear.dart`)

### 5.1. Окно
- Размер **full**. Заголовок **«Подстрочник · {Ин. 3:16}»**; подзаголовок зависит от вкладки (§5.2); справа от заголовка две кнопки **‹ «Предыдущий стих»** и **› «Следующий стих»**, затем «×». «Назад» нет.
- Сверху вниз: переключатель вкладок → цитата стиха (текст стиха из перевода панели, без разметки; пусто — не показывается) → сетка слов → подпись-подсказка.
- Состояния до готовности: «Загрузка…»; докачка оригинала — **«Загружаю оригинал… {подпись}»** (подпись установки: «Загрузка» / «Подготовка» / «Готово»); у книги нет оригинала (апокрифы) — серое **«Для этой книги нет оригинала.»** (вкладок при этом нет);
  ошибка — жёлтая рамка с текстом ошибки: **«Оригинальный текст пока недоступен.»** (оригинал или Септуагинта не найдены в каталоге), **«Подстрочник к Вульгате пока недоступен.»**; любая другая ошибка (например, сеть) — её текст как есть без префикса «Exception: »
- Слов нет — серое **«В оригинале этого стиха нет.»**; для Септуагинты и Вульгаты, когда слова есть, над сеткой серое **«Под словами — значения по словарю, а не перевод.»**

### 5.3. Слово-столбик (`_Cell`) и расположение
Слова идут **строками с переносом** (промежуток 6 по горизонтали, 10 по вертикали); **у вкладки «Еврейский» порядок справа налево** (строка начинается справа), у остальных — слева направо. Столбик (по центру, не уже 35):
1. **слово оригинала** (иврит — справа налево, шрифт для иврита); 2. **чтение русскими буквами** курсивом мелко (для греческого и иврита — `translit`, §5.7; для Вульгаты — начальная форма-лемма; нет — пустая строка для выравнивания);
3. **значение/перевод** цветом акцента: полужирно, если это слово из перевода; бледно-курсивом (≈ 55 % непрозрачности), если это «догадка по словарю» (`guess`); 4. **номер Стронга без буквы** (`G976` → `976`) мелко серо; нет — пустая строка.
Нажатие — только если у слова есть номера Стронга (у Вульгаты нет — не нажимаются): открывает **статью full** с автооткрытием и «назад» → подстрочник (§3.1).

### 5.4. Шаги по стихам
Кнопки ‹ ›: соседний стих **внутри этой же книги** по оригинальному тексту (счёт глав и стихов — по базе оригинала: `MAX(chapter)`, `MAX(verse)`); с первого стиха назад — на последний стих предыдущей главы; с последнего вперёд — на 1-й стих следующей; у первой главы назад и у последней вперёд — ничего. Читалка не листается; окно перезагружается. Модуль оригинала для шагов: `lxx-swete` / `vulg-interlinear` / `oshb` (ВТ) / `byz-rp2018` (НТ).

### 5.5. Сопоставление слов по номерам Стронга (`alignVerse`) — для вкладок «Синодальный»/«Еврейский»
Нужны: оригинал (`oshb` для ВТ, `byz-rp2018` для НТ; нет установленного → результата нет, окно перед этим докачивает его из каталога) и размеченный русский (`rst-plus`, иначе первый русский с номерами без `interlinear`). Токены обоих стихов — по `tokenize` (разметка §0.6; слово с пустыми номерами разбивается на обычные слова).
1. **Оригинал.** Для каждого слова: `OWord{текст без знаков кантилляции [U+0591–U+05AF, U+05BD, U+05C0], ключ = strongNum(первый номер), все номера, первая морфология}`. Слова с ключом складываются в **очереди по ключу** (в порядке стиха).
   Русского текста нет — результат: только слова оригинала.
2. **Группы-синонимы** (в греческом у всех форм глагола один номер, а в RST+ у форм свои): `{G1510 G2258 G2071 G2070 G2075 G2076 G2468 G5600 G1488 G1526 G2277}` («быть»), `{G3004 G2036 G2046 G4483}` («говорить»), `{G3708 G1492 G3700}` («видеть»),
   `{G2068 G5315}` («есть»), `{G5143 G1408}` («бежать»). Взять из очереди ключа `k`: перебираются номера группы `k` (или только `k`) в этом порядке, берётся первое слово из первой непустой очереди; запоминается как «последнее для `k`».
3. **Обход русских слов** по порядку. Знаки между словами: открывающие `«(„“‘[` в конце промежутка идут к **следующему** слову, остальное — приписывается к **предыдущему**; любой непустой промежуток — «разрыв».
   Для слова с номерами:
   - ключ = `strongNum(первый номер)`;
   - если ключ **равен ключу предыдущего слова и разрыва не было** («будет говорить» — два русских слова на одно): слово добавляется к значению предыдущего слова оригинала, своего оригинала у него **нет**;
   - иначе берётся слово оригинала по §5.5.2; русское слово добавляется в его список «перевод» (`gloss`); оригинал слова = взятое, а если очередь пуста — **последнее взятое для этого ключа**;
   - для каждого **дополнительного** номера слова из очереди берётся (и теряется) по слову оригинала.
   Слово без номеров оригинала не получает.
4. Результат: `ru` — все русские слова (с оригиналом, его морфологией, номером) — используется для §3.8; `orig` — все слова оригинала со списками русских слов.
**Вкладка «Синодальный/Еврейский»** показывает `orig` в порядке оригинала: значение = русские слова через пробел (жирно). Для слов оригинала **без** русского слова: если установлена симфония `rst-symphony`, слово не `G3588`/`H853` (артикль и частица прямого дополнения — «молчащие») и его номер не входит в группы синонимов §5.5.2, подставляется первый вариант из `renderings` статьи этого номера (самый частый), значение — **бледное** (`guess`). Иначе значение пусто.

### 5.6. Остальные вкладки
- **Винокуров** (только НЗ): модуль `vin-interlinear` ставится сам при первом открытии вкладки (нет в каталоге — вкладка пустая «В оригинале этого стиха нет.»). Слова идут в порядке византийского текста; в разметке слова `{русское|номера||греческое}` — над русским значением показывается **греческое слово** (4-е поле), значение = русский текст (если он «·» — пусто), номер = первый номер. Морфологии нет. Значение — **жирное**, не бледное.
- **Септуагинта** (только ВТ): модуль `lxx-swete`; слова в порядке LXX, у каждого — номер и значение, **всегда бледное** (`guess`). Подбор значения по номеру `N` слова:
  1. слова синодального стиха — из первого установленного из `rst-plus`, `rst`, `rst-dc` (с разметкой убранной);
  2. варианты `N` — все `renderings` симфонии для номеров группы `N` (§5.5.2), по убыванию числа (равные — по порядку), очищены от всего кроме букв, пробелов и «-», приведены к нижнему регистру/«ё»→«е», пустые отброшены;
  3. слова «артикль/частица» (`G3588`,`H853`) и слова без номера значения не получают; для остальных: **проход 1** — для каждого слова LXX по порядку берётся первый вариант, который **точно** совпадает с ещё не занятым словом синодального стиха (слово «занимается» один раз);
     **проход 2** — для оставшихся то же с «близким» совпадением: общее начало ≥ 3 знаков и расхождение не более чем на 2 знака с конца (`_near`); **проход 3** — для оставшихся: первый вариант, иначе начало статьи русского словаря `strongs-ru-greek` (`definition` до первой запятой, `;` или `(`).
  4. Занятое синодальное слово записывается в значение в том виде, как оно в стихе.
- **Вульгата** (оба Завета): модуль `vulg-interlinear` (ставится сам; нет — ошибка «Подстрочник к Вульгате пока недоступен.»). Слова — ячейки через пробел вида `форма|лемма|значение`, подчёркивание в значении = пробел.
  Столбик: форма, под ней лемма, значение бледное. Номеров и нажатия нет.

### 5.7. Чтение оригинала русскими буквами (`translit.dart`)
Применяется к слову оригинала: есть буквы U+0590–U+05FF → иврит; иначе есть U+0370–U+03FF или U+1F00–U+1FFF → греческий; иначе пусто.
**Греческий (`greekToRu`)**: слово раскладывается в NFD (в Dart для этого таблица `greek_nfd.dart`: precomposed-буквы → основа + знаки; в Swift — `decomposedStringWithCanonicalMapping`). Густое придыхание: регулярное выражение
`^[^M]*M*U+0314` на раскладе (`M` = диапазон U+0300–U+036F), то есть U+0314 находится в первой группе знаков слова, или слово начинается с «ῥ». Затем знаки U+0300–U+036F убираются, текст в нижний регистр.
Разбор слева направо: сначала пары `αυ→ау, ευ→эу, ηυ→эу, ου→у, υι→юи, γγ→нг, γκ→нк, γξ→нкс, γχ→нх`, иначе буква по таблице
`α а, β б, γ г, δ д, ε е, ζ дз, η э, θ т, ι и, κ к, λ л, μ м, ν н, ξ кс, ο о, π п, ρ р, σ с, ς с, τ т, υ ю, φ ф, χ х, ψ пс, ω о` (латинские и русские буквы остаются как есть, прочее отбрасывается).
Если было густое придыхание и результат не начинается с «р» — спереди добавляется «х».
**Иврит (`hebrewToRu`)**: знаки кантилляции `[U+0591–U+05AF, U+05BD, U+05BE, U+05C0, U+05C3]` убираются. Имя Божье: если буквы (без огласовок) оканчиваются на «יהוה» — результат «**Иегова**» (с большой буквы); если перед ним
стоит приставка (ла-, ва-, ми…) — транслит приставки + «иегова» (маленькая). Иначе слово делится на согласные с их знаками; для каждой согласной:
согласные: `א ''`, `ב в`, `ג г`, `ד д`, `ה х`, `ו в`, `ז з`, `ח х`, `ט т`, `י й`, `כ х`, `ך х`, `ל л`, `מ м`, `ם м`, `נ н`, `ן н`, `ס с`, `ע ''`, `פ ф`, `ף ф`, `צ ц`, `ץ ц`, `ק к`, `ר р`, `ש ш`, `ת т`;
с дагешем (U+05BC) `ב→б, כ/ך→к, פ/ף→п`; `ש` со знаком син (U+05C2) → «с»; «ה» в конце слова без дагеша — не читается (`''`); «י» без огласовок, не первая, после «и/е/э» — не читается;
«ו» с дагешем и без огласовки (шурук) → «у» (вместо согласной), «ו» с холамом (U+05B9), не первая → «о»;
огласовки: `U+05B0 е, 05B1 е, 05B2 а, 05B3 о, 05B4 и, 05B5 е, 05B6 е, 05B7 а, 05B8 а, 05B9 о, 05BA о, 05BB у, 05C7 о`; берётся первая гласная буквы, но «е» от шевы у **последней** буквы не берётся;
шва (U+05B0) без других гласных (диапазон `[U+05B1–U+05BB, U+05C7]` в знаках буквы отсутствует) даёт «е» только у **первой** буквы слова, иначе ничего.

## 6. Расшифровка морфологии (`morph.dart`, `morph_data.dart`)

`describeMorph(код)` → русская строка или `null` («не знаем» — тогда показывается сам код/«без расшифровки»). Данные — две константы в `morph_data.dart` (`morphDataJson`, `greekTvmJson`), сгенерированы из `morphData.json` и `greekTvm.json`
веб-версии; **в Swift перенести JSON дословно** (в ресурсы) и повторить разбор. Каждый термин показывается через `t(термин)` (перевод по русскому тексту как ключу).

### 6.1. Какой разбор для какого кода (по порядку проверок)
1. `^T?([HG])(\d+)$` — **код TVM** (RST+ для слов Стронга: `TH8804`, `TG5656`; без `T` — тоже):
   - `H` → таблица форм иврита (§6.2): «{порода}, {форма}» (напр. «Кал (Qal), перфект»); номера нет в таблице → `null`.
   - `G` → по `greekTvmJson[число]` берётся код Робинсона вида `V-AAI`; из части после первого «-» разбираются **три слота** `tense, voice, mood` (по таблицам §6.3, все три обязательны);
     результат «глагол, {время}, {залог}, {наклонение}» (лица, числа, падежа в TVM нет). Нет числа в таблице или не разобрался → `null`.
2. Иначе, если код соответствует `^[HA][A-Za-z0-9/]*$`, **не содержит «-»** и не является ключом греческих частей речи (`HEB`, `ARAM`) — **код OSHB** (иврит/арамейский), §6.4. Первая буква: `H` иврит / `A` арамейский.
3. Иначе — **код Робинсона** (греческий), §6.3.
Любая ошибка разбора (в том числе исключение) → `null`.

### 6.3. Греческий (Робинсон), структура `morphDataJson.greek`
- Разделитель «-»; **суффиксы** в конце кода (после тела) — если последний элемент(ы) есть в таблице суффиксов, они отрезаются: `S` превосходная степень · `C` сравнительная степень · `N` отрицательное · `I` вопросительное ·
  `K` слитно с καί (красис) · `ATT` аттическая форма · `ABB` сокращённая запись. Первый элемент — **часть речи**, остальное (склеенное «-») — **тело**, оно разбирается по слотам первой подходящей **форме** части речи;
  тело должно быть разобрано **целиком** (короткого нельзя). Слот разбирается «самым длинным ключом» (до 4 знаков).
- Части речи и формы (слоты по порядку; `when` — допустимые значения слота): `V` глагол: `[tense voice mood]` (mood = `N`) · `[tense voice mood - person number]` (mood ∈ I,S,O,M) · `[tense voice mood - case number gender]` (mood = P);
  `N` существительное и `A` прилагательное: `[case number gender]` | `[indecl]`; `T` определённый артикль, `R` относительное, `C` взаимное, `D` указательное, `K` соотносительное, `I` вопросительное, `X` неопределённое, `Q` соотносительное/вопросительное местоимение: `[case number gender]`;
  `P` личное местоимение: `[person case number]` | `[case number gender]` | `[person case number gender]`; `F` возвратное: `[person case number gender]`; `S` притяжательное: `[owner case number gender]`;
  без слотов: `ADV` наречие, `CONJ` союз, `COND` условная частица, `PRT` частица, `PREP` предлог, `INJ` междометие, `ARAM` арамейское слово, `HEB` еврейское слово. Русские названия частей речи — в JSON (`pos.*.ru`).
- Слоты: `tense` P настоящее время · I имперфект · F будущее время · 2F второе будущее · A аорист · 2A второй аорист · R перфект · 2R второй перфект · L плюсквамперфект · 2L второй плюсквамперфект;
  `voice` A действительный · M средний · P страдательный · E средний или страдательный · D средний (отложительный) · O страдательный (отложительный) · N средний или страдательный (отложительный);
  `mood` I изъявительное · S сослагательное · O желательное (оптатив) · M повелительное · N инфинитив · P причастие; `person` 1/2/3-е лицо; `case` N именительный · G родительный · D дательный · A винительный · V звательный; `number` S единственное · P множественное;
  `gender` M мужской · F женский · N средний; `owner` 1S мой · 1P наш · 2S твой · 2P ваш; `indecl` PRI несклоняемое имя собственное · NUI несклоняемое числительное · LI несклоняемое название буквы · OI несклоняемое слово.
- Вывод: «{часть речи}, {значение слота 1}, …, {суффикс}» через «, » (слоты «-» и прочерки не выводятся). Примеры: `V-PAI-3S` → «глагол, настоящее время, действительный залог, изъявительное наклонение, 3-е лицо, единственное число»;
  `N-NSF` → «существительное, именительный падеж, единственное число, женский род»; `TG5656` → «глагол, аорист, действительный залог, изъявительное наклонение».

### 6.4. Иврит и арамейский (OSHB), структура `morphDataJson.hebrew`
- Код `H…`/`A…`: первая буква — язык, остальное делится по «/» на **сегменты** (приставки и слово: `HC/Vqw3ms`); каждый сегмент — первая буква часть речи + тело. Все сегменты должны разобраться, иначе `null`.
- Слот «не указано» — `x` (пропускается). Тело **может быть короче** формы (остальные слоты просто не выводятся). Подбор формы части речи — как в греческом (`when` для глагола — по слоту `conj`).
- Части речи и формы: `A` прилагательное `[adjType gender number state]`; `C` союз; `D` наречие; `N` существительное `[nounType gender number state]`; `P` местоимение `[pronType person gender number]`; `R` предлог `[prepType]`;
  `S` суффикс `[suffixType person gender number]`; `T` частица `[particleType]`; `V` глагол: `[stem conj person gender number state]` при conj ∈ {p,q,i,w,h,j,v} · `[stem conj gender number state]` при conj ∈ {r,s} · `[stem conj]` при conj ∈ {a,c}.
- Порода `stem` зависит от языка (отдельные таблицы для `H` и `A`, напр. `q`→«Кал» у иврита и «Пеаль» у арамейского). Остальные слоты: `conj` p перфект (катал) · q вав-последовательный перфект (векатал) · i имперфект (йиктоль) · w вав-последовательный имперфект (ваййиктоль) ·
  h когортатив · j юссив · v повелительное · r действительное причастие · s страдательное причастие · a абсолютный инфинитив · c инфинитив конструкт; `gender` m/f/b/c; `number` s/p/d; `state` a абсолютное · c сопряжённое · d определённое; и т. д. — полностью в JSON.
- Вывод: для каждого сегмента «{часть речи}, {значения слотов}»; сегменты соединяются « + ». Пример: `HC/Vqw3ms` → «союз + глагол, Кал, вав-последовательный имперфект (ваййиктоль), 3-е лицо, мужской род, единственное число». Язык (иврит/арамейский) в строку не входит.

## 7. Параллельные места (`xrefs_sheet.dart`)

### 7.1. Значок `[⇅ n]` после стиха (`decorators.dart`)
Показывается, если включено «показывать» (`showXrefButtons`) и **не** включён режим чтения (`focusMode`) и n > 0. Курсив, серый, размер 0,72 от размера шрифта текста, отступ слева 0,2 em. Нажатие открывает окно параллельных мест (модуль — перевод этой панели).
n = число ссылок в таблице `xrefs` самого перевода **плюс** сумма `n` во всех включённых модулях параллельных мест (`crossrefs`), **без удаления повторов** (поэтому в окне строк может быть меньше). Порядок значков после стиха: `[⇅ n]` → иллюстрация → названия комментариев.

### 7.2. Окно
- Нормальная высота. Заголовок **«Параллельные места · {Ин. 3:16}»**, подзаголовок — название перевода панели. «Назад» нет.
- Загрузка: «Загрузка…» (список строится после показа окна — у «Бытия 1:1» ссылок десятки).
- Список ссылок: из самого перевода, затем из модулей параллельных мест (порядок модулей §0.6); повторы убираются по строке OSIS. Источник ссылки в интерфейсе **не показывается**.
- Нет ссылок: цитата стиха (если есть) и пустое состояние (значок звена) **«Параллельных мест нет»**.
- Есть ссылки: сверху **цитата исходного стиха** (не выше 34 % высоты экрана, со своей прокруткой; остаётся на месте, пока прокручивается список), под ней список. Первая строка списка: заголовок **«Места · {n}»** со значком-подсказкой ⓘ (нажатие показывает `belowHint`, §0.5).
- Строка: во всю ширину окна, под ней линия. Жирная ссылка цветом акцента (**полное** название книги: «От Иоанна 3:16–18») и текст по ссылке из **того же перевода** (до 4 стихов диапазона; при нескольких стихах у каждого маленький верхний индекс с номером; если диапазон длиннее — «…» серым;
  диапазон через главы — продолжается в следующей главе, пока стихи есть). Нет стиха в переводе → серое **«В переводе {перевод} нет этой книги.»** Тексты считаются по мере прокрутки.
- Нажатие на строку → `openRefBelow(pane, начало ссылки)` (§0.5): место открывается в новой панели под исходной (или в панели ниже), все окна закрываются.

## 8. Комментарии

### 8.1. Названия после стиха и раскрытие под стихом (`decorators.dart`)
Условия показа: не режим «Как книга» (`bookMode`). Какие модули: включённые комментарии, у которых есть статья, **начинающаяся ровно с этого стиха** (в том числе введения),
отфильтрованные по настройке «какие видны после стиха» (`inlineCommentaries` — список id; ключа/не список = все) и по **языку**: язык комментария должен совпадать с языком перевода панели (у синодального — русские, у KJV — английские).
Два вида (`commentView`):
- **`below`** (по умолчанию): после значков стиха идут **короткие названия** источников («Лопухин», «Десницкий») — мелко (0,68 от размера шрифта), полужирно, приглушённо; раскрытый — цветом акцента. Названия — только для источников, у которых после отбрасывания «введений»
  (заголовок статьи начинается с «Введение» либо равен «Introduction») остались статьи. Нажатие на название **раскрывает комментарий под стихом**, повторное — сворачивает; нажатие на другое название того же стиха меняет текст. Одновременно раскрыт **только один** комментарий на весь экран читалки
  (раскрытие в другом месте сворачивает прежний).
- **`tag`**: после стиха «метка» — название поднятым мелким жирным серым текстом; нажатие открывает **окно комментария** этого модуля (§8.3).
В режиме `tag` метка ставится **каждому** источнику, у которого есть статья с этого стиха (в том числе только введение), и введения над заголовками не показываются.

### 8.2. Раскрытый комментарий (`CommentPanel`)
Под стихом, во всю ширину колонки, слева вертикальная линия акцента 3 pt, отступ слева 12. Сверху маленький жирный заголовок цвета акцента — **полное название книги комментария** (`title`, иначе `name`; у введений — «{заголовок статьи} · {название}»),
ниже текст: размер `commentaryFontSize` (по умолчанию 19), строка 1,6, цвет текста чуть приглушён (86 %). Текст нескольких статей стиха склеивается «\n\n» (без введений).
Появление/сворачивание — плавно (260 мс, высота и прозрачность). **Нажатие на текст сворачивает**, **долгое нажатие** открывает **окно комментариев** этого модуля (там ссылки на стихи кликабельны).

### 8.3. Введение к книге и главе (`chapterIntro`, `IntroComments`)
Условия те же (не `bookMode`, не `tag`), источники берутся у **1-го стиха главы** (для книги — у 1-го стиха 1-й главы). Берутся только статьи с заголовком-введением:
для книги — заголовок начинается с «Введение в книгу» (или в главе 1 равен «Introduction»), для главы — прочие введения («Введение к главе», «Introduction» не в главе 1).
Расположение в читалке: введение книги — **над названием книги** (только в 1-й главе), введение главы — **над заголовком «Глава N»** («Псалом N» у Псалтири), в 1-й главе — после названия книги.
Вид: ряд коротких названий **«{заголовок введения} · {короткое имя модуля}»** (напр. «Введение в книгу · Лопухин») мелко, приглушённо, промежутки 14 по горизонтали / 4 по вертикали. Нажатие на название раскрывает под рядом текст (линия акцента слева, заголовок
«{заголовок} · {название книги комментария}»), повторное нажатие или нажатие на текст сворачивают (260 мс); **долгое нажатие** на название или на раскрытый текст — окно комментариев (на 1-м стихе главы). Состояние раскрытия — внутри блока (не общее).

### 8.4. Окно комментариев (`commentary_sheet.dart`)
- Высота normal. Заголовок **«Комментарий · {Ин. 3:16}»**, подзаголовок — полное название книги выбранного комментария (`title`; нет — пусто).
- Данные: `commentaryFor(стих)` — все включённые комментарии (**без** фильтра языка и без `inlineCommentaries`), у которых есть статьи, начинающиеся ровно с этого стиха; статьи комментария к диапазону лежат у его первого стиха,
  поэтому для 3-го стиха диапазона 1–5 окно будет пустым [как в коде]. Порядок модулей — §0.6.
- Выбранная вкладка: модуль, из которого открыли (`moduleId`), если он есть в результатах, иначе первый.
- «Загрузка…»; нет модулей — пустое состояние (значок сообщения) **«Комментариев к этому стиху нет»**.
- Модулей > 1 — **вкладки** (подчёркнутые) с названиями модулей. Ниже для каждой статьи выбранного модуля: заголовок `{полная ссылка статьи: «От Иоанна 3:16–18»}` + (если есть заголовок статьи) ` · {заголовок}`, под ним текст размера `commentaryFontSize`, строка 1,6, со ссылками на стихи (§0.4).
- Ссылка на стих в тексте → `openRefInOther` (§0.5). Внизу «Источник»: «{название} · {автор} · {лицензия}» (пустые части пропускаются).

## 9. Сравнение переводов (`compare_sheet.dart`)

### 9.1. Окно
- Заголовок **«Сравнение переводов»** (высота tall) либо **«Читать параллельно»** (режим `pick`, высота normal); подзаголовок — подпись выделения с **полным** названием книги: «От Иоанна 3:16» · «От Иоанна 3:16–18» (подряд идущие стихи одной главы) ·
  «От Иоанна 3:16, 18» (не подряд) · при разных главах/книгах — ссылки через «; ». Выделенные стихи сортируются: порядок книг, глава, стих.
- Модули: все включённые переводы **кроме** вспомогательных (`features.helper`), подстрочников (`features.interlinear`) и оригиналов `oshb`, `byz-rp2018`. **Открытый перевод — первым**, затем остальные в порядке хранилища модулей **[уточнить порядок]**.
- Для каждого перевода текст = выбранные стихи этого перевода: один стих — его текст без разметки; несколько — каждая строка `«{номер стиха} {текст}»`, строки через «\n»; стихи, которых в переводе нет, пропускаются.
- «Загрузка…» (тексты собираются после показа окна).
- Сверху (в этом порядке): если других переводов нет — пустое состояние (значок библиотеки) **«Другой перевод не установлен»** + **«Установите ещё один перевод из каталога.»** + ссылка **«Открыть каталог»** (закрывает все окна и открывает библиотеку); затем, если у переводов больше одного языка, —
  **ряд языков** (чипы): «**Все языки**» и по чипу на каждый язык. Порядок языков: `ru en zh hi es ar fr pt id de ja tr sw vi tl ko fa it pl uk ro nl el sv cs sr sq hy hr da nb be eo he grc la cu syr`, неизвестные коды — после них (порядок между ними не определён: сортировка в Dart нестабильна — в Swift брать порядок появления), пустой код («Другие») — последним.
  Подпись языка: при русском интерфейсе — таблица (`ru` Русский, `en` English, `zh` Китайский, `hi` Хинди, `es` Испанский, `ar` Арабский, `fr` Французский, `pt` Португальский, `id` Индонезийский, `de` Немецкий, `ja` Японский, `tr` Турецкий, `sw` Суахили, `vi` Вьетнамский, `tl` Тагальский,
  `ko` Корейский, `fa` Персидский, `it` Итальянский, `pl` Польский, `uk` Українська, `ro` Румынский, `nl` Нидерландский, `el` Новогреческий, `sv` Шведский, `cs` Чешский, `sr` Сербский, `sq` Албанский, `hy` Армянский, `hr` Хорватский, `da` Датский, `nb` Норвежский,
  `be` Белорусский, `eo` Эсперанто, `he` Иврит, `grc` Греческий, `la` Латынь, `cu` Церковнославянский, `syr` Сирийский; неизвестный — код заглавными); при другом языке интерфейса — название языка на нём из списка языков приложения, иначе код заглавными; пустой код — «Другие».
  Выбор языка скрывает переводы других языков; **открытый перевод остаётся всегда**.
- Список переводов (без промежутков, линии между, во всю ширину): шапка строки — **название** (жирно) · серым **полное название** (`title`) либо **«открыт сейчас»** у открытого · справа (не у открытого) значок «две колонки» (подсказка **«Читать параллельно»**) · ниже текст шрифтом читалки (16,3 pt, строка 1,5).
  Нет текста — серое **«В этом переводе нет такого места.»**
- **Различия**: для перевода **того же языка**, что и открытый, и когда у обоих есть текст, слова, которых нет в открытом переводе, подсвечены (оранжевая подложка ≈ 38 %, скругление 3). Алгоритм: слова обоих текстов нормализуются (нижний регистр, «ё»→«е», убрано всё кроме букв и цифр Unicode);
  наибольшая общая подпоследовательность слов (динамическое программирование; на ничьей шаг по открытому тексту); слова другого текста вне подпоследовательности — «отличаются»; слова, состоящие только из знаков, не подсвечиваются; пробелы сохраняются. Номера стихов в многостишном тексте — тоже слова. Результат считается один раз.
- Внизу большая кнопка **«Другие переводы»** (значок библиотеки): закрывает все окна и открывает библиотеку.

### 9.2. «Читать параллельно» (значок у перевода)
Берётся первый выделенный стих. В переводе нет такой **книги** → уведомление внизу экрана **«В переводе {перевод} нет книги «{книга}»»** (окно остаётся). Иначе: откуда = панель окна (или первая панель с открытым переводом).
Панелей меньше двух → экран делится: вторая панель с этим переводом, затем переход на стих. Панелей две и больше → целевая панель = 1, если откуда 0, иначе 0; в ней меняется перевод на выбранный и переход на стих (мигает). Все окна закрываются.

### 9.3. Как окно открывается из панели выделения (`_parallel`, `selection_bar.dart`)
Значок «языки / Читать параллельно»: если установлен **ровно один** другой перевод (без оригиналов) — сразу открывает его в соседней панели (как выше, без окна); иначе — это же окно сравнения в режиме `pick` (высота normal, заголовок «Читать параллельно»).
Сравнение с меню «⋯» — режим обычный (tall). После открытия выделение снимается.

## 10. «Всё о стихе» (`verse_guide.dart`)

- Высота tall. Заголовок **«Всё о стихе · {Ин. 3:16}»**. «Назад», подзаголовка нет. Загрузка: «Загрузка…». Блоки показываются **только если есть что показать** (общего «пусто» нет), сверху вниз:
1. **Цитата** — текст стиха в переводе панели (всегда, даже пустая).
2. **«Ваши пометки»** (значок блокнота) — только если есть заметка, цвет выделения или подборки: строка «цветная точка + название цвета» (имя, которое человек задал цвету, иначе стандартное); карточка заметки (текст заметки; **нажатие открывает редактор заметки** для этого стиха);
   серая строка **«В подборках: {названия через запятую}»**.
3. **«Слова оригинала · по {перевод}»** (значок «языки») — перевод = первый включённый русский с `features.strongs` (**[уточнить]**: может оказаться подстрочником); слова стиха, у которых есть номер Стронга, **без повторов по первому номеру** (номер берётся как записан в разметке, без `strongKey`; поэтому `H0430` не найдёт статью `H430`). Сетка карточек: число колонок `⌊(ширина + 6) / 156⌋`, не менее 1 и не более 8, промежутки 6.
   Карточка: **слово из перевода** (жирно) · **лемма** (иврит — справа налево) · серая строка в один ряд **«{номер} · {xlit} · {значение}»** (значение = `definition` статьи, иначе первое слово из `renderings`; части, которых нет, пропускаются). Статья берётся `lookupStrong(номер)`: словарь с id на `strongs-`, иначе первый. Нажатие → окно статьи (normal) со **списком словарей** по этому слову (без автооткрытия) — вернуться к «Всё о стихе» нельзя (§0.1).
4. **«Комментарии»** (значок сообщения) — карточка на модуль: жирное название модуля + начало первой статьи (первые 220 знаков и «…»). Нажатие → окно комментариев этого модуля.
5. **«Параллельные места»** (значок звена) — **первые 8** ссылок: жирная короткая ссылка + текст **одного** стиха (первого). Нажатие → `openRefBelow`.
6. **«Места на карте»** (значок булавки) — плашки по названиям мест, упомянутых в стихе (без повторов по id); нажатие **закрывает все окна** и открывает карту места во второй половине экрана.
Карточки: строки через 6 pt; текст 15 pt.

## 11. Иллюстрации

### 11.1. Значок после стиха
Показывается при включённой настройке `showIllustrations` и **не** в режиме «Как книга». Число картинок у стиха = сумма по включённым модулям иллюстраций, **не более 2**. Значок: плашка с картинкой (0,62 от размера шрифта, отступ слева 0,3 em), цифра **2** — только если картинок две.
Нажатие открывает просмотр с картинками стиха (без повторов по адресу, не более 2).

### 11.2. Просмотр (`image_viewer.dart`) — весь экран, тёмный фон
- **Сверху**: слева короткая ссылка стиха («Ин. 3:16», жирно); если картинок > 1 — **«{n} из {total}»**; справа круглая **×** («Закрыть»).
- **Центр**: картинка по адресу `img` целиком (вписана), загрузка с заголовком `User-Agent: AOBible/1.0 (https://aobible.app)`; пока грузится — индикатор; не загрузилась — по центру **«Картинка не загрузилась. Проверьте интернет.»** Картинки в приложении не хранятся.
  При >1 картинке слева и справа по центру круглые стрелки **«Предыдущая картинка»**/**«Следующая картинка»** (на краях тусклые, не нажимаются). Справа внизу: **«Уменьшить»** (тусклая при 1×), **«Увеличить»** (тусклая при 5×).
- **Низ**: заголовок картинки (жирно, если есть); строка **«{автор}, {год} · {лицензия} · источник ↗»** (части без значения пропускаются); «источник» — ссылка `src`, открывается во внешнем браузере.
- **Жесты** (сырые касания):
  - два пальца — масштаб 1…5× по расстоянию между пальцами вокруг их середины, одновременно сдвиг; при масштабе ≤ 1 сдвиг сбрасывается; уйти за край увеличенной картинки нельзя (поле = ширина·(s−1)/2, высота аналогично);
  - один палец по **увеличенной** картинке — сдвиг;
  - один палец по картинке 1× вниз (больше 12 pt вниз и вертикаль > 1,2·горизонталь) — картинка едет за пальцем и немного уменьшается (на `min(сдвиг, 400)/2000`), фон бледнеет (прозрачность не ниже 0,35, `1 − сдвиг/400`);
    отпустили: сдвиг > 110 pt **или** средняя скорость > 0,6 pt/мс → закрыть просмотр, иначе вернуть;
  - короткое нажатие (до 350 мс, палец сдвинулся не больше 8 pt): масштаб > 1,05 → вернуть 1×; иначе увеличить **×2,5** в точке нажатия;
  - горизонтальный сдвиг на 1× (> 60 pt): влево — следующая картинка, вправо — предыдущая (крайние — не уходят);
  - кнопки лупы: ×1,6 / ÷1,6 вокруг центра картинки (в пределах 1…5).
  Смена картинки сбрасывает масштаб и сдвиг.

## 14. Расхождения со Swift

Проверено чтением: `swift/AOBible/Views/StudyViews.swift`, `WordViews.swift`, `MapsView.swift` (подстрочник, карта), `ReaderView.swift` (вызовы окон, `CompareSheet`, панель выделения),
`Core/Lexicon.swift`, `Core/StudyData.swift`, `Core/SearchEngine.swift`, `Views/SearchPage.swift`, `Core/PanesStore.swift`, `Core/Markup.swift`, `Core/Starter.swift`. Не проверено: содержимое модулей `rst-interlinear`/`vin-interlinear`, подсветка нажатого слова в `ReaderView`.

### 14.1. Совпадает с Flutter (проверено)
- `Core/Lexicon.swift`: алгоритм поиска статей (окончания, приставки, беглая гласная, правило глагола, привязка по симфонии `windex`, порядок и число статей `form/lemma/root/stem`, слияние симфонии, фильтр `ruStrongs`) совпадает с `lexicon.dart` построчно.
- Таблицы изучения (`dict`, `windex`, `comm`, `xr`, `xrefs`, `illus`, `st_ready`) строятся при установке (`ModuleStore.buildStudy`) и читаются теми же запросами (`Core/StudyData.swift`).
- Порядок строк в карточке слова (`WordSheet`): примечание «≈ приблизительно…» → места → статьи Стронга → прочие словари; высота окна: Стронг — `.large`, остальное — `.medium` (через `detent`).

### 14.2. Чего нет в Swift
1. **Карточка слова** — `WordViews.swift: WordSheet` это лист с `NavigationStack`, а не карточка со стрелкой; нет позиционирования у слова; строка «Словари в библиотеке» не нажимается (§1.5); нет `wordIndex` (форма слова в статье не определяется); выбор строки не закрывает карточку, а проталкивает статью в тот же `NavigationStack` (внутри листа есть системная стрелка «назад» к списку).
2. **Статья Стронга** (`WordViews.swift: EntryDetail`, `StudyViews.swift: EntryView`): нет шапки-карточки (лемма крупно, `xlit · pron · номер · язык`); нет «В этом стихе»/«Грамматическая форма» и вообще **расшифровки морфологии** (`morph.dart` не портирован: нет `describeMorph`, таблиц `morphData`/`greekTvm`);
   нет вкладок модулей и таблеток статей (вместо них — список секций «ключ · модуль» и `NavigationLink` на каждую статью); нет заголовков «Статья {num}»/«Слово: {word}» и подзаголовка со стихом (заголовок — просто слово); нет ссылки-стопки «от H24» с «назад» к прежней статье
   (есть `NavigationStack` и `path`, но без правила «назад» §3.2); нет блока «Источник/лицензия» и плашек `refs` («Где встречается»/«Связанные стихи»); нет блока статистики (`WordStatsBlock`: плитки, полосы по книгам, «Считаю…», «И ещё в {n} книгах.», 8 мест);
   «Как переведено» — плоская строка «слово ×N, …» вместо полос с «Ещё {n}», без подписи «В Синодальном переводе» и **без подстановки `renderings` из симфонии**, когда у самого словаря их нет; Дворецкий — без сворачивания «Развернуть/Свернуть» (>420 знаков, 7 строк);
   нет предупреждающих рамок статьи: «Не нашли это слово в оригинале.», «Найдено по основе…», «Найдено по корню…», «Статей не найдено», «Нет включённых словарей.» + «Открыть библиотеку»; нет плашек «S · NN %» (только общее примечание в карточке слова); нет «списка словарей» (`_DictRow`: «{n} статьи», «по основе слова»).
3. **Номер Стронга в тексте** → `StrongSheet` (`StudyViews.swift`): `.medium/.large` вместо full; список всех **включённых** словарей без фильтра (в нём окажутся английский Стронг, Abbott-Smith, BDB, симфония отдельно, Дворецкий) — нет `lookupStrong` (русские Стронги, слияние симфонии); заголовок — номера, без «Слово: …»/подзаголовка.
4. **Все места** — `WordViews.swift: ConcordancePage`: ищет через полнотекстовый `SearchEngine.run` по модулю **первой панели** (если у него есть Стронг), а не `rst-plus`; список 60 + «Показать ещё (n)» вместо 40; **нет** фильтров (книга / глава / вариант перевода), **нет** выделения слова с номером в тексте стиха, нет подзаголовка «n раз в m стихах · перевод»;
   заголовок «{key} · все места» вместо «Все места · {num} {лемма}»; текст «Найдено: N»; нажатие на место — `openVerse` (первая панель), а не `openRefInOther` (вторая панель) и без закрытия окон; текст «Нужен перевод с номерами Стронга…» вместо «В переводе со Стронгом этого слова нет.».
5. **Карточка Стронга в поиске** (`SearchPage.swift`): вместо карточки (номер, лемма, транслитерация, значение, «Статья словаря →», места с фильтрами и частью Библии) — одна ссылка «{strong} — словарная статья» на `StrongList`; поддерживаются только латинские `G`/`H` (`SearchEngine.strongNumber`).
6. **Подстрочник** (`MapsView.swift: InterlinearSheet`) — другая концепция: слова берутся из **модулей-подстрочников** (`features.interlinear`) и идут в порядке этого модуля; нет выравнивания `alignVerse` по оригиналам `oshb`/`byz-rp2018` в **порядке оригинала**, нет вкладок «Синодальный/Винокуров/Вульгата» и «Еврейский/Септуагинта/Вульгата» (вместо них — переключатель модулей-подстрочников, если их >1),
   нет Септуагинты и Вульгаты (`lxxInterlinear`, `vulgInterlinear`), нет бледных «догадок по словарю», нет русского чтения оригинала (`translit`), нет строки номера без буквы (показан полный «G976 G1»), нет иврита справа налево, нет стрелок «предыдущий/следующий стих», нет докачки оригинала («Загружаю оригинал…»),
   нет сообщений («Для этой книги нет оригинала.», «В оригинале этого стиха нет.», «Под словами — значения по словарю…», подписей-подсказок и подзаголовков вкладок), нет запоминания вкладки (`ilSource`/`ilSourceOT`); заголовок «Ин. 3:16» вместо «Подстрочник · Ин. 3:16»; размер `.medium/.large` вместо full;
   нажатие на слово открывает `WordSheet` (список), а не сразу статью full с «назад» → подстрочник и точной формой слова.
7. **Комментарии**: окно (`StudyViews.swift: CommentarySheet`) — только список секций «модуль → заголовок + текст»; нет вкладок по модулям, нет заголовка «{полная ссылка статьи} · {заголовок}», нет размера шрифта `commentaryFontSize`, нет ссылок на стихи в тексте (`splitRefs`), нет «Источника», заголовок окна «Толкования» вместо «Комментарий · {ref}»,
   подзаголовка нет; пустое состояние «Нет толкований» вместо «Комментариев к этому стиху нет». **Нет вообще**: названий комментариев после стиха и раскрытия под стихом (`below`), меток (`tag`), введений к книге и главе над заголовками, настроек `commentView`, `inlineCommentaries`, `commentaryFontSize`, общего правила «раскрыт один комментарий».
8. **Параллельные места** (`StudyViews.swift: XrefsSheet`): нет цитаты исходного стиха сверху, нет заголовка «Места · n» с подсказкой ⓘ, ссылка в строке краткая («Ин. 3:16»), а не полная («От Иоанна 3:16»), нет верхних индексов и «…» в многостишных ссылках,
   текст берётся максимум 4 стиха без перехода через главу; нажатие — `panes.openSecond` (вторая панель) вместо `openRefBelow` (новая панель под исходной); значок после стиха — « ⇅N» акцентом без квадратных скобок и курсива.
9. **Сравнение** (`ReaderView.swift: CompareSheet`): только один стих, а не выделенный диапазон; перечисляет **все** `store.bibles` (включая оригиналы, подстрочники и вспомогательные), открытый перевод не первый и не отмечен «открыт сейчас»; нет подсветки различий (`diffWords`), нет ряда языков, нет кнопки «Читать параллельно», нет «Другие переводы»/«Другой перевод не установлен»;
   подзаголовка (подпись выделения) нет; заголовок «Сравнить переводы» вместо «Сравнение переводов». Окна «Читать параллельно» (режим `pick`) нет — вместо него в меню «⋯» подменю «Перевод рядом» со всеми переводами.
10. **«Всё о стихе»** (`verse_guide.dart`) — нет совсем (нет пункта в меню «⋯» панели выделения).
11. **Иллюстрации** (`StudyViews.swift: IllustrationsSheet`): лист `.large` с постраничным `TabView` вместо полноэкранного просмотра; нет увеличения щипком/нажатием, сдвига, закрытия потягиванием вниз, кнопок лупы, счётчика «{n} из {total}», стрелок; не ограничено двумя картинками и не убраны повторы;
   значок после стиха — эмодзи « 🖼N» (число всегда), а не значок с цифрой «2» только при двух; ссылка «Страница файла на Commons» вместо «источник ↗»; нет сообщения «Картинка не загрузилась. Проверьте интернет.».
12. **Карта в карточке слова**: `WordViews.swift` — пункт «Название · Карта» открывает `PlaceDetail` внутри листа (Apple Maps), а не карту во второй половине экрана (область «Карты»; здесь только фиксация расхождения).
13. **Закрытие окон**: общего «закрыть всё» (× / фон / свайп вниз) нет — у каждого листа «Готово», закрывающее один лист; ступени высоты системные (`.medium`/`.large`/`.height(...)`), а не 0,5 / 0,86 / 0,92 / full; правило «назад только где нужно» не соблюдено (`NavigationStack` везде даёт свою стрелку).
14. **Выключенные модули**: во Flutter небиблейские модули можно выключить (они пропадают из словарей, комментариев, параллельных мест, иллюстраций, статистики); в Swift (`ModuleStore.installed`) такого признака нет (поиск по всему `swift/AOBible` на `setEnabled`/`isEnabled`/`disabled` — только несвязанное совпадение).
15. **Прочее по мелочам**: порядок словарей — `rank 0` включает `rst-symphony` (во Flutter симфония — ранг 1), внутри ранга сортировка по `name`, а не по `id` (`StudyData.swift: dictionaries`); в Swift нет проверки готовности таблиц (`studyReady`) и фонового достроения таблиц у старых установок (`StudyData.ensure`) — таблицы строятся только при установке;
    ключи настроек значков — `showXrefs` (Swift) против `showXrefButtons` (Flutter) — учесть при переносе резервной копии (`Core/UserData.swift`); у Swift нет настроек `commentView`, `inlineCommentaries`, `commentaryFontSize`; нет режима чтения для скрытия `[⇅ n]` (`focusMode`) [не проверял].

### 14.3. Есть в Swift, но нет в Flutter-версии изучения
- `DictionaryView` («Словарь» в меню «Ещё»: поиск по номеру Стронга или по началу слова) — отдельного экрана-словаря в `lib/features/study` нет (поиск по номеру Стронга живёт в вкладке «Поиск»).
- «См. слово»-ссылки в статьях словарей «по словам» (`StrongLinks.attributed(refs:)`, `EntryPage.openRef`) и блок «Другие словари» для того же ключа (`otherEntries`) — во Flutter вместо этого вкладки модулей и ссылки на стихи.
- Строка « KJV: …» в статье Стронга (`EntryView`) — во Flutter поле `kjv` не показывается.
- Порядок разделов статьи Стронга: Swift — «происхождение», затем «значение»; Flutter — «Значение», затем «Происхождение».
