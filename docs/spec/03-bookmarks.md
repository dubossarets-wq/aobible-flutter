## 0. Поправки к `SWIFT_SPEC.md` и `01-reader-settings.md`

1. SWIFT_SPEC §7: вкладка называется **«Любимые стихи»** (не «Любимые»). Порядок вкладок: **Закладки · Любимые стихи · Заметки · Выделения · Подборки · История**, у каждой справа число (§10.1).
2. SWIFT_SPEC §3.1 «сердечко только на широком экране»: порог — **ширина экрана ≥ 460 pt** (§5.1). У всех iPhone (≤ 440 pt) сердечка на панели **нет**: «В любимые» только в меню «⋯».
   Там же оно есть **всегда** (на любой ширине), а не «на узком — в меню».
3. SWIFT_SPEC §3.1 «цвет (ряд из 6 кружков + «стереть»)»: это не ряд на панели, а **всплывающая плашка под кнопкой-маркером** (§5.4).
4. SWIFT_SPEC §3.1: закладка по кнопке панели ставится/снимается **только у первого (по порядку Библии) из выделенных стихов**, а не у всех (§5.5). Заметка — тоже у первого.
5. SWIFT_SPEC §3.1: после «В любимые» уведомление есть, а **после выбора цвета уведомления нет** (§5.4); «Закладка удалена» / «Убрано из любимых стихов» из панели выделения — **без «Отменить»** (отмена есть только в окне «Закладки и заметки», §10).
6. SWIFT_SPEC §7 «подборок в Swift, похоже, нет» — подтверждаю: **нет** (§17).
7. `01` §8 `[уточнить правила обрезки знаков]`: `partText` берёт текст **от начала первого выбранного слова до конца последнего**; всё, что между ними (пробелы, знаки, «курсив» переводчиков), остаётся; пробелы сжимаются до одного, края обрезаются. Знаки перед первым и после последнего слова в часть не входят (§8.3).
8. `01` п. 23 «смена главы Swift сбрасывает выделение, у Flutter глава тоже меняет выделение»: в прочитанном коде **ничто не снимает выделение при смене главы**; выделение — множество `VerseRef` (с книгой), поэтому оно переживает переходы, а подпись панели умеет показывать стихи из разных мест (§5.2). Свайп главы при выделении отключён. **[уточнить на устройстве]**, снимается ли выделение при «Перейти».

## 1. Хранение и формат данных

Всё пользовательское лежит в SharedPreferences (iOS — `UserDefaults` с префиксом `flutter.`), **каждый ключ — одна строка с JSON**. Ключи и формат **совпадают с веб-версией**
(`App.jsx`, `core/highlights.js`), поэтому подходят перенос из старого приложения и файл «Мои данные». Любое изменение сразу пишет **весь JSON изменившегося ключа**
(сравнение «изменился ли объект» по ссылке). Повреждённый или отсутствующий JSON → пустое значение (приложение не падает). Неизвестные поля внутри записей **сохраняются как есть**
(записи хранятся как `Map`, не как фиксированные структуры).

Идентификатор книги — OSIS-подобный: `Gen`, `Exod`, `Matt`, `John`… (как в `lib/core/books.dart`). Время — **миллисекунды Unix** (`DateTime.now().millisecondsSinceEpoch`), целое число.
Ключ места — строка **`«книга.глава.стих»`**, например `John.3.16` (`refKey`); разбор `parseKey` требует ровно три части и числа в главе и стихе.

### 1.1. Ключи

| Ключ prefs | Тип JSON | Содержимое |
|---|---|---|
| `bookmarks` | список | `[{book, chapter, verse, text, at}]`. Новая — **в начало** списка. Одна закладка на стих (переключатель). Порядок в списке = порядок показа («новые сверху»). `text` — начало стиха, **не длиннее 160 знаков**, на момент установки (потом не пересчитывается). |
| `favorites` | список | `[{book, chapter, verse, text, at, part?:{from, to}}]`. Новая — в начало. **Один стих — одна запись.** `text` — полный текст стиха (без разметки) либо, если есть `part`, **только выбранные слова**. `part.from ≤ part.to` — номера слов (§8.3), включительно. |
| `notes` | объект | `{"книга.глава.стих": {text, label, at, updated}}`. Ключ — **первый (наименьший по порядку Библии) из выделенных стихов**. `at` — когда создана (не меняется при правках), `updated` — когда изменена, `label` — подпись («Исход 3:1–5»). Записи, у которых значение не объект, при чтении отбрасываются. |
| `highlights` | объект | `{"книга.глава.стих": "1".."6"}` — id цвета строкой (числа из файла приводятся к строке через `toString`). Один цвет на стих. |
| `highlightLabels` | объект | `{"1": "подпись", …}` — свои названия цветов выделения; пустое/пробельное = «имя по умолчанию». Меняется в «Оформление → Цвета» (§14). |
| `collections` | список | `[{id, name, at, items:[{book, chapter, verse, text, at}]}]`. Новая подборка — **в начало**. `id` — время создания в мс, записанное в системе по основанию 36 (`ms.toRadixString(36)`). `items` — в порядке добавления (показываются по порядку Библии). `text` в элементе — **до 200 знаков**. |
| `backups` | список | служебный ключ, §12.5. В файл «Мои данные» не входит. |
| прочие | — | `settings`, `panes`, `lang`, `searchQuery`, `plans`, `readLog`, `sermons`, `sermonSort`, `pulpitSize`, `customPlan*`, `ilSource`, `ilSourceOT` и др. — не этой области, но **входят в файл «Мои данные»** (§12.1). |

Ключ **`lastBuild`** — служебный: версия приложения при прошлом запуске (строка, `'1.0.0'` — константа `appVersion`), нужен для копии «до обновления с версии …» (§12.5).

### 1.2. Цвета выделения (`hlColors`, id → название по умолчанию, цвет)

`1` Жёлтый `#f3d36b`, `2` Голубой `#7fc4ec`, `3` Зелёный `#7ccfa4`, `4` Оранжевый `#f2a65a`, `5` Розовый `#e79ac0`, `6` Сиреневый `#b7a3e3`. Порядок в плашке, фильтре и настройках — именно этот.
Название для показа: `highlightLabels[id]` (обрезав пробелы), если не пусто, иначе переведённое имя по умолчанию (`t('Жёлтый')`…). Цвет любимого стиха: `#d9475e` (`loveColor`).

### 1.3. Флаги стиха (`Marks.flags`)

Для каждого стиха одна строка флагов: `f` любимый целиком, `p` любимая **часть** (`part` есть), `b` закладка, `n` заметка, `c` в какой-нибудь подборке, цифра `1…6` — цвет.
Считается один раз на снимок данных; читалка берёт готовое. По флагам рисуются отметки у стиха (§4).

### 1.4. Правила изменения данных (`marks.dart`, `MarksNotifier`)

| Действие | Правило |
|---|---|
| Закладка (переключатель) | Есть закладка этого стиха → удалить (по ключу стиха); нет → вставить `{book, chapter, verse, text, at: now}` **в начало**. |
| Любимый (вкл) | Сначала **удаляется** прежняя запись этого стиха (любимая часть тоже), потом новая `{…, text, at: now}` вставляется **в начало**. То есть повторное «в любимые» обновляет время и поднимает наверх, а любимую часть **заменяет полным стихом**. |
| Любимый (выкл) | Запись стиха удаляется. |
| Любимая **часть** | Прежняя запись стиха удаляется, новая `{…, text: выбранные слова, part:{from,to}, at: now}` вставляется **в начало**. Часть **заменяет** прежнюю отметку (целый стих или другую часть). |
| «Любимый ли стих» | `isFavorite` — есть запись с этим ключом (часть тоже считается). |
| Заметка | `setNote(первый, текст, подпись)`: если `текст.trim()` пуст — запись **удаляется**; иначе пишется `{text: текст как есть (не обрезается), label, at: прежний at или now, updated: now}`. |
| Выделение цветом | Для каждого стиха выбранных: цвет ставится (заменяя прежний) или (цвет `null`) снимается. |
| В подборку | Подборка существующая (по `id`) или новая (имя). Новая вставляется **в начало** с `items: []`. Добавляются только те стихи, которых в ней ещё нет (по ключу); каждому добавленному ставится `at: now`. Имена подборок **не проверяются на повтор** (две подборки с одним именем возможны). Переименовать подборку и менять порядок нельзя. |
| Отмена удаления (`putBack`) | Возвращает элемент **на прежний индекс** (индекс обрезается до длины списка), если в списке его ещё нет; проверка «уже есть» — своя для каждого списка (см. §10). |

Любое изменение, кроме загрузки, ещё и **перерисовывает отметки у видимых стихов** (счётчик `decorVersion`).

### 1.5. Тексты, которые кладутся в данные

- Берутся из перевода **панели, откуда действие**, без разметки (`verseText` → `plainText`: `{слово|G123}` → `слово`, `‹курсив›` → `курсив`). Стих 1 — берётся сам стих, а не заголовок главы.
- Это **снимок**: при смене перевода сохранённый `text` не меняется. Исключение: вкладка «Выделения» показывает текст стиха **живьём** из перевода панели (§10.5).
- Несколько стихов (в проповедь, копирование) — через пробел в одних кавычках или построчно «номер текст» (§5.6, §8.1).

## 2. Подпись места и формат цитаты

`Books.formatRef(book, chapter, verse, full)` = `«{сокращённое или полное имя} {глава}:{стих}»` (`Ин. 3:16` / `От Иоанна 3:16`). Сокращение — из справочника книг для языка интерфейса (`meta(book).short`), полное — `meta(book).name`.

`selectionLabel(refs, full)` (стихи уже по порядку Библии):
- один стих → `Нав. 18:5`;
- несколько в **одной книге и главе**: подряд → `Нав. 18:5–7` (длинное тире –), не подряд → `Нав. 18:5, 7, 9`;
- в разных главах/книгах → каждый как `formatRef`, через `; ` (`Нав. 18:5; Нав. 19:2`).

Цитата для копирования/«Поделиться»: `quoteText` = **`"текст" - подпись`**, где текст — тексты всех стихов через пробел (пустые пропускаются; пробелы сжаты), подпись — `selectionLabel(refs)` с заменой `–` на обычный дефис `-`:
`"Не ходи по следам злодеев…" - Притч. 4:14-16`. Кавычки — прямые `"`, перед подписью ` - ` (пробел, дефис, пробел).
Часть стиха копируется так же с подписью `Книга. гл:ст` (§8.2).

## 3. Что видно у стиха: отметки (`decor.dart`)

Только для настоящих стихов (не заголовков). В режиме «Как книга» значки скрыты; **цветной фон выделения остаётся** [из `verse_view.dart`: фон берётся из украшений без проверки режима].

**Фон стиха** (цвет подложки):
- есть цвет выделения → цвет с прозрачностью: жёлтый `1` — 36 % в тёмных темах и 45 % в светлых; сиреневый `6` — 45 %; остальные — 42 %;
- нет цвета, но стих **любимый целиком** (`f`) → розовый `#d9475e` 9 %;
- у «любимой части» (`p`) фона всего стиха нет — закрашены только слова части (`#d9475e` 20 %, §8.4);
- выделенный (панелью) стих рисуется читалкой поверх (9 % акцента + полоса 3 pt слева, SWIFT_SPEC §1.5) — это приоритетнее цвета.
- **Вспышка** при двойном касании: к фону добавляется `#d9475e` 30 % и гаснет за ≈0,8 с (5 ступеней по 160 мс, затухание квадратичное; SWIFT_SPEC §1.3).

**Значки между номером стиха и текстом** (слева направо, каждый с отступом справа 0,25 размера шрифта; размеры в долях размера шрифта `fontSize`):
1. закладка (`b`) — ленточка цвета акцента 0,42 × 0,62 с вырезом внизу; подпись для VoiceOver «Закладка»;
2. сердечко (`f` или `p`) — 0,62, цвет `#d9475e`; у части — 75 % непрозрачности; подписи «Любимый стих» / «Любимая часть стиха»;
3. папка (`c`) — 0,6, цвет акцента; «Стих в подборке».

**После текста:** жёлтая плашка заметки (`n`) 1,25 × 1,05 со значком пера, отступ слева 0,3, подсказка «Заметка». **Нажатие на плашку открывает окно заметки** этого одного стиха (§6). Дальше идут значки других функций (`⇅ n`, иллюстрации…).

**Под последним выделенным стихом** — строка действий (§7); при «Части стиха» вместо неё — панель части (§8).

## 4. Жесты чтения, меняющие данные (`gestures.dart`)

### 4.1. Двойное касание стиха (когда выделения нет; сам жест — SWIFT_SPEC §1.2–1.3)
- Снимается подсветка слова (`activeWord = null`).
- Стих уже в `favorites` (любой записью, в том числе «частью») → запись **удаляется**; уведомление **«Убрано из любимых стихов»**. Иначе → запись с полным текстом стиха из перевода панели (если текста нет — пустая строка) и уведомление **«♥ Добавлено в любимые стихи»**.
- Запускается вспышка сердечка (§3). **«Отменить» нет.**
- Уведомление — `Hub.toast`: плашка внизу экрана ≈2,6 с (с кнопкой действия — 5 с); новое заменяет прежнее.

### 4.2. Добавление любимой части: `addFavoritePart` (из панели части, §8)
Текст — выбранные слова; индексы упорядочиваются (`from ≤ to`); запись заменяет прежнюю отметку стиха (§1.4); уведомление **«♥ Часть стиха — в любимых»**.

### 4.3. Автокопия при смене версии (`bootBackup`, первое задание после запуска)
Если сохранённый `lastBuild` непустой и ≠ текущей версии → `snapshot('до обновления с версии {прежняя}')`. Если ≠ — записать текущую в `lastBuild`. При самой первой установке (`lastBuild` нет) копии нет.
Копия делается **раньше** переноса из старого приложения (§13): регистрация `afterStart` ставит `bootBackup` первым.

## 5. Панель действий выделенных стихов (`selection_bar.dart`)

### 5.1. Где и когда
- **Заменяет собой верхнюю панель (шапку) той панели чтения, где есть выделение** (высота панели — 54 pt, цвет и тень шапки; выделение хранится **отдельно для каждой панели**, у каждой своя панель).
- Выделение: долгое нажатие на стих или нажатие на номер стиха; когда выделение уже есть — нажатие в любом месте стиха добавляет/снимает стих. Жесты — SWIFT_SPEC §1.
- Esc (клавиатура) снимает выделение во всех панелях.
- Пока идёт выбор «Части стиха» или выделение — свайп главы выключен; режим чтения (`focusMode`) показывает скрытые панели.
- Слева направо (ширина кнопки `btn` зависит от ширины экрана: **≥ 460 pt — 44, 400…460 — 40, уже 400 — 36**; высота всегда 44; кнопки круглые, без подписей — только подсказки/метки):

| № | Элемент | Подсказка / метка | Когда есть |
|---|---|---|---|
| 1 | **✕** (24) | «Готово, снять выделение» | всегда |
| 2 | **подпись места** (занимает всё свободное место, сжимается по ширине, один ряд, 16,8 pt на широком / 15,2 на узком) | метка VoiceOver «Выделено стихов: {n}» | всегда |
| 3 | значок «языки» | «Читать параллельно» | всегда |
| 4 | значок «сообщение с текстом» | «Комментарии» | если подключена функция изучения (в обычной сборке — да) |
| 5 | **маркер** | «Выделить цветом» | всегда; «включён» (подсвечен), если у **первого** выделенного стиха есть цвет |
| 6 | **сердце** | «В любимые» / «Убрать из любимых» | **только при ширине ≥ 460 pt**; «включено», если **все** выделенные уже любимые |
| 7 | **заметка** (блокнот с пером) | «Добавить заметку» / «Открыть заметку» | всегда; «включена», если у первого есть заметка |
| 8 | **закладка** (контур / с галочкой) | «Закладка: продолжить отсюда» / «Убрать закладку» | всегда; «включена», если у первого есть закладка |
| 9 | **копировать** | «Копировать» | всегда |
| 10 | **«⋯»** (22) | «Ещё действия» | всегда |

На iPhone (ширина ≤ 440 pt) видны: ✕, подпись, языки, комментарии, маркер, заметка, закладка, копировать, «⋯» — девять элементов; сердца нет.
Подпись места слева берётся как `selectionLabel(выбранные по порядку Библии)` (§2), без полных названий.

### 5.2. Что считается «первым стихом»
`refs` — выделенные стихи **в порядке Библии** (не в порядке нажатий); `first = refs.first`. Состояния «включено» у маркера, заметки, закладки считаются **только по `first`**.
Выделение может содержать стихи из разных глав и книг (см. §0 п. 8); тогда «первый» — наименьший по порядку Библии.

### 5.3. После любого действия
Выделение **снимается** (`clear(pane)`), кроме: окно «⋯» открывается — снимается кадром позже (`doneLater`, чтобы окно успело открыться); ошибка «Поделиться» — выделение остаётся.
Окна «Заметка» и «В подборку» открываются от **контекста читалки**, а не панели, потому что панель исчезает сразу после снятия выделения.

- Для **заметки** над полем показывается `selectionText(модуль, refs)`: один стих — без номера; несколько — по строке «номер текст».

## 6. Окно «Заметка» (`showNoteSheet`)

**Вход:** кнопка «заметка» панели (§5.4), жёлтая плашка у стиха (§3, один стих), кнопка-карандаш в строке вкладки «Заметки» (§10.5), «Всё о стихе» (нажатие на карточку заметки в блоке «Ваши пометки»; область «изучение»).

**Окно:** нижний лист примерно **половина высоты** (поднимается над клавиатурой), прокручивается; заголовок, подзаголовок, тело, нижняя полоса с кнопками.

| Элемент | Содержимое |
|---|---|
| Заголовок | «**Заметка**» — если у `first` заметка уже есть; иначе «**Новая заметка**» |
| Подзаголовок | подпись: если у существующей заметки есть непустой `label` — он; иначе `selectionLabel(refs, full: true)` («Исход 3:1–5», полное имя книги) |
| Цитата | если текст стиха найден: карточка с текстом `selectionText(модуль, refs)` шрифтом чтения (15 pt, интервал 1,5). У нескольких стихов — по строке «номер текст». Когда окно открыто плашкой или карандашом — `refs` это **один** стих (`first`), поэтому показывается только он. |
| Поле | многострочное, **от 7 до 12 строк**, автофокус (клавиатура сразу), подсказка «**Ваши мысли, вопросы, ссылки…**», шрифт чтения 16,3 pt, межстрочный 1,5. Начальный текст — текст существующей заметки. |
| Ссылки | если в введённом тексте есть хотя бы одна ссылка на стих (`splitRefs`: «Ин 3:16», «1 Кор 13:4–7», «Быт. 23:19; 49:29–31» — вторая ссылка наследует книгу) — **под полем появляется карточка-просмотр** (рамка пунктиром) с тем же текстом, где ссылки — кнопки. Нажатие на ссылку: заметка **сохраняется** (текст из поля, `label`), открывается место `openRefInOther(pane, ссылка)` (из панели 0 — во вторую панель, при одной панели она создаётся; из другой панели — в ней самой) и **закрываются все окна**. |
| Дата | если заметка уже есть: «**Создана {дд.мм.гггг чч:мм}**» (по `at`) мелким серым |
| Нижняя полоса | слева «**Удалить**» (значок корзины; только если заметка есть), справа «**Сохранить**» (значок дискеты, главная). Если не помещаются — переносятся на вторую строку. |

**Действия:**
- «**Сохранить**» → `setNote(first, текст как есть, label)`; уведомление: непустой (`trim`) → «**Заметка сохранена**», пустой → «**Заметка удалена**» (запись удаляется, §1.4). Окно закрывается.
- «**Удалить**» — двухшаговая кнопка (`ConfirmButton`): первое нажатие заменяет её парой «**Удалить**» (красная) + «**Отмена**»; сама возвращается назад через **4 с**; «Отмена» — вернуть. Подтверждение → `setNote(first, '', '')`, уведомление «**Заметка удалена**» (**без «Отменить»**), окно закрывается.
- Закрытие листа жестом/вне окна — **ничего не сохраняет** (автосохранения нет, кроме перехода по ссылке).
- `label`: у существующей заметки он **не пересчитывается** при правках (остаётся прежним, даже если окно открыто с другим выделением); для новой заметки вычисляется один раз при **открытии** окна как `selectionLabel(refs, full: true)`.
  Именно `label` потом показывается заголовком строки во вкладке «Заметки» (§10.5), поэтому заметка, созданная к трём стихам, подписана «Исход 3:1–3», хотя ключ хранения — первый стих.
- Заметка многострочная, любой длины, не обрезается.

## 7. Строка действий под выделенным стихом (`sel_inline.dart`)

**Где:** сразу под **последним (по порядку Библии) выделенным стихом** панели, внутри блока текста; при «Сплошном» тексте блок текста разрывается и строка вставляется после этого стиха.
Карточка с «язычком» к стиху (язычок у левого края, на 24 pt); при появлении выезжает снизу на 6 pt и проявляется за 200 мс. Пока выделено несколько стихов — строка одна, под последним.

**Состав (слева направо):**
1. **«Слушать»** — главная кнопка, **только значок наушников** (квадрат во всю высоту ряда), метка «Слушать с этого стиха», подсказка «Слушать». Если функции аудио нет — кнопки нет. Действие: `listenFrom(pane, first)` и снять выделение.
2. **«В проповедь»** — `addToSermon(refs, модуль)` (окно §15), выделение снимается. Нет функции проповедей — кнопки нет.
3. **«Часть стиха»** — **только если выделен ровно один стих.** Включает режим §8: запоминается `PartSelection(pane, стих, модуль)`, **выделение снимается**.
4. **«Подстрочник»** — `openInterlinear(first, модуль)`, выделение снимается.

**Раскладка:** если подписи помещаются — одна строка высотой 44 «значок + подпись»; иначе — равные ячейки высотой 54: значок сверху, подпись снизу (12 pt, сжимается до 10,5 pt). Ячейка при нажатии слегка сжимается (0,96).

## 8. «Часть стиха»

### 8.1. Вход и выход
- Вход — только кнопка «Часть стиха» строки действий (§7) при **одном** выделенном стихе. В «⋯» панели выделения «Части стиха» нет.
- Режим привязан к **панели и стиху**. Стих при этом выглядит выделенным (полоса 3 pt слева); общее выделение снято.
- Режим **сбрасывается**: кнопкой «Отмена»; при выделении любого стиха в этой панели; при переходе или смене перевода панели; при закрытии панели; после «В проповедь», «В любимые», «Копировать».
- Свайп главы и щипок на время режима не работают (`01` §7.2, п. 5 поправок).

### 8.2. Панель под стихом (`_PartInline`) — тексты и состав
- Над кнопками подсказка серым курсивом: «**Нажмите на первое и последнее слово.**» (пока слово не выбрано); после выбора — выбранный текст в ёлочках: **«…»**.
- Кнопки высотой 44: широкая акцентная **«В проповедь»** (значок свитка) слева; справа составная кнопка из трёх частей с вертикальными линиями: **♥ «В любимые» | копировать «Копировать» | × «Отмена»**.
  Пока часть не выбрана (нет слов), «В проповедь» и первые две части — бледные и не нажимаются; «Отмена» работает всегда.
- «**В проповедь**» → `addFragmentToSermon(стих, модуль, текст)` → окно §15 в варианте «часть». Затем режим и выделение снимаются.
- «**В любимые**» → `addFavoritePart(стих, модуль, lo, hi, текст)` (§4.2). Затем режим снимается.
- «**Копировать**» → буфер: `"{текст части, пробелы сжаты}" - {Сокр. книги} {гл}:{ст}` (без слова «часть»); уведомление «**Часть стиха скопирована**»; режим снимается.
- «**Отмена**» → только `partSelection = null` (панель исчезает; общее выделение уже было снято при входе).

### 8.3. Выбор слов
- Слово — единица `wordsOf`: в **обычном тексте** каждое слово по регулярному выражению `[\p{L}\p{M}]+(?:[-’'][\p{L}\p{M}]+)*` (буквы и метки; внутри слова допускаются дефис/апостроф между буквами); слово **с номером Стронга** (`{слово|G123}`) — **один «слово» целиком** (весь текст фрагмента, включая пробелы и знаки внутри него).
  **Индекс** слова — его порядковый номер в стихе (с 0); именно он хранится в `part.from/to` и поэтому должен считаться **теми же правилами**, что в Flutter/вебе, иначе любимые части из файла сдвинутся.
- Нажатия по словам **этого** стиха: первое — ставит начало; второе — конец; третье — начинает заново с нового начала. Порядок нажатий неважен (границы упорядочиваются: `lo = min, hi = max`). Пока выбрано одно слово, `to` отсутствует и текст = это слово.
- Нажатие по пробелу/знаку препинания и по словам **других** стихов — ничего. Нажатие на номер стиха — обычное выделение стиха (и режим сбрасывается).
- Выбранные слова закрашены цветом акцента 24 % (одной цельной плашкой по строкам, скругление 6, расширение 2).
- Текст части (`partText`): от начала первого слова (внутри его фрагмента) до конца последнего (внутри его фрагмента), все фрагменты между ними целиком; `\s+` → один пробел; `trim`. Если слов в стихе нет — пусто.

### 8.4. Как показывается сохранённая любимая часть
В стихе, у которого есть `part`, слова с индексами `from…to` закрашены `#d9475e` 20 % (цельная плашка по строкам, скругление 6, расширение 2), сердечко у номера — 75 %. Индексы применяются к тексту **текущего перевода панели** (в другом переводе
выделятся слова с теми же номерами — запись о модуле не хранится) [так в коде; уточнить, нужно ли иначе].
Слова вне диапазона, при `from/to` больше числа слов, прижимаются к границам (`clamp`).

**Вход:** «⋯» → «В подборку…». **Окно:** нижний лист (≈ половина высоты), заголовок «**В подборку**», подзаголовок `selectionLabel(refs, full: true)`.

## 10. Окно «Закладки и заметки» (`manager.dart`)

### 10.1. Вход, оболочка, вкладки
- **Вход:** нижняя вкладка «Закладки» (во всех случаях открывается «для панели 0»); на широком экране (≥ 900 pt) — ещё «Закладки и заметки» в меню «⋮». Пока окно открыто, нижняя вкладка «Закладки» подсвечена.
- Параметр `pane` — панель, от которой работают «открыть место», «Продолжить чтение» и «История»; если такой панели нет — берётся панель 0.
- Окно со своей областью уведомлений: «**Отменить**» видно **поверх окна**. Заголовок окна: «**Закладки и заметки**». Содержимое — вкладки, горизонтальный свайп по списку переключает вкладки.
- Вкладки (ряд под заголовком; каждая показывает **число**): «**Закладки**» {число закладок} · «**Любимые стихи**» {число} · «**Заметки**» {число} · «**Выделения**» {число отмеченных стихов} · «**Подборки**» {число подборок} · «**История**» {длина истории панели}.
  Числа обновляются сразу при правках. Открывается всегда на первой вкладке «Закладки» (запоминания нет). Вкладки в стиле iPhone (их больше четырёх) — прокручиваемый ряд капсул «название число».
- Открытие места из любой вкладки (`_open`): панель `navigate(pane, стих)` (с миганием стиха) и закрытие **всех** окон (возврат к чтению).

### 10.2. Общая строка списка (`AobListRow`)
- Заголовок: значок (14) + название в одну строку (обрезается «…»); рядом (8 pt справа от названия) дата-время мелким серым — `meta`; ниже подпись до **двух строк** серым.
- Справа в строке — дополнительные кнопки (`extra`: только у заметок) и **кнопка-корзина** (вне стиля iPhone). В **стиле iPhone (всегда на iPhone)** корзины в строке нет.
- **Нажатие** на строку — действие вкладки (обычно «открыть место», §10.1).
- **Удаление:** смахивание строки **влево**. Вне стиля iPhone — красная полоса 88 pt с корзиной и подписью («Удалить» или «Убрать»); смахнуть за порог (стандартные ≈40 % ширины) — строка исчезает и удаляется. В стиле iPhone — капсула с подписью «Удалить»/«Убрать» (60 × 38): смахивание открывает её; **больше 60 % ширины** (или быстрый рывок) — действие выполняется сразу, меньше — строка остаётся открытой (щелчок по капсуле выполняет; щелчок по строке/смахивание вправо закрывает).
- Удаление всегда **сразу**, без вопроса, и всегда показывает уведомление с кнопкой «**Отменить**» (≈5 с; новое уведомление заменяет прежнее).
- В стиле iPhone строки объединены в карточку группы (первая/последняя — со скруглениями).

### 10.3. Вкладка «Закладки»
- **Сверху всегда карточка «Продолжить чтение»** (даже когда закладок нет): слева круг со значком «play», в середине три строки: «**Продолжить чтение**» (серым) · полное имя книги + `глава:стих` **текущего живого места панели** (то самое «верхний видимый стих», либо `ref` панели) · начало текста этого стиха (одна строка, если найден); справа стрелка. Нажатие → `_open` на это же место (мигание + закрытие окон). При касании карточка слегка сжимается (0,98).
- Пусто: значок закладки, «**Закладок пока нет**», «**Зажмите стих и нажмите «Закладка».**»
- Строки (в порядке хранения, новые сверху): значок закладки + полное имя `Книга глава:стих`; дата «дд.мм чч:мм» (**без года**); подпись — сохранённый `text` (до 2 строк). Подсказка/метка удаления: «**Удалить закладку**».
- Удаление: запись убирается; уведомление «**Закладка удалена**» + «Отменить» → запись возвращается на прежний индекс (если этой самой записи в списке нет).
- Закладок «на стих» бывает одна (переключатель), но в списке могут быть повторы, пришедшие из файла/старой версии — показываются все.

### 10.4. Вкладка «Любимые стихи»
- Пусто: значок сердца, «**Любимых стихов пока нет**», «**Дважды нажмите на стих — он станет любимым.**»
- Строки (в порядке хранения): красное сердечко + полное имя; **даты нет**; подпись — сохранённый `text` (у любимой части — только выбранные слова, значка «часть» в строке нет). Метка корзины «**Убрать из любимых**», подпись смахивания «**Убрать**».
- Удаление: запись убирается; уведомление «**Убрано из любимых стихов**» + «Отменить» → возвращается на прежний индекс, **если этого стиха снова нет в любимых** (проверка по ключу стиха).
- Нажатие — открыть место.

### 10.5. Вкладка «Заметки»
- Пусто: значок блокнота, «**Заметок пока нет**», «**Зажмите стих и нажмите «Заметка».**»
- Порядок: **по времени правки, новые сверху** (`updated`, иначе `at`, иначе 0). Записи с ключом, который не разбирается, пропускаются.
- **Поиск:** если заметок **больше трёх** — первым элементом списка (прокручивается вместе с ним) поле «**Поиск по заметкам**». Ищет по нижнему регистру с заменой «ё» на «е» подстроку в «текст + подпись + полное имя места». Если ничего не найдено — просто пустой список под полем (сообщения нет).
- Строка: значок блокнота + заголовок = `label` заметки, а если его нет — полное имя места; дата «дд.мм чч:мм» (по `updated`/`at`); подпись — **текст заметки** (2 строки); справа **кнопка-карандаш** «**Изменить заметку**» (мелкая, открывает окно §6 на один этот стих) и корзина. Метка удаления «**Удалить заметку**».
- Нажатие на строку — открыть место (ключ заметки = её первый стих).
- Удаление: запись убирается; уведомление «**Заметка удалена**» + «Отменить» → возвращает заметку, **если по этому ключу ещё ничего нет**.

### 10.6. Вкладка «Выделения»
- Пусто: значок маркера, «**Выделений пока нет**», «**Зажмите стих и нажмите маркер.**»
- Ряд плашек-фильтров (прокрутка вбок, поля 16): «**Все**» и по плашке на **каждый цвет, у которого есть хотя бы один стих**, в порядке цветов 1…6: кружок цвета + название (своё или по умолчанию) + число. Выбрана «Все» по умолчанию; фильтр — локальный в виджете вкладки (при повторном открытии окна сбрасывается; сохраняется ли при переключении на другую вкладку и обратно — **[уточнить]**).
  [краевой случай: если убрать последний стих выбранного цвета, плашки цвета уже нет, а фильтр остаётся на нём — список пуст; в «Все» не возвращает. Уточнить, исправлять ли в Swift].
- Список — **в порядке Библии**; строка: кружок цвета (если id не из 1…6 — цвет линии) + полное имя места; даты нет; подпись — **живой** текст стиха из перевода панели (для первых **200** строк; дальше без текста). Метка «**Убрать выделение**», подпись смахивания «**Убрать**».
- Удаление: цвет у стиха снимается; уведомление «**Выделение убрано**» + «Отменить» → цвет ставится обратно (поверх того, что там стало).

### 10.7. Вкладка «Подборки»
- Пусто: значок папки, «**Подборок пока нет**», «**Зажмите стих → «⋯» → «В подборку…».**»
- **Список подборок** (порядок хранения, новые сверху): значок папки + название; справа прижато «**{n} ст.**» (число стихов, **без даты**). Метка «**Удалить подборку**». Нажатие — **открывает подборку внутри этой же вкладки**.
  Удаление подборки (целиком, вместе со стихами): уведомление «**Подборка «{название}» удалена**» + «Отменить» → подборка возвращается на прежний индекс, **если подборки с таким `id` нет**.
- **Внутри подборки:** сверху слева маленькая кнопка «**‹ Все подборки**», под ней заголовок группы «**{название} · {число}**», затем стихи **в порядке Библии**: полное имя места (без значка), подпись — сохранённый `text`. Метка «**Убрать из подборки**», подпись смахивания «**Убрать**».
  Удаление стиха из подборки: уведомление «**Убрано из подборки**» + «Отменить» → стих возвращается на прежний индекс в списке `items`.
  Нажатие на стих — открыть место (окно закрывается). Если открытую подборку удалили, вкладка возвращается к списку подборок.
  Переименования, перемещения стихов между подборками, добавления из этого окна **нет**. [уточнить: сохраняется ли выбранная подборка при переключении на другую вкладку и обратно — состояние локальное в виджете вкладки]

### 10.8. Вкладка «История»
- История переходов **этой панели** (только в памяти; при перезапуске пропадает, `01` §2): **новые сверху**. Число на вкладке = длина истории.
- Строка (от края до края окна): значок «часы» + полное имя места; **текущее место** (индекс `hIndex`) — цветом акцента, жирнее, справа «**сейчас**». Даты и удаления нет.
- Нажатие: закрыть все окна и перейти по истории на нужное число шагов (`go(pane, индекс − hIndex)`) — **без новой записи в историю**.
- Пустого состояния нет (история всегда содержит хотя бы текущее место).

## 12. «Мои данные» (`mydata_page.dart`, `userdata.dart`)

### 12.1. Файл
Формат: **`{ "format": "aob-userdata", "version": 1, "exportedAt": "<ISO-8601 UTC с долями секунды>", "data": { "<ключ>": "<строка JSON>", … } }`**; подходит и веб-версии (тот же файл).
В `data` попадают **все ключи prefs со строковым значением**, кроме служебных; значения — строки JSON как они лежат в prefs. Исключения, где значение приводится к виду веб-версии:
- `lang`, `searchQuery` → JSON-строка в кавычках (`"ru"`);
- `panes` → веб-формат `[{moduleId, ref, history:[ref], hIndex:0, nav:1, highlight:null, flash:null}, null]` (не больше двух панелей, дополняется `null` до двух; неразобранные пропускаются).

**Служебные ключи** (в файл и в копии не входят, при восстановлении не трогаются): `backups`, `offlineAudio`, `autoAudio`, `lastBuild`, `activeBuild`, `autoUpdate2`, `knownBuilds`, `notifiedBuild`, `lateStarter`, `bootstrapped`, `errorLog`, `playUpdateNotified`, `legacyMigrated`, `legacyWeb`.
Модули (переводы, словари) в файл не входят. Не-строковые ключи (флаги, числа) не входят. (`widgetDay`, `newsSeen` и т. п. строковые — попадают в файл [уточнить, нужно ли].)

### 12.2. Окно «Мои данные» (лист, заголовок «**Мои данные**»), сверху вниз
1. Пояснение: «**Закладки, заметки, любимые стихи, выделения, планы, проповеди и настройки — в одном файле. Чтобы ничего не потерять или перейти на новый телефон.**»
2. Две кнопки (в стиле iPhone — **одна под другой, во всю ширину**; иначе в ряд при ширине ≥ 368 pt): «**Сохранить в файл**» (главная, значок «скачать») и «**Восстановить из файла**» (значок «загрузить»).
3. (если есть) ошибка красным текстом: «**Это не файл с данными AO Bible.**» (или текст системной ошибки сохранения).
4. (если выбран файл) карточка подтверждения, §12.4.
5. Заголовок раздела «**Резервные копии**», пояснение «**Настройки, закладки, заметки и любимые стихи сохраняются перед каждым обновлением (последние 5 копий).**», список копий (§12.5) или «**Копий пока нет — первая появится при следующем обновлении.**»
Окно имеет свою область уведомлений.

### 12.3. «Сохранить в файл»
Имя файла: **`AO Bible — мои данные ДД-ММ-ГГГГ.json`** (локальная дата; первая часть переводится: `t('AO Bible — мои данные')`). Файл пишется во временную папку и отдаётся системному «Поделиться» (`mimeType application/json`, заголовок «AO Bible — мои данные»).
Если пользователь **не отменил** — уведомление «**Файл сохранён**». Ошибка — текст ошибки красным под кнопками.

### 12.4. «Восстановить из файла»
1. Выбор файла (любой). Содержимое читается как UTF-8 JSON и проверяется: объект, `format == 'aob-userdata'`, `data` — объект. Иначе ошибка «**Это не файл с данными AO Bible.**» (красным).
2. Показывается карточка: «**В файле от {дд.мм.гггг чч:мм}: закладок {n}, заметок {n}, любимых стихов {n}, выделений {n}, планов {n}, проповедей {n}.**» (если даты в файле нет — «**В файле: закладок …**»). Числа — длина списка/число ключей объекта; не разобралось — 0.
   Ниже: «**Всё на телефоне заменится данными из файла. Нынешнее останется в резервной копии («Версии приложения»).**» и кнопки «**Восстановить**» (главная) / «**Отмена**» (убирает карточку).
3. «Восстановить»: `snapshot('перед восстановлением из файла')`; затем **замена целиком** (`replaceAll`): сначала удаляются **все пользовательские ключи** (кроме служебных), затем записываются ключи из файла (`lang`/`searchQuery` — из JSON-строки в обычную; `panes` — в наш формат `[{moduleId, ref}]`; неразобранные `panes` пропускаются; служебные ключи из файла игнорируются).
   Если запись оборвалась — прежние ключи возвращаются, замена считается неудачной (уведомление в п. 4).
   **Ключи, которых нет в файле, пропадут** (например, файл без `collections` сотрёт подборки на телефоне) — это ожидаемо и описано в тексте карточки.
4. После успеха: перечитываются настройки, панели, закладки/заметки (`marks.reload`), язык (`setLang(prefs['lang'] ?? 'ru')`), список копий обновляется. **Отдельного сообщения об успехе нет**; карточка просто исчезает.
   Ошибка: уведомление «**Не удалось сохранить: —**» (в подстановку `{error}` кладётся прочерк).

### 12.5. Резервные копии
- Хранятся в ключе **`backups`**: список (**новые первыми**) `[{at: мс, build: '', reason, data: {ключ: строка}}]`. `data` — все пользовательские ключи **как лежат в prefs** (без веб-преобразований).
- **Лимиты:** не больше **5** копий; общий размер JSON списка не больше **1 500 000 знаков** — пока больше, отбрасывается самая старая (минимум одна остаётся). Если пользовательских данных нет совсем — копия не создаётся. Любая ошибка записи молча игнорируется («данные важнее копий»).
- **Когда делаются:** перед восстановлением из файла (`перед восстановлением из файла`); перед возвратом из копии (`перед восстановлением из копии`); при первом запуске новой версии (`до обновления с версии {версия}`, §4.3). Причина хранится **по-русски в данных** и переводится при показе (`reasonLabel`; понимает ещё `перед переходом на версию {v}` из старой версии).
- **Строка копии:** дата «дд.мм.гггг чч:мм» жирно; ниже «{причина} · закладок {n}, заметок {n}, любимых {n}»; кнопка «**Восстановить эту копию**» (значок «вернуть», мелкая) — двухшаговая: первое нажатие → «**Восстановить**» (красная) + «**Отмена**» (само возвращается через 4 с); подтверждение → `snapshot('перед восстановлением из копии')` и замена целиком данными копии (в неё не входят служебные ключи; значения возвращаются как есть).
  Поскольку восстановление **само делает копию**, самая старая копия при заполнении списка (5) вытесняется.

## 13. Перенос из старой версии (`legacy.dart`) — только Android, один раз

**Для iOS/Swift не нужен** (в Swift своё: подхват ключей `flutter.*` из `UserDefaults` — см. «Расхождения»), но правила сохранены здесь, потому что те же ключи и приоритеты нужны при импорте файла.

- Старое приложение (Capacitor, Google Play) хранило данные в `localStorage` встроенного браузера по адресу `https://localhost`, ключи с префиксом **`aob.`**. Новое приложение — тот же пакет, хранилище то же: открывается невидимый `WebView` (пустая страница с базовым адресом `https://localhost/`), скриптом читаются все `aob.*`, ответ — одной JSON-строкой. Ожидание до **25 с**; ошибка/таймаут → `null` (перенос повторится при следующем запуске).
- Задание `Hub.afterStart` `migrateFromOldApp`: только **Android** и только пока `legacyMigrated != true`. Прочитанное (без префикса, только строки, без пропускаемых) **сначала целиком сохраняется в ключ `legacyWeb`**, затем раскладывается (`applyLegacy`), и только потом ставится `legacyMigrated = true`. Старые данные не удаляются.
- **Не переносятся** (служебные): `backups`, `offlineAudio`, `autoAudio`, `lastBuild`, `activeBuild`, `autoUpdate2`, `knownBuilds`, `notifiedBuild`, `lateStarter`, `bootstrapped`, `errorLog`, `playUpdateNotified`, `welcomePending`, `widgetDay`.
- **Правила раскладки** `applyLegacy(данные)`:
  - `lang`, `searchQuery` — в старом приложении JSON-строка; декодируется в обычную. `lang` записывается, если непустой; `searchQuery` — **только если в новом приложении пусто**.
  - `settings` — **слияние** `{...текущие, ...старые}` (старые значения побеждают).
  - `panes` — `convertWebPanes`: берутся только панели с `kind` пусто/`bible`; `moduleId` строка, `ref` из `{book, chapter, verse}`; неизвестный модуль заменяется на `rst-plus`; **не больше двух** панелей; формат → `[{moduleId, ref}]`.
  - **все остальные ключи** (`bookmarks`, `favorites`, `notes`, `highlights`, `highlightLabels`, `collections`, `plans`, `sermons` …) — записываются **только если в новом приложении пусто** (`null`, `''`, `[]`, `{}`, `'null'`) **и** прежнее значение непусто: то, что человек уже успел сделать в новой версии, не затирается.
- После переноса (если данные были): `setLang`; затем ждёт, пока установится хотя бы один перевод (экран первой загрузки), и вызывает `restartApp()` — состояние приложения пересоздаётся целиком (иначе уже прочитанные пустыми проповеди/планы/выделения остались бы пустыми); при отсутствии такой функции — перечитываются настройки, панели и закладки. Любая ошибка — только запись в журнал.

## 14. «Цвета выделений» (названия цветов)

Подраздел «Оформление → Цвета» (общая структура — `01` §10.5): заголовок «**Цвета выделений**», пояснение «**Дайте цветам названия — например, «Обетования», «Вопросы».**», затем шесть строк: кружок цвета (20) + поле названия (подсказка — имя по умолчанию, например «Жёлтый»). ## 15. «В проповедь» из выделения (`sermon_add.dart`)

**Вход:** «⋯» → «В проповедь» (все выбранные стихи), кнопка «В проповедь» в строке под стихом (§7), «В проповедь» в панели части стиха (§8, с `fragment`). Окно — лист на **70 %** высоты, всегда от «панели 0» (`pane: 0`).

**Подготовка:** тексты стихов `verseText(модуль, стих)` (полные, без обрезки; не найден — пусто); для части — один текст (`fragment`). Подпись `label` = `selectionLabel(refs, full: true)` (+ « (часть)» для части).

**Окно «Добавить в проповедь»** (подзаголовок — `label`):
- Заголовок блока: «**Новая проповедь**» (если проповеди уже есть) или «**Назовите проповедь**» (если нет); поле с подсказкой «**Например: Благодать Божья**» (автофокус, если проповедей нет) + кнопка «**Создать**» (значок плюса). Клавиша «Готово» = «Создать». Имя пустое → «**Новая проповедь**».
- Если проповеди есть: заголовок группы «**Или выберите проповедь**» и список проповедей (строка со значком плюса справа; порядок — как в списке проповедей [уточнить в sermons]). Нажатие на строку — добавить в неё.
- Добавление: на каждый стих — `VerseItem(книга, глава, стих, текст, part: это часть)`; **стихи подряд одной главы склеиваются в один блок** «Ин 3:16–18» (кроме частей); модуль записывается в блок.

**Экран «Добавлено»** (то же окно после добавления): по центру большая галочка; внизу надпись «**{подпись} — в проповеди «{название}».**» (подпись жирно); кнопки «**Открыть проповедь**» (главная, значок свитка; закрывает окно и открывает редактор этой проповеди страницей) и «**Читать дальше**» (закрывает окно).
**Выделение снимается** сразу при нажатии «В проповедь» (из строки под стихом — сразу; из «⋯» — кадром позже; из панели части — после вызова).

**Пустые состояния:** Закладки — «Закладок пока нет» / «Зажмите стих и нажмите «Закладка».» · Любимые — «Любимых стихов пока нет» / «Дважды нажмите на стих — он станет любимым.» ·

**Подсказки полей:** «Поиск по заметкам» · «Ваши мысли, вопросы, ссылки…» · «Новая подборка: «К уроку», «Утешение»…» · «Например: Благодать Божья» · «Нажмите на первое и последнее слово.»

## Расхождения со Swift (что нет / что иначе)

Файлы: `swift/AOBible/Views/BookmarksView.swift` (BM), `Views/InfoViews.swift` (ID, «Мои данные»), `Views/ReaderView.swift` (RV, панель выделения), `Views/PartSheet.swift` (PS), `Core/MarksStore.swift` (MS), `Core/UserData.swift` (UD),
`RootView.swift` (RT), `Views/MoreView.swift` (MV).

### А. Данные и формат
1. **Нет ключей `highlightLabels` и `collections`** вообще (MS `MarksData` содержит только `bookmarks`, `favorites`, `notes`, `highlights`; `exportEntries` — те же четыре). Следствия: подборки и названия цветов **пропадают** при импорте файла Flutter/веба (`importEntries` собирает `MarksData()` заново); при экспорте из Swift их в файле нет, а Flutter при восстановлении такого файла **сотрёт** подборки и названия цветов на телефоне (§12.4 п. 3).
   Подхват данных Flutter из `UserDefaults` (`flutter.bookmarks` и др.) — тоже только четыре ключа (MS `init`).
2. Модели Swift (`MarkItem`, `NoteEntry`) — фиксированные структуры: **неизвестные поля записей теряются** при перезаписи (Flutter хранит `Map` и сохраняет их). `MarkItem.at`/`NoteEntry.at` — `Double` в мс (формат совпадает).
3. `MarksStore.toggleFavorite(..., part:)`: если стих уже любимый — **удаляет** его (а не заменяет), т. е. «любимая часть» над уже любимым стихом (PS) **снимает любимое**; во Flutter часть заменяет прежнюю отметку (§1.4). Нет метода «любимые обновить»: поднятие наверх при повторном добавлении тоже нет.
4. `setNote` (MS): **обрезает пробелы** по краям текста (Flutter хранит как есть, обрезка нужна только для проверки «пусто»); **не принимает `label`** (подпись не создаётся; существующая сохраняется при правке текста); для новой заметки `at = updated = now` — совпадает.
5. Закладка/любимый из панели выделения (RV `selectionBar`) переключает **каждый выделенный стих** (у кого состояние совпадает с состоянием первого), с **полным** текстом стиха; Flutter — закладка только у `first` и с текстом ≤ 160; любимый: «все любимые → снять у всех, иначе поставить всем» (§5.4).
6. Закладка из «Ещё» (MV строка 18–30): ставится **начало главы** `max(1, verse панели)`, не снимается повторным нажатием, показывает `alert` «Закладка: …»; Flutter — переключатель на живое место без уведомления (§11).
7. Текст закладки Swift — без обрезки до 160; Flutter-списки показывают подпись до 2 строк, поэтому визуально без разницы, но размер данных больше.

### Д. «Часть стиха» (PS)
28. Не режим в тексте, а **отдельный лист** со словами-кнопками; слова = **куски по пробелам/переводам строки** (`split`), а не слова по `wordsOf` (буквы + метки + слова с номерами Стронга целиком). Поэтому **индексы `part.from/to` несовместимы** с Flutter/вебом: части из файла Flutter подсвечиваться/читаться будут неверно и наоборот. Нужен общий разбор слов (регулярное выражение `[\p{L}\p{M}]+(?:[-’'][\p{L}\p{M}]+)*` и «слово Стронга = одно слово»; в `ReaderView.wordRe` оно уже есть).
29. Нет подкраски выбранных слов в тексте стиха (акцент 24 %) и подсветки сохранённой части (`#d9475e` 20 %).
30. Копирование — `текст\n— Книга глава:стих (часть) (Модуль)`; Flutter — `"текст" - Сокр. гл:ст` и уведомление «Часть стиха скопирована». Кнопки: «Копировать», «Поделиться», «Любимое» (без подсказки), «В проповедь» — меню; сообщения «Скопировано», «Любимые обновлены», «Добавлено в проповедь» (зелёным текстом).

### Е. «Мои данные» (ID `MyDataView`, UD)
33. Вход: в Swift пункт «Мои данные» стоит в «Ещё» (MV строка 83); во Flutter — только в «Настройки → Мои данные» (строка с подписью «Сохранить и перенести на новый телефон»), в «Ещё» его намеренно нет. Оставить ли оба входа — решить (`01` Д3 п. 30).
34. **Набор ключей уже:** `collect` (UD) отдаёт `bookmarks`, `favorites`, `notes`, `highlights` (без `highlightLabels`, `collections`), планы, `sermons` и подмножество `settings` (15 ключей; названия отличаются: `showXrefs`, `panesStacked`). Не передаются `lang`, `panes`, `searchQuery`, `readLog`, `customPlan*`, `sermonSort`, `pulpitSize`, `ilSource*`. Файл Swift при восстановлении во Flutter **заменит всё**, что в нём отсутствует (§12.4).
35. Файл Swift — `prettyPrinted`, `exportedAt` без долей секунды; **разбор `exportedAt`** (UD `parse`, `ISO8601DateFormatter()` по умолчанию) вероятно **не понимает дату с долями секунды**, которую пишет Flutter (`…T10:15:30.123456Z`) — тогда карточка покажет «В файле: …» вместо «В файле от …» [проверить].
36. Имя файла по умолчанию — «AO Bible — мои данные» (без даты `ДД-ММ-ГГГГ`).
37. Даты в окне: `d MMMM yyyy, HH:mm` (по-русски), Flutter — `дд.мм.гггг чч:мм` цифрами одинаково для всех языков.
38. Карточка подтверждения: перечисление «закладок N, заметок N, …» без предложения «В файле от …: …» (почти совпадает); кнопки «Восстановить» / «Отмена» — есть.
39. **Нет двухшагового подтверждения** «Восстановить эту копию» (в Swift сразу «Вернуть эти данные»), причина копии при возврате — «перед возвратом из копии» (Flutter: «перед восстановлением из копии»); пояснение копий: «…перед каждым обновлением и восстановлением» (Flutter: «перед каждым обновлением»).
40. Сообщения: Swift пишет зелёным «Данные восстановлены.» / «Данные возвращены из копии.» / «Файл сохранён.»; Flutter об успехе восстановления не сообщает. Ошибка «Не удалось сохранить: —» отсутствует.
41. После восстановления Swift не перечитывает язык/панели (`lang`, `panes` в файле не обрабатываются, §12.4 п. 4).
42. Копии Swift хранятся файлом `backups.json` и содержат только `collect()` (п. 34), Flutter — **все** пользовательские ключи; лимит 5 / 1,5 млн знаков совпадает. Копия «до обновления» в Swift делается по `CFBundleVersion` в `RootView.task`; Flutter — по константе `appVersion`.
43. Нет `legacy.dart` (и не нужен для iOS): вместо него в `RootView.task` один раз подхватываются `flutter.settings` и `flutter.lang`.

### Ж. Что совпадает
Формат файла `aob-userdata` / `version 1`; цвета выделения (6 цветов, id `"1"`…`"6"`); структуры `bookmarks`/`favorites`/`notes`/`highlights`; `Part {from,to}`; двойное касание → любимый с тем же текстом уведомления и красной вспышкой;
лимит 5 копий и 1,5 млн знаков; текст «Это не файл с данными AO Bible.»; «Всё на телефоне заменится данными из файла…» (кроме «(«Версии приложения»)»); выделение — полоса акцента 3 pt и фон 9 % / 16 % («Сплошной»).
